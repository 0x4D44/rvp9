# GOP topology / GfGroup (Phase-I infra) — scratchpad

## Goal
libvpx-faithful `GF_GROUP` struct = single source of truth for per-frame TYPE
(KF/GF/ARF/OVERLAY/normal-inter) + ARF src offsets + GF interval. Gate-safe
refactor: emitted frame types + refresh flags BYTE-IDENTICAL to today.

## Current scheduling (frame_loop.rs) — what we must reproduce
- KF: `frame_idx % gop == 0` → `FrameKind::Key`, refresh=0xFF.
  - frame_loop.rs:1077-1082 (decision), :1398 / build_keyframe_packet (refresh 0xFF).
- Normal inter: refresh=0x01 (LAST only). frame_loop.rs:2027-2031.
- GOLDEN-refresh inter: every `A14_GOLDEN_REFRESH_PERIOD = 8` inter frames
  since last KF/golden-refresh → refresh=0x03 (LAST+GOLDEN).
  - counter `frames_since_golden_refresh` incremented BEFORE check.
  - frame_loop.rs:595, 697 (const=8), 2023-2031, 2210-2212 (reset on refresh), 1446 (reset on KF).
  - NOTE: independent cadence from ARF (constant 8, not gop/2).
- ARF (only when `enable_alt_ref`): every `arf_interval = max(gop/2, 2)` inter
  frames since KF/ARF → non-show ARF (refresh=0x04), superframe-prepended.
  - counter `inter_frames_since_arf`. frame_loop.rs:585-591, 1199-1230, 1247-1250, 1447 (KF reset), 1228 (ARF reset).

## Design decision (1-pass subset, byte-identical)
The current encoder has TWO independent cadences (GOLDEN-period=8, ARF=gop/2).
libvpx's 2-pass merges them; the 1-pass RT path the encoder actually runs does
NOT. To stay byte-identical I reproduce the encoder's CURRENT decisions, not
libvpx's 2-pass schedule. `GfGroup` answers per display-frame:
- `update_type(frame_idx)` -> KF/GF/LF (golden/normal) for the SHOW frame.
- `arf_src_offset` / ARF presence via `arf_before(frame_idx)` query (gop/2 cadence).
- `refresh_flags(frame_idx)` -> 0xFF / 0x03 / 0x01 (the exact mask emitted today).

Fields exposed for TPL/2-pass consumers: update_type[], arf_src_offset[],
gf_group_size, gf_interval. 2-pass-only fields (rf_level, layer_depth,
bit_allocation, gfu_boost, arf_index_stack) documented as follow-up.

## PROOF oracle
Decode emitted bitstream via rvp9-decoder, extract per-frame (FrameKind +
refresh_frame_flags + show_frame), assert EXACTLY matches GfGroup schedule.
Anti-G3: a stubbed/diverging schedule fails. Byte-identity via FNV golden
(reuse RVP9_A4_RD_PARTITION_DISABLE pin like w_buffer_pool.rs).
