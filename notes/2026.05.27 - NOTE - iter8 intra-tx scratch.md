## Key constraint discovered
- KF writer `write_kf_block` (modes_writer.rs ~1060) does NOT emit tx_size bits
  (step 4 comment: "tx_size NOT emitted when tx_mode != TxModeSelect").
- Decoder KF path (tile.rs:787) reads tx_size via read_tx_size BEFORE y_mode,
  using params.tx_mode from header. allow_select = !lossless = true.
- So decoder is ALREADY ready. To enable intra tx select:
  1. KF header tx_mode -> TxModeSelect
  2. write_kf_block must call write_tx_size between skip and y_mode (wire order!)
     decoder order: skip(767) -> tx_size(787) -> y_mode(807)
     writer order today: skip -> y_mode -> uv_mode -> [no tx]

## Plan
1. Add `picked_tx_size` field to PartitionLeafDesc (default max_txsize).
2. choose_intra_luma_tx_size in lib.rs: causal-recon RD loop.
   - For each candidate tx (Tx4x4..max_tx): scratch-recon the leaf (predict->
     fdct->quant->idct-add per sub-block into a scratch buffer seeded from
     committed neighbour recon), accumulate transform-domain dist (vp9_block_error
     >> shift) + coef rate (cost_coeffs, leaf-local ctx). Pick min RD.
   - tx_type for Y = mode.tx_type() unless Tx32x32 (DctDct). ADST per candidate.
3. Call it in pick_and_simulate_intra_encode_partitions (Y only, after mode pick,
   before simulator). Store into leaf.picked_tx_size. Thread chosen tx into
   simulator via luma_tx_override param (None=max for the test-only callers).
4. build_kf_mi_grid + build_kf_mi_grid_for_lf: tx_size = leaf.picked_tx_size.
5. build_keyframe_packet: tx_mode -> TxModeSelect.
6. write_kf_block: insert write_tx_size after skip, before y_mode. Add tx_mode param.
   write_tile_intra_keyframe + write_partition_tree thread tx_mode through.
7. Re-pin goldens if drift_diag SSE=0 + gate 4/4 pass.
