## Gate semantics (the real correctness bar)

The cross-decoder gate is a **differential decode test**: encode with rvp9-encoder,
decode the SAME stream with BOTH rvp9-decoder and vpxdec+ffmpeg, assert byte-identical
decoded frames. Implication: the encoder output may CHANGE freely as long as the new
stream is valid VP9 that both decoders agree on. Keeping the default path byte-identical
(as the session has done) is the *strongest* safety (proves no regression from known-good),
but is not strictly required — a green differential gate on a changed stream still proves
self-consistency. Each integration must keep the gate green.
