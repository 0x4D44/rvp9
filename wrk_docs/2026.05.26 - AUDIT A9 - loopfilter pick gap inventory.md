## Section-by-Section Narrative

### 1. Main Filter-Level Entry Point

`vp9_pick_filter_level` (vp9_picklpf.c:159-203) routes selection to three strategies based on `LPF_PICK_METHOD`:

1. **LPF_PICK_MINIMAL_LPF**: Disable filter if it was enabled on previous frame.
2. **LPF_PICK_FROM_Q**: Fast linear formula `filt_guess = (q_index * 20723 + 1015158) >> 18` (8-bit; scaled for HBD).
3. **LPF_PICK_FROM_FULL_IMAGE / LPF_PICK_FROM_SUBIMAGE**: Call `search_filter_level` for SSE-driven binary search.

rvp9 implements strategy 2 only via `pick_filter_level(q_index: u8)` in loopfilter.rs:75-77 (`(q_index >> 1).min(MAX_LOOP_FILTER)` — equivalent to the 8-bit libvpx formula but missing CR scaling, KF adjustment, HBD variants, method routing).

### 2. Binary Search Infrastructure (NOT PORTED)

`search_filter_level` (picklpf.c:78-157) implements ternary search to minimise frame Y-SSE. Initialises from prior frame `lf->last_filt_level`, computes step size, iterates filter+SSE evaluations with bias penalty `bias = (best_err >> (15 - (filt_mid/8))) * filter_step`, modulated by `section_intra_rating` in 2-pass and halved when `tx_mode != ONLY_4X4`.

`try_filter_frame` (picklpf.c:46-76) builds mask, applies LF (single or MT), measures Y-SSE (8-bit or HBD), restores unfiltered frame. Called up to ~63× per frame when search is active.

Both NOT PORTED. Loop-filter kernels themselves are in rvp9-core, but the measure-and-search loop is absent.

### 3. Auxiliary Gates and Modulation

`get_max_filter_level` (picklpf.c:37-44) clamps max to `MAX_LOOP_FILTER * 3/4 = 47` instead of 63 when 2-pass + section_intra_rating ≤ 8%. Prerequisite: 2-pass infrastructure (A3, NOT PORTED).

`get_section_intra_rating` (picklpf.c:27-35) reads 2-pass intra-coding percentage. Used by max gate and search bias modulation.

### 4. High-Bit-Depth Variant

HBD path (picklpf.c:62-67) selects `vpx_highbd_get_y_sse` vs `vpx_get_y_sse` based on `cm->use_highbitdepth`. **In scope per goal — Profile 2/3 is included.** Prerequisite: HBD frame buffer + SSE kernel (A20).

### 5. Editorial Gates

**Cyclic-refresh scaling (picklpf.c:191-195):** When 1-pass CBR + CR-AQ + segmentation + (qindex<200 OR >320×240) + non-screen + non-KF, scale `filt_guess = 5 * filt_guess >> 3`. CR-boosted blocks have higher effective QP so need less deblocking.

**Keyframe adjustment (picklpf.c:197):** `if (frame_type == KEY_FRAME) filt_guess -= 4`. Keyframes use lower base QP.

### 6. Encoder Call Site

libvpx calls `vp9_pick_filter_level` in `loopfilter_frame` (encoder.c:3430) inside an ALT-REF gate, with `last_filt_level = 0` reset on non-forced keyframes, and saves the picked level to `last_filt_level` for next frame's search init.

rvp9 calls `pick_filter_level(q_index)` unconditionally in frame_loop.rs:770 (KF) and frame_loop.rs:1027 (inter). No ALT-REF gate, no KF reset, no `last_filt_level` tracking.

## Cross-Cutting Gaps

**CC-1. No search-based filter-level selection at low cpu-used:** libvpx has LPF_PICK_FROM_FULL_IMAGE (cpu<3) and LPF_PICK_FROM_Q (cpu≥3). rvp9 always uses Q-based. Search method architecturally unavailable. Expected ~1-2 dB at cpu-used 0-2.

**CC-2. No per-frame LF search history:** libvpx tracks `lf->last_filt_level` across frames; rvp9's pick is a stateless pure function. Marginal (<0.05 dB) but architecturally cleaner.
