RVP9 Unit 1369 — AVX2 quantizer clamp-constant hoist (rejected)

Base: integrated trunk commit 8dc22c2339390bae0b349dc319667ff54abdbb54.

Candidate: construct the AVX2 `INT16_MIN` and `INT16_MAX` clamp vectors once
per quantizer call, outside the AC coefficient loop, then reuse them for every
eight-coefficient chunk. The candidate changes no arithmetic, scan order, or
output representation. It was selected from the Unit 1366 Crucible profile,
where `vp9_quantize_fp_avx2_inner` accounted for 9.278% of weighted samples.

Correctness:

- Crucible x86-64 release focused suite: 4 passed, 0 failed.
- A deliberately mutated `max_i16` vector set the clamp ceiling to zero. The
  same focused scalar differential failed in `Tx4x4` (`qcoeff` mismatch),
  proving the test exercises the clamp path.
- After restoring `INT16_MAX_I32`, the x86 suite passed again: 4/4.
- Local AArch64 release scalar quantizer tests passed: 6/6.

mechanism is increased register pressure or altered loop scheduling; no PGO
qualification is warranted for a clear plain-release loss. The source change
was removed from the task branch after this evidence was captured.
