# x86 zero-quantized Hadamard metrics: exact, not retained

The SSE2 prototype skipped sign restoration and dequantization for eight-coefficient groups whose quantized magnitudes were all zero. It accumulated their exact coefficient-square error and kept the existing mixed-group path. The [current production-PGO exact-IP profile](../2026-09-26-current-pgo-tree-town-exact-ip/README.md) put six relevant Tx8 full-metrics RVAs at 5.76% of direct Tree samples, 3.62% of Town, and 0.023% of Ducks. Those shares identified an experiment, not a predicted speedup. An older NEON zero-group branch lost on CPU7 VBR; this was the distinct x86 CPU6 test.

The candidate was local code commit `ce7a6fc9`; [candidate.patch](candidate.patch) preserves its zero-context one-file diff (`git apply --unidiff-zero`) without landing it on main. Source SHA-256 was `dde637612afdcbbabdc315d8cc02c88ff03d118780d4fafb55316b62eb8b0aaa`. The new old-path/scalar differential covered zero, mixed, and extreme coefficients at four quantizers, including a zero-quantized `i16::MIN` pair. The worker observed its deliberate-red mutation fail with error `0` instead of `64`, then restored the source. AArch64 passed 38 focused quantizer tests and `cargo check --locked -p rvp9-encoder`; Rosetta x86-64 and native Crucible x86-64 each passed all three SSE2 module tests. Formatting and diff hygiene passed. A later independent red rerun was refused by the Mac's active quiet-window guard; no check was bypassed and the temporary source mutation was restored to the committed hash.

Crucible built the candidate with the unchanged [28-row production PGO recipe](pgo-manifest.txt), 60 frames per row and 31 raw profiles. Candidate EXE SHA-256 was `af445484f63a2880ae766d4cdf05dbd51929c06dbafd865b34f58df921e285d3`, PDB SHA-256 `35c22a2ba728784e2f34330ae96757f6d753a6ab6e9b0e387e4446568101a522`. The code-equivalent integrated control PGO EXE was `3caee3f4416087ffe13069b4280f48fe92435bc32c9c0a41bebb7c187a73b3ee`. Each screen's identity CSV pins both binaries and the three inputs. The checked [five-pair runner](screen-zero-metrics.ps1) and [one-core runner](screen-zero-metrics-pinned.ps1) adapt existing checked-in paired scripts; both retain alternating arm and clip order, warmups, every raw pair, and exact output hashes.
