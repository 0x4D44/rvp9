The TX-selector callsite at `crates/rvp9-encoder/src/lib.rs:11471` contributes 61 Ducks samples; that source line contains a large inlined call and is **not** a single-operation estimate. Full-pixel diamond search plus its SAD4D adapter and SAD4D kernel contribute 98 + 74 + 120 Ducks samples, again a sampled self upper bound, not an expected gain. Tree's leading symbols are AVX2 sub-pixel variance (179/1,189), guarded Hadamard metrics (86), and round-trip reconstruction (71); Town's are sub-pixel variance (143/1,017), AVX2 quantizer (71), and guarded metrics (51).
