RVP9 Unit 1362 `(0,0)` sub-pel identity fast path

Candidate: working-tree source after Unit 1361 plus the direct integer-centre
path in `crates/rvp9-core/src/dsp/x86_64/subpel_variance_avx2.rs`.

The path is exact: at `(xoffset, yoffset) == (0, 0)`, the scalar bilinear
filters are `[128, 0]` in both directions, so the interpolated block equals
the source block byte for byte. The AVX2 path therefore calls the existing
exact `(sum, sse)` variance reduction directly and applies the same scalar
variance finisher.

`src_stride + 1`; `differential_var_sse` failed at `w=4, h=4, xoff=0, yoff=0`
with `(var,sse)` mismatch. Restoring the source made the same test pass.

--all -- --check` passed. Existing workspace clippy diagnostics remain in
