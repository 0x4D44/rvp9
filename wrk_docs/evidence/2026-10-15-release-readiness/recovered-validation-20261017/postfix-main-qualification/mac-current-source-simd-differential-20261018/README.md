# Native Apple Silicon SIMD differential test filters

On 2026-10-18, two serial, locked-offline `rvp9-core` library test filters passed on native Apple Silicon (`aarch64-apple-darwin`) at source commit `9700ed85a7f73fa2220d80decf7fbd9a981ab1fd`. The `rvp9-core` source tree is identical to the release candidate's product source commit `fb5c0c917038db6c640b3dbc7c2b84b567233333`; identities and toolchain versions are in `source-identity.txt`.

`cargo test --locked --offline -p rvp9-core --lib differential -- --test-threads=1` passed 35 tests with 0 failures or ignored tests. `cargo test --locked --offline -p rvp9-core --lib scalar -- --test-threads=1` passed 33 with 0 failures or ignored tests. The test-name sets are disjoint, for 68 unique selected tests. Readable output and exit status are preserved for each command. The committed text copies remove one redundant terminal line feed from Cargo’s double-line-feed ending so the evidence passes `git diff --check`; `source-identity.txt` records SHA-256 values for the byte-exact scratch logs. Appending one LF to each committed transcript reproduces and verifies its recorded raw-log SHA-256.

The selected tests include native NEON SAD, SAD x4D, variance, subpixel variance, quantization, subtraction, transform, inverse-transform, projection, min/max, convolution, and Hadamard oracle checks. Several are adjacent routing or scalar checks rather than HLD SIMD kernels; the filters are based on test-name substrings, not a complete selection of every HLD-mapped test. The `scalar` filter selects test names containing “scalar”; it does not run the crate with SIMD disabled. No `RVP9_FORCE_SCALAR` qualification is claimed.

This is Apple Silicon test-execution evidence only. It does not establish the x86-64 matrix, all HLD rows, tests with other names, universal equivalence outside bounded input domains, full AArch64 scalar routing, or release-gate acceptance. The source inventory remains open; existing x86 focused evidence is recorded separately in the readiness status.
