# Code review — `crates/rvp9-harness/`

Date: 2026-08-22  
Scope: `crates/rvp9-harness/`  
Baseline: the fresh `origin/main` worktree supplied by Deltic  
Method: static, multi-lens source review with independent adversarial verification

This was one bounded read-only review pass. It did not build or run the app,
tests, external encoders, bitstream tools, or the exploratory-test harness.

## Result

Nine defects were confirmed and filed. Five are Medium severity false-green or
invalid-comparison paths. Four are Low severity validation or diagnostic
failures. No separate requirement survived conservative triage: every promoted
item is a concrete behavior defect, not design debt.

## Confirmed findings

### Medium — F.0.2 strict mode does not check all strict fields

`crates/rvp9-harness/src/bin/f02_block_oracle.rs:884` names `q_index`,
`tx_size`, and `luma_eob_nonzero` as strict. The comparator at
`crates/rvp9-harness/src/f02_schema.rs:1256` checks seven other fields and omits
all three. A difference confined to these values produces a zero mismatch count
and can pass strict mode.

Concrete fix: compare the three fields, include them in paired JSONL, and add a
table-driven regression that mutates each field independently. Tracked as
`RVP9-BUG-KIL-00084`.

### Medium — frame selection removes decoder history before deep comparison

Level 3 skips pre-range packets before updating frame-context banks at
`crates/rvp9-harness/src/bin/diff_bitstream.rs:1454`. Level 4 skips them before
packet parsing and reconstruction at
`crates/rvp9-harness/src/bin/diff_bitstream.rs:1917`. Selecting an interframe
therefore starts from fresh state. Because symmetric errors are suppressed, the
two legs can fail for the same missing-history reason without reporting the
target divergence.

Concrete fix: prime both state machines through the selected start, suppressing
only pre-range reporting. Add an interframe regression whose target requires an
earlier reference frame. Tracked as `RVP9-BUG-KIL-00085`.

### Medium — malformed F.0.2 arguments can produce a zero-work success

Several numeric options silently fall back to defaults at
`crates/rvp9-harness/src/bin/f02_block_oracle.rs:453`. The bitrate parser at
line 503 drops invalid tokens. `--kbps nope` leaves an empty vector, skips the
work loop at line 614, and reaches `Done` at line 1592.

Concrete fix: distinguish omitted from malformed options; require positive
frames and bitrates; reject empty or partly malformed bitrate lists. Tracked as
`RVP9-BUG-KIL-00086`.

### Medium — E.1 hides failure of a requested comparison leg

`run_libvpx` maps setup, timeout, exit, and read errors to `None` at
`crates/rvp9-harness/src/bin/e1_block_stats.rs:1182`. The caller at line 2254
renders `n/a`, writes the report, and exits successfully even when the caller
explicitly supplied an existing `vpxenc`.

Concrete fix: distinguish an omitted optional leg from a failed requested leg,
and propagate the latter as a non-zero command result. Use a fake child for
exit/timeout regressions. Tracked as `RVP9-BUG-KIL-00089`.

### Medium — four fixture-dependent test groups still report false green

The early returns in `crates/rvp9-harness/tests/multi_tile.rs:27`,
`crates/rvp9-harness/tests/lossless.rs:42`,
`crates/rvp9-harness/tests/intra_only.rs:41`, and
`crates/rvp9-harness/tests/buffer_pool_recycle.rs:40` turn missing vectors into
passing tests. Multi-tile decoding, lossless/WHT, IntraOnly/show-existing, and
buffer recycling can therefore all appear covered when no assertion ran.

Concrete fix: apply the existing `rvp9_conformance_vectors` visible-ignore
pattern, then require each exact vector and sidecar when enabled. This is a new
set of sites related to, but not covered by, fixed bug `RVP9-BUG-KILN-00063`.
Tracked together as `RVP9-BUG-KIL-00092`.

### Low — PSNR summary accepts a non-finite test sample

`crates/rvp9-harness/src/bdrate.rs:221` validates the reference interpolation
but subtracts the rvp9 PSNR without validating it. A covered `NaN` or infinite
sample returns a present summary with non-finite statistics.

Concrete fix: validate the complete rvp9 curve and return no signal for invalid
samples, with `NaN` and infinity regressions. Tracked as
`RVP9-BUG-KIL-00087`.

### Low — frame-diff diagnostics index beyond visible edges

`crates/rvp9-harness/src/bin/dump_frame_diff.rs:219` unconditionally dumps a
12×8 luma window. Lines 290-324 dump a full 4×4 block even when the ceiling-
divided block grid ends in a partial visible block. Small frames or a mismatch
at a non-multiple-of-four edge can panic.

Concrete fix: clip every diagnostic loop to visible dimensions and add small
and odd-size fixtures. Tracked as `RVP9-BUG-KIL-00088`.

### Low — duplicate F.0.2 fields use last-value-wins parsing

The assignments at `crates/rvp9-harness/src/f02_schema.rs:119` do not track
whether a known key already occurred. A malformed sidecar can repeat an
identity or decision field and silently replace the first value before strict
comparison.

Concrete fix: reject a second occurrence of every known field and cover both an
identity key and a decision key. Tracked as `RVP9-BUG-KIL-00090`.

### Low — unreadable LLDs disappear from a successful format check

`crates/rvp9-harness/src/bin/check_lld_format.rs:195` flattens directory-entry
errors, and lines 206-209 only warn on file-read errors. The exit decision at
line 224 considers only reports that were read successfully.

Concrete fix: make enumeration and read errors fail the command, and require an
accounted-for report for every candidate file. Tracked as
`RVP9-BUG-KIL-00091`.

## Not reported as new bugs

- **Unverified:** `--fixed-q 0` is accepted by the harness while the rvp9
  encoder source ignores a zero environment override and clamps its selected
  qindex to one. The exact libvpx CLI-to-internal-q mapping was not established
  within this read-only slice, so this remains `NEEDS_REVERIFY` and was not
  filed.
- **Existing record:** seconds-granularity F.0.2 run directories and the
  unbounded child process are covered by open `RVP9-BUG-KILN-00064`.
- **Existing record:** threaded F.0.2 sink loss is covered by open
  `RVP9-BUG-FLUX-00016`.
- **Refuted:** `check-lld-format` intentionally treats line count, citation
  count, and an empty section 7 as diagnostics; its documented exit contract
  fails only on missing required sections. Only unreadable-input omission was
  filed.
- **Refuted:** whole-file and retained-record memory observations did not
  establish a violated bound. `diff-bitstream --max-frames` bounds its reads;
  the uncapped default and the other tools are explicit local diagnostics.
- **Refuted:** local path, JSONL, and MD5 resource-exhaustion concerns require
  treating the user's own selected diagnostic inputs as hostile. No trust
  boundary or violated size contract was found.
- **Held as design debt:** authenticating every conformance filename inside
  `conformance_scope` duplicates the pinned fetch script's manifest/checksum
  role; the current scope checker is count-and-capability based by design.
