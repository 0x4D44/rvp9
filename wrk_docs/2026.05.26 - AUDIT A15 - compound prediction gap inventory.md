## 1. Frame-level compound gating and reference-mode policy

### `vp9_compound_reference_allowed`
**Status: NOT PORTED.** libvpx (`vp9_pred_common.c:16-22`) returns 1 if any non-LAST reference has a sign-bias different from LAST — i.e. compound is structurally legal for this frame. Called once per encoded frame from `vp9_encodeframe.c:6288`. rvp9 has no equivalent gate. The encoder's frame-loop unconditionally sets `reference_mode = ReferenceMode::Single` (lib.rs:446, 598, 764, 792; frame_loop.rs:1560, 1748, 1777), so the gate is moot for now but must exist before any compound is emitted.

### `vp9_setup_compound_reference_mode`
**Status: PORTED** (decoder-shared, reused by encoder for harness purposes). `inter/mode_info.rs:738-760` mirrors `vp9_pred_common.c:24-40` faithfully. Currently invoked at `lib.rs:788` and `frame_loop.rs:1768` to populate `InterModeReadParams.{comp_fixed_ref, comp_var_ref}` even though the encoder always uses `ReferenceMode::Single` — call site documents the dummy-init pattern.

### `allow_comp_inter_inter` flag
**Status: NOT PORTED.** Per-frame boolean in `VP9_COMP` (`vp9_encoder.h:841`) set by `vp9_encodeframe.c:6287-6294`. Read by `vp9_rdopt.c::handle_inter_mode` caller (`vp9_rdopt.c:3748`, `4428`), pickmode RT (`vp9_pickmode.c:2102`), and bitstream writer (`vp9_bitstream.c:1348`). No counterpart in `crates/rvp9-encoder/`.

### `reference_mode` decision (`SINGLE_REFERENCE` / `COMPOUND_REFERENCE` / `REFERENCE_MODE_SELECT`)
**Status: PARTIAL.** Decoder/writer wire-format supports all three (`bitstream/compressed_header.rs:521-545`, `inter/mode_info.rs:1014-1026`). Encoder hard-codes Single. libvpx (`vp9_encodeframe.c:6309-6324`) decides based on prior-frame `prediction_type_threshes`, `comp_pred_diff` history, `check_dual_ref_flags`, and `static_mb_pct == 100`. rvp9 has neither the threshold state nor the rollup.

### `comp_pred_diff[REFERENCE_MODES]` rollup
**Status: NOT PORTED.** `RD_COUNTS::comp_pred_diff` (`vp9_encoder.h:378-380`) accumulates per-MB `single_pred_diff`, `comp_pred_diff`, `hybrid_pred_diff` from each `PICK_MODE_CONTEXT` (`vp9_encodeframe.c:1879-1881`). Drives the next-frame `reference_mode` decision via `mode_thrs[i] = (mode_thrs[i] + rdc->comp_pred_diff[i] / cm->MBs) / 2` (`vp9_encodeframe.c:6338`). No structure or wiring in rvp9.

### `{single,comp,hybrid}_pred_diff` per-block context
**Status: NOT PORTED.** `vp9_context_tree.h:50-52` declares the per-block slots; `vp9_rdopt.c:2503-2505` populates them from the `best_pred_rd[]` array in the mode loop. Absent in rvp9 — `PickedInterMode` / pick context structures carry only the chosen mode's rate/dist, no per-reference-mode RD spread.

### `prediction_type_threshes`
**Status: NOT PORTED.** Indexed `rd_opt->prediction_type_threshes[frame_type][REFERENCE_MODES]` and persists across frames (`vp9_encodeframe.c:6310, 6337-6338`). No equivalent in `rvp9-encoder`.

### Post-frame `reference_mode` fallback
**Status: NOT PORTED.** After encoding in `REFERENCE_MODE_SELECT`, libvpx counts `comp_inter[]` totals; if either `comp_count_zero == 0` (no single picks) or `single_count_zero == 0` (no compound picks) it collapses `reference_mode` to the unanimous side (`vp9_encodeframe.c:6343-6359`, mirrored at 6405-6419 for the non-update path). rvp9 has no Select path so no fallback is needed yet, but the policy must land alongside the Select gating.

## 2. RDO compound mode evaluation (`handle_inter_mode` / `rd_pick_inter_mode_sb`)

### `estimate_ref_frame_costs` (ref-frame signaling costs)
**Status: NOT PORTED.** `vp9_rdopt.c:2430-2488` returns three arrays: `ref_costs_single[MAX_REF_FRAMES]`, `ref_costs_comp[MAX_REF_FRAMES]`, and `comp_mode_p`. Branches on `cm->reference_mode`. rvp9's encoder constructs ref cost approximations inside `mode_decision/rd_thresh.rs` but for single-ref only; there is no `ref_costs_comp` and no `comp_mode_p` plumbing.

### `handle_inter_mode` compound branches
**Status: NOT PORTED.** `vp9_rdopt.c:2812-3265` has dozens of `if (is_comp_pred)` branches: NEWMV joint search dispatch (2877-2916), 2-ref MV clamp (2946), compound prediction build (compound MC inside the filter loop), `intpel_mv &= !mv_has_subpel(&mi->mv[1].as_mv)` (3001), per-ref filter-cache, etc. rvp9's `pick_inter_mode_luma` explicitly comments (inter.rs:36-37) "no compound prediction".

### Compound NEWMV `single_newmv` seeding
**Status: NOT PORTED.** `vp9_rdopt.c:2891-2898` initializes the compound NEWMV from the single-ref NEWMV cache (`single_newmv[refs[0]]` and `single_newmv[refs[1]]`) so the joint search starts at the best single-ref winners. Without this cache (and the single-ref iteration that fills it), compound joint search has no warm start. rvp9 has no `single_newmv` cache.

### `joint_motion_search`
**Status: NOT PORTED.** `vp9_rdopt.c:1907-2075` — alternating-reference iterative refinement (up to 4 iters). Even iters search ref 0; odd iters search ref 1; at each iter it builds a `second_pred` for the held ref, then runs `vp9_refining_search_8p_c` against the average + `find_fractional_mv_step` with `second_pred`. ~170 LOC, no analog in `mv_search/`.

### `get_joint_search_iters` (speed-feature dispatch)
**Status: NOT PORTED.** `vp9_rdopt.c:1895-1905` returns 0/2/MAX_JOINT_MV_SEARCH_ITERS depending on `comp_inter_joint_search_iter_level` (`vp9_speed_features.{c,h}`). Lives entirely in libvpx.

### `skip_iters` (joint-search early exit)
**Status: NOT PORTED.** `vp9_rdopt.c:1837-1855` returns 1 if both refs' MVs are unchanged from the previous iter (with full-pel comparison on the "other" ref). Trivial to port, but only valuable if joint_motion_search is ported first.

### `vp9_refining_search_8p_c` (small-range refining search vs average prediction)
**Status: NOT PORTED.** `vp9_mcomp.c:2825-2890`. 8-point neighborhood SAD against an averaged second_pred buffer. Needs an SDAF (SAD-against-average-frame) kernel; rvp9's SAD kernels are single-ref only (`dsp::sad*`).

### `vp9_get_mvpred_av_var`
**Status: NOT PORTED.** `vp9_mcomp.c:1480-1530`. Variance against averaged predictor. Needs `subpel_avg_variance` family SIMD; rvp9 only has the single-ref `subpel_variance` family.

### `find_fractional_mv_step` `second_pred` parameter
**Status: PARTIAL.** rvp9's sub-pixel search (`crates/rvp9-core/src/mv_search/sub_pixel.rs`) implements the single-ref pyramid faithfully but takes no `second_pred` argument. libvpx threads `second_pred` and `pw, ph` through the same function (`vp9_rdopt.c:2039-2043`), switching the variance kernel from `vfp->svf` to `vfp->svaf` when non-NULL.

## 3. Mode iteration / skip masks

### `vp9_mode_order` compound entries
**Status: NOT PORTED.** `vp9_rdopt.c:107-118` lists 6 compound entries (`{NEAREST/NEAR/NEW/ZERO} × {LAST,GOLDEN}+ALTREF`) interleaved with intra modes. Compound iteration depends on the canonical `MAX_MODES`-sized table; rvp9's picker iterates `[ZERO, NEAREST, NEAR, NEW]` only.

### Compound `ref_frame_skip_mask[1]` / `SECOND_REF_FRAME_MASK`
**Status: NOT PORTED.** Two-element mask in `vp9_rdopt.c:3480-3568` (init) and `3685-3686` (consume). Encodes second-ref-frame allowance per-mode. rvp9 has no such mask.

### Sign-bias compound skip
**Status: NOT PORTED.** `vp9_rdopt.c:3750-3752, 4430-4432`: skip compound if `sign_bias[ref_frame] == sign_bias[second_ref_frame]`. Required for bitstream conformance (compound only legal between opposite-bias refs). The sign-bias table itself is populated by the encoder (lib.rs:787) but never checked for compound legality.

### `FLAG_SKIP_COMP_BESTINTRA`
**Status: NOT PORTED.** `vp9_rdopt.c:3762-3764`: when best so far is INTRA, skip compound. Speed-feature gate; only meaningful once compound is enabled.

### `compmode_cost`
**Status: NOT PORTED.** `vp9_rdopt.c:3874-3876`. Bit cost of the `comp_inter` flag added to `rate2` when `reference_mode == REFERENCE_MODE_SELECT`. Without this rvp9 cannot correctly rate-cost a compound block even if the picker produced one.

### `ref_costs_comp` (consumed)
**Status: NOT PORTED.** `vp9_rdopt.c:3881-3885`. Consumes the array produced by #9. Compound block's reference-frame signaling cost.

### `best_pred_rd[REFERENCE_MODES]` tracking
**Status: NOT PORTED.** `vp9_rdopt.c:4030-4049` maintains per-reference-mode best RD across the mode loop, decomposing each candidate's `rate2` into `single_rate` vs `hybrid_rate`. Drives `best_pred_diff` (4142-4147) consumed by `store_coding_context` (2492-2505) → `comp_pred_diff` rollup → next-frame `reference_mode` decision.

### NEWMV → {NEAREST/NEAR/ZERO} demotion (compound branches)
**Status: NOT PORTED.** `vp9_rdopt.c:4085-4104`. If best NEWMV matches NEARESTMV/NEARMV/ZEROMV on BOTH refs (`comp_pred_mode && frame_mv[NEARESTMV][refs[1]] == best_mbmode.mv[1]`), demote to the cheaper mode. The compound branches of this demotion are absent (the single-ref branches are also absent in rvp9's picker — covered by A1).

## 4. Sub-8x8 compound

### `rd_pick_inter_mode_sub8x8` compound iteration
**Status: NOT PORTED.** `vp9_rdopt.c:4296-4847` runs the full mode loop for sub-8 partitions with compound entries (`vp9_ref_order[3..4]`). ## 6. MC blend layer

### `build_inter_predictors` compound loop
**Status: PARTIAL.** Decoder-side compound MC blend exists at `crates/rvp9-decoder/src/reconstruct_inter.rs:303-477` (the `r > 0 ⇒ is_compound_avg=true` path matches libvpx `vp9_reconinter.c:126-207`). However:
- The encoder has no symmetric `build_inter_predictors_*` consumer at mode-decision time. libvpx's `handle_inter_mode` calls `vp9_build_inter_predictors_sby/sbuv/sb` (`vp9_reconinter.c:236-256`) inside the filter/RD loop to materialize the predicted block — the same function transparently handles compound via the `1 + is_compound` loop. rvp9's encoder calls `crates/rvp9-core/src/inter/scale.rs` / `inter/filter.rs` directly with single-ref assumptions.
- Verified the encoder's call to the convolve kernels at `crates/rvp9-encoder/src/lib.rs:4688` passes `is_compound_avg = false` literally — no compound averaging is ever invoked at encode time.

### Encoder `pred_sse[MAX_REF_FRAMES]`
**Status: PARTIAL.** libvpx `vp9_block.h:108` carries per-ref SSE used by the compound NEWMV seed cache and the `reference_masking` speed feature. rvp9 carries per-block SSE only for the chosen single ref (no per-ref dictionary).

## 7. Bitstream-side (cross-zone A6)

### Compound write gate in uncompressed header
**Status: PARTIAL (cross-zone A6).** `vp9_bitstream.c:1348` emits the `reference_mode` bits only when `cpi->allow_comp_inter_inter`. rvp9's writer machinery (`bitstream/modes_writer.rs:1018-1053` for per-block, `bitstream/compressed_header.rs:521-545` for frame-level) supports the compound writes but the encoder never sets `reference_mode != Single` (lib.rs:446, 598, 764, 792; frame_loop.rs:1560, 1748, 1777). Flagged as a cross-zone reference; the per-block compound write path is well-covered by writer tests (modes_writer.rs:5215-5365 round-trips compound ZEROMV / NEWMV / Select+compound / Compound+SwitchableFilter) but is never driven from the encoder picker.

## Cross-cutting gaps

### Encoder has no compound producer at all
The `ReferenceMode` enum, the compound MC blend, the compound bitstream write path, the compound MV reader, the compound MV ref context functions (`get_pred_context_comp_ref_p`, mode_info.rs:328-410), and the compound prob slots (`comp_inter`, `comp_ref` in `FrameCounts`, adapt.rs:239-308) are ALL implemented on the decoder/writer side. The full producer side (picker + RD loop + frame-level policy + joint motion search + average-prediction MC kernels) is the entire gap. Closing A15 means adding the producer; it does not require touching the wire-format infrastructure.

### Compound depends on ALTREF (A16)
libvpx's compound modes pair LAST/GOLDEN with ALTREF (sign-bias-opposite). With ALTREF construction absent (A16 scope), compound has at most LAST+GOLDEN pairings which, depending on the GF/altref-gf-group state, may be ineligible per the sign-bias rule (vp9_rdopt.c:3750-3752). Compound is effectively gated on A16 landing first.

### Compound needs the SDAF / SVAF SIMD kernel families
`vp9_refining_search_8p_c` and `vp9_get_mvpred_av_var` consume `fn_ptr[bsize].sdaf` (SAD against averaged frame) and `fn_ptr[bsize].svaf` (sub-pixel variance against averaged frame) function-pointer slots. rvp9 ships only the single-ref `sad` and `subpel_variance` families. Roughly 1500 LOC of new SIMD across SSE2/SSSE3/SSE4/AVX2 to match libvpx coverage.

### Compound interacts with `single_newmv` cache (A1 plumbing)
Compound NEWMV joint search seeds from `single_newmv[refs[0..1]]` populated during the single-ref iteration that ran earlier in the same mode loop. rvp9's picker has no `single_newmv[MAX_REF_FRAMES]` cache (each candidate's NEWMV is consumed locally). Adding this cache is small (~10 LOC) but it's a structural change to the picker call sequence — multi-ref iteration must precede compound iteration in the mode_map.

## Conclusion

**Gap counts:** 30 rows total → 1 PORTED, 6 PARTIAL, 23 NOT PORTED, 0 OUT OF SCOPE.

**Row-count sanity check:** expected 9-14 (0.21 × 45 baseline scale); actual 30. Above the upper band. Justified above: compound spans three discrete codepaths (RDO `handle_inter_mode`, RDO sub-8, RT `vp9_pick_inter_mode`) plus a frame-loop policy layer plus an MC-blend layer, and each carries distinct helpers with separate libvpx citations. Reducing the count would require collapsing multiple distinct helpers under one row, which contradicts the "one row per helper" rule.

**Cross-zone dependencies flagged for master inventory:**
- A1 (pick_inter_mode): the `single_newmv[MAX_REF_FRAMES]` cache must be added to the picker context before compound joint search can seed.
- A6 (bitstream packing): compound writer machinery exists and is exercised by writer round-trip tests; only the encoder-side `allow_comp_inter_inter` gate + `reference_mode` selection are missing. Compound's wire-format side belongs to A6 in the master inventory but every item is enumerated here.
- A7 (speed features): `comp_inter_joint_search_iter_level`, `use_compound_nonrd_pickmode` are speed-feature-defined; defaults need to land alongside the compound paths.
- A13 (RDO mode-decision): A15 is effectively a subset of A13. Compound RDO is unreachable without the larger A13 RDO path.
- A14 (sub-8x8 picker): P15 is gated on A14.
- A16 (ALTREF / temporal filtering): P0 — compound is mostly LAST/GOLDEN + ALTREF; without ALTREF the sign-bias gate blocks compound entirely.

**Recommended Phase-2 sequencing:** A16 first (ALTREF), then A13 (RDO baseline including handle_inter_mode), then A15's Tier 0 → Tier 1. Sub-8 compound (P15) follows A14. RT compound (P12) is optional and only valuable if `REFERENCE_MODE_SELECT` is active at RT speeds.
