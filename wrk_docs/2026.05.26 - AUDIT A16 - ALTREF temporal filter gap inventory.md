## 1. Top-level driver and gating

### `vp9_temporal_filter` driver (vp9_temporal_filter.c:1104-1205)
The public entry point. Computes adjusted `arnr_frames` / `arnr_strength` (via `adjust_arnr_filter`), fills `arnr_filter_data->frames[]` from `vp9_lookahead_peek`, sets up `scale_factors` (separate SVC path at 1140-1180 for resolution-scaled refs vs non-SVC native-size at 1183-1192), initializes `set_error_per_bit` + `vp9_initialize_me_consts` at `ARNR_FILT_QINDEX = 128`, then dispatches to single-threaded `temporal_filter_iterate_c` (1202) or row-MT `vp9_temporal_filter_row_mt` (1204).
**Status: NOT PORTED.** rvp9 has no `vp9_temporal_filter` analog; grep for `temporal_filter`, `arnr`, `arf_construct` across `crates/` returns only RefFrame enum / decoder dump usage.

### `is_altref_enabled` (vp9_encoder.h:1422-1427)
Three-way gate: `mode != REALTIME && rc_mode != VPX_CBR`, AND `lag_in_frames ≥ MIN_LOOKAHEAD_FOR_ARFS=4`, AND `enable_auto_arf`. Drives both ARF source selection in encoder.c:6052 and GF-group ARF planning in firstpass.c:2710.
**Status: NOT PORTED.** No `is_altref_enabled` predicate or equivalent in rvp9; `enable_auto_arf` config field absent.

### `get_arf_src_index` (vp9_encoder.c:6049-6063)
Returns the lookahead distance of the ARF source. 2-pass: reads `gf_group.arf_src_offset[gf_group.index]` when `update_type[index] == ARF_UPDATE`. 1-pass: returns `frames_till_gf_update_due` when `rc->source_alt_ref_pending`. 0 means "no ARF this frame".
**Status: NOT PORTED.** rvp9 has no lookahead-distance ARF index logic; cross-zone with A19 (lookahead pipeline).

### ARF-source dispatch (vp9_encoder.c:6432-6474)
The encoder's recode loop top-level: peeks `lookahead[arf_src_index]`, sets `cpi->alt_ref_source`, runs `vp9_temporal_filter(cpi, arf_src_index)` + `vpx_extend_frame_borders(&cpi->alt_ref_buffer)`, optionally `vp9_alt_ref_aq_setup_mode`, then flips `force_src_buffer = &cpi->alt_ref_buffer`, `show_frame=0`, `refresh_alt_ref_frame=1`, clears `is_src_frame_alt_ref` / `source_alt_ref_pending`.
**Status: NOT PORTED.** rvp9's frame_loop.rs has no equivalent ARF intercept; encoding proceeds frame-by-frame from the show-source.

### `check_src_altref` (vp9_encoder.c:6065-6086)
Called when a normal source is read; sets `rc->is_src_frame_alt_ref` true when this source is the ARF overlay (2-pass: `gf_group.update_type == OVERLAY_UPDATE`; 1-pass: `source == cpi->alt_ref_source`). Overlay frames disable `refresh_last_frame` so LAST is preserved as alternate prediction.
**Status: NOT PORTED.** `is_src_frame_alt_ref` is referenced 13 times across libvpx encoder.c (829, 1233, 2190, 3221, 3355, 3369, 3425, 4824, 4904, 4936, 6071-6078, 6469); none of these gates exist in rvp9.

## 2. Per-frame ARF construction loop

### `temporal_filter_iterate_c` / `_tile_c` / `_iterate_row_c` (vp9_temporal_filter.c:645-1028)
The full work: for each `mb_row` × `mb_col_start..mb_col_end`, zero `accumulator[BLK_PELS*3]` + `count[BLK_PELS*3]`, then loop `frame=0..frames_to_blur-1` running MC + filter accumulation, finally normalize `(accumulator[k] + count[k]/2) * fixed_divide[count[k]] >> 19` into `cpi->alt_ref_buffer.{y,u,v}_buffer`. MV-limit setup clamps row/col with the TF-specific 17 − 2·VP9_INTERP_EXTEND border (697-711). Handles VP9E_CONTENT_FILM low-variance strength reduction (713-734), the alt-ref self-anchor (frame == alt_ref_index ⇒ blk_fw = {2,2,2,2}, use_32x32=1; 752-754), and the 32x32 vs 4×16x16 use_32x32 decision via the err/err16 ratio + max−min split (766-790), capped by frame-distance (792-799).
**Status: NOT PORTED.** No analog in rvp9; the entire 350-LOC per-row driver is absent.

### `temporal_filter_find_matching_mb_c` (vp9_temporal_filter.c:552-643)
Runs `vp9_full_pixel_search` with `search_method = MESH` (and `search_method_16 = cpi->sf.temporal_filter_search_method`) on the 32x32 block, then sub-pel refine via `cpi->find_fractional_mv_step` at `USE_8_TAPS_SHARP`, then repeats per 4×16x16 sub-block. Step_param = `mv_sf->reduce_first_step_size` clamped to `MAX_MVSEARCH_STEPS-2`. Saves/restores `x->plane[0].src` and `xd->plane[0].pre[0]`.
**Status: NOT PORTED.** Cross-zone with A1 (`vp9_full_pixel_search` mesh method = PARTIAL: rvp9 only has the diamond method per picker-inventory row 5). The MESH search method and the dual 32x32 + 4×16x16 fan-out are both absent.

### `temporal_filter_predictors_mb_c` (vp9_temporal_filter.c:48-186)
Builds Y/U/V inter predictors for a 32x32 block (or 4 × 16x16 sub-blocks when `use_32x32 == 0`) using `EIGHTTAP_SHARP` kernel (8-tap sharp filter — different from the encoder default `EIGHTTAP`). UV uses `MV_PRECISION_Q4` when uv_block_width = BW/2 (subsampled), else `MV_PRECISION_Q3`. HBD branch via `vp9_highbd_build_inter_predictor`.
**Status: NOT PORTED.** rvp9 has inter-pred infrastructure (`crates/rvp9-core/src/inter/`) but no TF-side caller; the `EIGHTTAP_SHARP` filter selection at ARF-construction time is not exposed.

## 3. Non-local means filter (the actual blur)

### `vp9_apply_temporal_filter_c` (vp9_temporal_filter.c:260-399)
The NLM core. For each pixel: compute squared diff `y_diff_sse[i,j] = (src - pred)^2` (Y) and `u/v_diff_sse` (UV). Then for each Y pixel: sum `y_diff_sse` over the 3×3 neighbourhood (clipped at borders, y_index counts valid neighbours), add `u_diff_sse[uv_r,uv_c]` and `v_diff_sse[uv_r,uv_c]` to `modifier` (y_index += 2), then `mod_index(modifier, y_index, rounding, strength, filter_weight) → y_count[k] += mod; y_accumulator[k] += mod * pred_pixel`. Chroma path mirrors but also folds in the corresponding Y squared diffs (375-383). Asserts `strength ∈ [0,6]`.
**Status: NOT PORTED.** The NLM kernel does not exist anywhere in rvp9; no analog of `y_diff_sse` accumulator, no `mod_index` weighting.

### `vp9_highbd_apply_temporal_filter_c` (vp9_temporal_filter.c:402-550)
HBD variant. Diffs are stored in `uint32_t` (vs `uint16_t` for low-bit-depth). `adj_strength = strength + 2*(bd-8)` is applied at the call site (815-823). Cross-zone with A20 (HBD).
**Status: NOT PORTED.** No HBD path; cross-zone with A20.

### `mod_index` / `highbd_mod_index` (vp9_temporal_filter.c:195-213, 216-234)
Maps `sum_dist` → filter modifier. Formula:
```
mod = (clamp(sum_dist, 0, UINT16_MAX) * index_mult[index]) >> 16;
mod = (mod + (1<<strength)/2) >> strength;
mod = min(16, mod);
mod = (16 - mod) * filter_weight;
```
`index_mult[14] = { 0, 0, 0, 0, 49152, 39322, 32768, 28087, 24576, 21846, 19661, 17874, 0, 15124 }` — a fixed-point reciprocal LUT keyed by neighbour-count (5..13).
**Status: NOT PORTED.** No mod_index/index_mult equivalent.

### `get_filter_weight` (vp9_temporal_filter.c:236-258)
Returns one of `blk_fw[0..3]` based on (i, j) quadrant; degenerates to `blk_fw[0]` when `use_32x32==1`.
**Status: NOT PORTED.**

### `fixed_divide[512]` + `vp9_temporal_filter_init` (vp9_temporal_filter.c:36, 188-193)
`fixed_divide[i] = 0x80000 / i` for i ∈ [1, 511]. Used at output normalization: `pval = (acc + count/2) * fixed_divide[count] >> 19`. Avoids per-pixel division.
**Status: NOT PORTED.** `vp9_temporal_filter_init` is called from `vp9_create_compressor` in libvpx; rvp9 has no equivalent init hook.

## 4. Filter-weight decision logic (the quality knobs)

### use_32x32 vs 4×16x16 selection (vp9_temporal_filter.c:766-790)
Computes `err` (32x32 SAD) and `err16 = sum of 4 sub-block SADs`. If `(err*15 < err16*16 AND max_err-min_err < 10000)` OR `(err*14 < err16*16 AND max_err-min_err < 5000)`, use_32x32=1 with weight tier from `err` vs `thresh_low<<THR_SHIFT (10000<<2) / thresh_high<<2 (20000<<2)` → blk_fw ∈ {0, 1, 2}. Otherwise use_32x32=0 with per-sub-block weight from `blk_bestsme[k]` vs raw `thresh_low/high (10000/20000)`.
**Status: NOT PORTED.** The dual-granularity decision and the err / err16 hysteresis are the **dominant ARF-quality knob**; getting this wrong destroys ARF efficacy.

### Frame-distance weight cap (vp9_temporal_filter.c:792-799)
`switch (abs(frame - alt_ref_index)) { case 1: cap=2; case 2,3: cap=1; default: 0 }` — limits how far the filter can pull from frames far from the ARF anchor.
**Status: NOT PORTED.**

### ALTREF self-anchor (vp9_temporal_filter.c:752-754)
When iterating the ARF-anchor frame itself, blk_fw = {2,2,2,2}, use_32x32 = 1, ref_mv = 0. Always present.
**Status: NOT PORTED.**

### VP9E_CONTENT_FILM strength reduction (vp9_temporal_filter.c:713-734)
For film content with src variance ≤ 2 (very flat), reduce strength by 2 (floored at 0). Preserves grain on flat blocks.
**Status: NOT PORTED.** Cross-zone with A12 (`content` config knob).

### `adjust_arnr_filter` (vp9_temporal_filter.c:1031-1102)
Computes effective `arnr_frames` (frames_bwd + 1 + frames_fwd, with even-length asymmetry: `bbbAff` for len=6, `bbbAfff` for len=7) and `arnr_strength` from `oxcf.arnr_strength + cpi.twopass.arnr_strength_adjustment` (2-pass), clamped to [0,6]. Strength scaled by avg q (q≤16 ⇒ reduce). Both capped by `group_boost`: `frames ≤ group_boost/150`, `strength ≤ group_boost/300`. Skip-filter (frames=1) for intermediate ARFs whose `arf_src_offset < baseline_gf_interval-1`.
**Status: NOT PORTED.** Cross-zone with A3 (rate control: needs `gfu_boost`, `avg_frame_qindex`).

## 5. ALT_REF_AQ (segmentation-on-ARF)

### `vp9_alt_ref_aq_*` (vp9_alt_ref_aq.c:14-63)
**Important:** libvpx itself ships these as **no-op stubs**: `struct ALT_REF_AQ { int dummy; }` and every function body is `(void)self; (void)cpi;`. The 127-LOC header documents an API that was never implemented (`alt_ref_aq_private.h` referenced in the comment block does not exist in the tree). Faithful-port parity therefore requires only the call-site dispatch shells in `vp9_encoder.c:2435, 2893, 4218, 4664, 5250, 5916, 6458` and a stub struct — not a real segmentation backend.
**Status: NOT PORTED.** The dispatch sites and stub struct are missing from rvp9. Quality impact is **low** (libvpx itself does nothing here) but counts as a faithful-port gap because the call sites must exist for source-line parity with libvpx encoder.c.

### `alt_ref_aq` config field + ctrl (vp9_cx_iface.c:56, 95, 626, 1044-1047, 2079)
Default 0 (off). `VP9E_SET_ALT_REF_AQ` ctrl toggles. Even when on, libvpx's stub is a no-op so behaviour is identical to off.
**Status: NOT PORTED.** Cross-zone with A12.

## 6. Threading and SIMD

### `vp9_temporal_filter_row_mt` (vp9_ethread.c:547-583)
Row-MT ARF construction. Builds `ARNR_JOB` queue, launches `temporal_filter_worker_hook` (vp9_ethread.c ~510-545) which loops `vp9_temporal_filter_iterate_row_c` per job. Gated by `cpi->row_mt` at vp9_temporal_filter.c:1201.
**Status: NOT PORTED.** rvp9's `arnr_filter_data` and ARNR_JOB queue don't exist; cross-zone with A2 (frame-loop driver / row-MT infra).

### x86 SIMD (`temporal_filter_sse4.c` + `highbd_temporal_filter_sse4.c`)
1768 LOC total of SSE4.1 vectorized NLM (`vp9_apply_temporal_filter_sse4_1`, `vp9_highbd_apply_temporal_filter_sse4_1`). Function-pointer dispatch via `vpx_dsp_rtcd`.
**Status: NOT PORTED.** SIMD is downstream of the C reference port. Quality-neutral when C reference is present; perf delta is significant for ARF-heavy encodes.

### NEON SIMD (`vp9_temporal_filter_neon.c`, `vp9_highbd_temporal_filter_neon.c`)
**Status: OUT OF SCOPE.** Justification: ARM SIMD is out of scope per Arthur 2026-05-25 (GOAL doc line 158).

### `define_gf_group` ARF planning (vp9_firstpass.c:2692-2966)
Sets `rc->source_alt_ref_pending`, `rc->source_alt_ref_active`, `rc->gfu_boost`, `rc->baseline_gf_interval`, and `gf_group->update_type[*] = ARF_UPDATE / OVERLAY_UPDATE`. The TF driver reads `gfu_boost` (via `adjust_arnr_filter`) and `gf_group.arf_src_offset[index]` (via `get_arf_src_index`).
**Status: NOT PORTED.** Cross-zone with A3 (rate control 2-pass).

### `cpi->alt_ref_buffer` (vp9_encoder.c:1041, 1298-1306)
A YV12 buffer at native frame size, allocated in `vp9_alloc_compressor_data` with `VP9_ENC_BORDER_IN_PIXELS=32` border. TF writes filtered Y/U/V here; the encoder then encodes from `force_src_buffer = &cpi->alt_ref_buffer`.
**Status: NOT PORTED.**

### `arnr_max_frames` / `arnr_strength` / `arnr_type` config (vp9_cx_iface.c:43-95, 600-626, 280-281)
Defaults: 7 / 5 (clamped to ≤ 6 by RANGE_CHECK_HI at validation — note the asymmetry: default value 5 ≤ max 6, but max_frames default 7 ≤ max 15). `arnr_type` ctrl exists (VP8E_SET_ARNR_TYPE at 977) but the OXCF field is unused in libvpx ≥ recent.
**Status: NOT PORTED.** Cross-zone with A12 (CLI defaults).

## Cross-cutting gaps

### G1. Entire ARF lifecycle absent
The faithful-port surface area is the full lifecycle:
1. **Detection** (`is_altref_enabled` + `get_arf_src_index`) — decides "this frame slot is an ARF".
2. **Source aggregation** (`vp9_lookahead_peek` × `frames_to_blur`) — gathers the window of source frames.
3. **Filter computation** (`vp9_temporal_filter` → ME × NLM × normalize) — produces the blurred YUV.
4. **Encoder intercept** (`force_src_buffer = alt_ref_buffer`, `show_frame=0`, `refresh_alt_ref_frame=1`) — encodes the synthetic frame.
5. **Overlay handling** (`check_src_altref` → `is_src_frame_alt_ref`) — when the real source matching the ARF distance comes back, encode it as a show-existing / overlay and don't refresh LAST.

Stages 1-5 are **all absent** in rvp9. The encoder produces no ARF frames at all.

### G2. No `is_src_frame_alt_ref` plumbing
13 sites in libvpx encoder.c read `rc->is_src_frame_alt_ref` to gate rate-control / mode-decision / partition behaviour. rvp9 has zero references to any equivalent flag → all those gates currently take the wrong branch on what would have been overlay frames (because no ARF/overlay frames are produced).

### G3. ARF tuning surface absent from rvp9 config
No `arnr_max_frames`, `arnr_strength`, `enable_auto_arf`, `alt_ref_aq`, `arnr_type` knobs exist in rvp9's CLI / encoder config struct. CLI parity (A12) is blocked on these.

### G4. Lookahead pipeline coupling
The ARF feature requires lookahead. `lag_in_frames ≥ 4` is the gate (MIN_LOOKAHEAD_FOR_ARFS=4). Cross-zone with A19 (lookahead, listed as "absent or partial" in GOAL table).

### G5. SIMD parity
Once C reference is ported, the 1768-LOC SSE4.1 path (Y + UV NLM + HBD) is required for performance parity. Function-pointer dispatch + cpu-detect plumbing must mirror libvpx's `vpx_dsp_rtcd` table for TF.

## Conclusion

**Gap counts:** 34 NOT PORTED rows; 0 PARTIAL; 0 PORTED; 0 OUT-OF-SCOPE. The entire A16 zone is greenfield.

**Cross-zone dependencies flagged for master inventory:**
- **A1 (pickmode)** — `vp9_full_pixel_search` needs the **MESH** search method for `temporal_filter_find_matching_mb_c` (currently only diamond per picker-inventory row 5).
- **A2 (frame-loop driver)** — must intercept at `encode_frame_to_data_rate` to dispatch ARF construction (encoder.c:6432-6474 surface).
- **A3 (rate control)** — `define_gf_group` must set `source_alt_ref_pending`, `gfu_boost`, `gf_group.arf_src_offset[*]`; `is_src_frame_alt_ref` plumbing for 13 read sites in encoder.c.
- **A12 (CLI / config defaults)** — `arnr_max_frames=7`, `arnr_strength=5`, `enable_auto_arf=1`, `alt_ref_aq=0`, plus ctrl-set IDs.
- **A19 (lookahead)** — `vp9_lookahead_peek(distance ≥ 4)` must function for ARF source aggregation.
- **A20 (HBD)** — `vp9_highbd_apply_temporal_filter_c` for profiles 2/3.
- **A18 (SVC)** — `svc.scaled_frames[]` realloc path in TF (vp9_temporal_filter.c:1140-1180).

**Sequencing suggestion:** A3 + A19 are hard prerequisites — without them, A16 has no input and no trigger. Inside A16 itself, P0-P5 (Tier 0 + Tier 1) form a single landable wave because they cannot be tested independently; P6-P10 (Tier 2) layer on top once the base wave passes a bit-exact cross-decoder check; P11-P15 (Tier 3) are performance / HBD / SVC and can land in any order.
