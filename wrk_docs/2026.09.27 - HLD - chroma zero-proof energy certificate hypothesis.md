# Chroma zero-proof energy certificate hypothesis

The current production-PGO profile attributes 1,794/16,158 direct Ducks samples to the inlined early chroma-proof call at `crates/rvp9-encoder/src/lib.rs:11766`. This is source attribution, **not** an estimate of removable CPU. A residual-reuse implementation was exact but 1.1–2.1% slower in two paired screens, so further loop rearrangement has no measured case.

The cross-family consult proposed a sufficient energy check before the TX8/TX4 chroma transforms. Define `T = min_b(ceil(65536 / quant_fp[b]) - round_fp[b])` over DC and AC bands. For a complete 8×8 residual tile, `65 * SSE < (T - 4)^2` implies that its TX8 and all four TX4 transforms fast-quantize to EOB0, **only** under the current 8-bit DctDct/`quant_fp` paths. The certificate must reject `quant_fp == false`, unsupported geometry, nonpositive multipliers, negative rounding, and `T <= 4`; cap the usable `T` at 837 to keep the integer-wrap proof valid even if a caller constructs non-table quantizers. The related Hadamard picker idea remains a separate, untested hypothesis.

The [exact-rational check](evidence/2026-09-27-chroma-energy-census/check-chroma-bound.py) reads the live cosine constants and 8-bit Q tables. The 1-D DCT row-norm bounds give `|TX8 coefficient| <= 2*N8*sqrt(SSE) + B8` and `|TX4 coefficient| <= 4*N4*sqrt(SSE) + B4`; `(2*N8)^2` and `(4*N4)^2` are about 64.003, while `B8=3.656` and `B4=1.192`. Thus the strict predicate keeps every coefficient below `T`. Across all legal 8-bit Q indices and independently clamped DC/AC deltas, `T <= 837`; the admitted `SSE <= 10,675` bounds every residual magnitude by 103. The checked integer intermediates stay below 32,768, so the scalar/SSE2/NEON 16-bit narrowing and saturation points are inert. The scalar/AVX2/NEON fast quantizers then return zero. These equivalences were checked against the current source; the arithmetic script does not execute compiler intrinsics.

The diagnostic [Crucible census](evidence/2026-09-27-chroma-energy-census/README.md) saw 251,653 predicate hits in 304,058 Ducks calls (82.76%), with no disagreements, and 29.72%/36.97% hits on Tree/Town. A deterministic stress oracle ran all 256 Q indices, five residual families, and TX8-only/dual-TX modes on AArch64 and native x86 without a false certificate. These tests support the source-reviewed proof; they cannot replace it. The whole-leaf shortcut is committed on a separate branch and passed deliberate-red exact differentials and canonical output checks. Three paired PGO screens showed an advantage over one control binary, but the [fresh direct comparison](evidence/2026-09-27-chroma-energy-production-pgo/README.md) exposed a larger build-to-build spread in unchanged control code. Code-caused CPU gain is therefore not established, and the shortcut remains unintegrated.

The authoritative PGO source attribution and binary identities are in [the integrated PGO profile](evidence/2026-09-27-current-pgo-ip/README.md). The integrated source's earlier direct result was 1.061826× pinned libvpx equal-clip CPU; a later rebuild of the same encoder source measured 1.102646×. The candidate itself measured 1.065957×. All remain above the ≤1.05× target, and cross-build PGO variability must be resolved before ranking this code.
