# G4 -- Encode Breakout Test

**Date:** 2026-05-24
**Source:** `vp9/encoder/vp9_pickmode.c:933-1036` (`encode_breakout_test`)
**Integration site:** `crates/rvp9-core/src/mode_decision/inter.rs`, `pick_inter_mode` main loop

## 1. What it does

After a candidate's full RD cost is computed, `encode_breakout_test` checks
whether the prediction alone is good enough to skip the residual entirely.
When it fires, the mode loop breaks immediately -- no further candidates
are evaluated.

The test compares the Y-plane `var` and `sse` (already computed by
`model_rd_for_sb_y`) against quantizer-derived thresholds. If Y passes,
it repeats the check on U and V. On full pass: `skip = true`,
`rate = mode_cost_only`, `dist = sse_y << 4`.

## 2. Threshold computation (8-bit, no SVC, no skin)

```
thresh_ac = clamp(dequant_ac^2 >> 3, min_thresh, 36000)
thresh_ac >>= 12 - (bsize.width_log2() + bsize.height_log2())

thresh_dc = dequant_dc^2 >> 6
```

Where `min_thresh = min(encode_breakout << 4, 36000)` and
`encode_breakout` is the per-frame quality knob (typically ~20 for
realtime). The `12 - (w_log2 + h_log2)` shift is the rvp9 equivalent
of libvpx's `8 - (b_width_log2 + b_height_log2)`.

## 3. Pass conditions

**Y plane:**
```
var_y <= thresh_ac  AND  (sse_y - var_y) <= thresh_dc
```

**UV planes** (checked only if Y passes; each independently):
```
(var_u << 2) <= thresh_ac  AND  (sse_u - var_u) <= thresh_dc
(var_v << 2) <= thresh_ac  AND  (sse_v - var_v) <= thresh_dc
```

UV uses the same thresholds as Y (libvpx sets `thresh_ac_uv = thresh_ac`,
`thresh_dc_uv = thresh_dc`; the `sb_is_skin` override zeros them -- we
skip that, no skin detection in rvp9).

## 4. Motion gate

Breakout is suppressed when the MV exceeds +/-64 quarter-pel (8 pixels):
```
if mv.row.abs() > 64 || mv.col.abs() > 64 { return; }
```
This prevents breakout on fast motion where the prediction may drift.

## 5. Proposed function signature

```rust
/// Returns `true` when the block can be encoded with prediction only.
///
/// Port of `encode_breakout_test` (vp9_pickmode.c:933-1036).
/// 8-bit Profile 0 only; no SVC, no skin detection.
pub fn encode_breakout_test(
    var_y: u32,
    sse_y: u32,
    var_u: u32,
    sse_u: u32,
    var_v: u32,
    sse_v: u32,
    dequant_dc: u16,      // Y plane dequant[0]
    dequant_ac: u16,      // Y plane dequant[1]
    bsize: BlockSize,
    mv: Mv,
    encode_breakout: u32, // per-frame quality knob
) -> bool
```

Place in `crates/rvp9-core/src/mode_decision/model_rd.rs` alongside
the other variance-domain utilities it depends on.

## 6. Integration point

Inside `pick_inter_mode`'s `for &(ref_frame, mode) in &RT_INTER_MODES`
loop, **after** the candidate is evaluated and the best-so-far is updated
(line ~817), but **before** the existing `best_rd_cost == 0` early-exit
(line ~822):

```rust
// --- G4: encode breakout test ---
if let Some(ref b) = best {
    if b.picked_ref_frame == ref_frame && b.best_mode == mode {
        // This candidate just became the new best. Check breakout
        // using the model_rd var/sse from the winning evaluation.
        if encode_breakout_test(...) {
            // Overwrite rate to mode-cost-only, dist to sse << 4.
            best = Some(PickInterModeResult {
                best_rate: mode_rate_only,
                best_distortion: sse_y,
                best_rd_cost: rd_cost(lambda, mode_rate_only, sse_y),
                // ... other fields unchanged
            });
            break; // exit the entire mode loop
        }
    }
}
```

**Practical note:** The `var_y` / `sse_y` values come from
`ModelRdResult` which is computed inside `evaluate_candidate_for_filter`.
To surface them at the `pick_inter_mode` level, add `var_y: u32` and
`sse_y: u32` fields to `InterModeSearchResult`. These are already in
`ModelRdResult` -- just thread them through.

For the UV check, the breakout test needs chroma variance/SSE. Two options:

1. **Lazy UV compute** (matches libvpx): only build the chroma prediction
   and compute `(var_u, sse_u, var_v, sse_v)` when the Y test passes.
   Requires the chroma source/ref planes to be available in
   `PickInterModeParams`.
2. **Defer UV** (simpler v1): skip the UV check entirely. Accept a small
   quality risk on chroma-noisy content. Revisit if breakout fires too
   aggressively on chroma edges.

Recommend option 2 for the initial port; add UV gating as a follow-up
if quality data warrants it.

## 7. Result fields when breakout fires

| Field               | Value                                       |
|---------------------|---------------------------------------------|
| `best_rate`         | `inter_mode_cost[ctx][mode] + ref_frame_cost + filter_cost` (no coef, no MV, no skip bit) |
| `best_distortion`   | `sse_y` (raw pixel-domain SSE, not shifted)  |
| `best_rd_cost`      | `rd_cost(lambda, best_rate, best_distortion)` |
| `coef_rate`         | `0`                                          |
| `coef_dist`         | `0`                                          |
| `picked_ref_frame`  | unchanged (whichever ref won)                |
| `picked_intra_mode` | `None`                                       |

The mode loop `break`s immediately. The intra-in-inter fallback
(Phase 2b) is skipped -- breakout means the block is clean enough
that intra cannot improve on the prediction.

## 8. Interaction with skip_txfm

`model_rd_for_sb_y` already sets `SkipTxfm::AcDc` when the residual
quantizes to zero, which triggers the DCT-round-trip short-circuit in
`evaluate_candidate_for_filter` (line 1387). The breakout test is a
**separate, coarser** gate:

- `skip_txfm == AcDc` means "this candidate's residual is zero" but
  the mode loop continues evaluating other candidates.
- Breakout means "this candidate's prediction is so good we stop the
  entire search."

Breakout can fire even when `skip_txfm != AcDc` because the thresholds
are different (dequant-squared vs. zbin-squared). The two mechanisms
are complementary, not redundant.

## 9. Scoping decisions

| Item                        | Decision  | Rationale                                  |
|-----------------------------|-----------|--------------------------------------------|
| SVC gate                    | Omit      | rvp9 has no SVC                            |
| `sb_is_skin` UV override    | Omit      | rvp9 has no skin detection                 |
| `scene_change_detected`     | Omit      | rvp9 has no scene-change detector (yet)    |
| Highbitdepth threshold shift| Omit      | 8-bit Profile 0 only (D-01)               |
| `encode_breakout` knob      | Hardcode  | Use `20` (libvpx default for speed >= 5)   |
| UV variance check           | Defer     | Y-only in v1; add UV follow-up if needed   |

## 10. Testing
