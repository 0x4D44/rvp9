# RVP9 0.2.0-beta.1 qualification contract

Arthur authorized defining a sensible subset, retesting it, fixing findings and cutting the beta on 2026-10-21. This is a beta evaluation release, with no stable production-parity or general WebRTC integration claim. The lead owns integration and publication. Existing full-production qualification remains intact and separate.

## Qualified feature boundary

- Native macOS Apple Silicon and native Windows x86-64 MSVC; portable release binaries built from clean integrated origin/main, with both Cargo Rust flag overrides cleared. Record exact source, compiler, binary and input hashes.
- Encoder: 8-bit profile 0, I420, one-pass realtime CBR, CPU-used 6, 7 and 8, cyclic-refresh AQ3, denoiser off, one temporal/spatial layer, lag zero, keyframe interval 60. These are tested configurations, not a promise for every flag combination.
- Targets: 720p30 / 1 thread / tile-columns 0; 1080p30 / 4 threads / tile-columns 2; 1080p60 / 8 threads / tile-columns 3.
- Every target uses Tree, Ducks and Old Town. The canonical originals are 720p50 scenes; scaling and frame-rate conversion create derived 1080p and 60fps workloads. This release does not claim representative conferencing, screen-sharing, native-1080p60 or broad livestream coverage.
- VBR, AQ0, denoising and temporal/spatial SVC remain available but experimental and outside this qualified beta surface. Frame dropping, external rate-control integration, high bit depth, slow presets, altref and two-pass are deferred.

## Acceptance

1. Full 307-vector/4,816-frame decoder conformance on native and forced-scalar dispatch at one and two threads, independently on both platforms. Encoder32/reverse24 cross-reference gates supplement the scoped beta matrix, without extending beta quality claims.
2. Beta matrix: three CPU configurations x three targets x three scenes = 27 quality curves, six bitrate points each, 162 retained candidate streams, 486 candidate decode runs. Pin libvpx 1.14.1 revision 12f3a2ac603e8f10742105519e0cd03c3b8f71dd. Retain the existing per-target bitrate grids. Each CPU/target arithmetic mean BD-rate must be <=+0.5%; each scene <=+2%. No averaging across CPU/target failures. All candidate streams must have expected frame/byte counts and matching nonempty RVP9/libvpx output; FFmpeg must decode successfully.
3. Nine relative-speed corpus groups: both separate and paired geometric means <=1.05x libvpx, existing one warmup/five pairs/two reversed rotations, host load <=0.75 busy logical cores. Build all tools before acquiring a quiet lease. Resume only sealed complete groups under the existing fingerprint contract.
4. Twenty-seven latency rows, one warmup/five measured runs each: median p50 <=33ms at 30fps or <=16ms at 60fps; median p99 <=50ms or <=25ms respectively; AQ maximum frame <=66ms. Measure actual shipped portable encoder binaries. Disclose reference hardware. Native macOS performance does not establish Windows performance.
5. Exact candidate workspace formatting, Clippy at configured severity, locked release tests, public API docs, scoped safety regression tests, native sanitizer coverage where supported, bounded parser/full-frame fuzz and production-mode encode/decode smoke. Previously approved billion-iteration fuzz/72-hour soak remain deferred. Any unavailable mandatory safety route is reported and resolved explicitly, never treated as a pass.
6. Build/verify the five-package graph; test extracted production archives using the exact candidate siblings; dry-run publication. Extract both CLI archives and run their actual binaries through version and encode/decode checks. Preserve legal notices, build metadata and checksums. Registry downloads and GitHub artifacts must match the published candidate.

## Execution and stopping rules

Retain commands, native host/toolchain, exact source/ref, raw outputs, exit codes, hashes and ignored-test counts under wrk_docs/evidence/2026-10-21-beta. Registered external scratch owns large files/targets. Reproduce a potential defect twice, mint/claim its ledger record, fix with observed red/green regression, and require a different verifier. Requalify affected gates after code changes. A failed gate triggers diagnosis/repair; no threshold or input change to make a failure pass.

Only publish/tag v0.2.0-beta.1 after the required evidence passes. Integration and release publication are authorized by Arthur's instruction. Use the existing manual release lane because deltic release has no prerelease selector and this repo has no release descriptor; preserve the alpha-only packaging guard. Keep this contract and a live journal as the continuation state.
