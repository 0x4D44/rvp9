## Section-by-section narrative

### 0. Cross-cutting prerequisite — sub-8x8 partition leaves are never produced

`vp9_pick_inter_mode_sub8x8` and `vp9_rd_pick_inter_mode_sub8x8` are only invoked from `vp9_encodeframe.c:4694–4695` (`hybrid_intra_mode_search`) and `vp9_encodeframe.c:4761` (`nonrd_pick_sb_modes`), and only when the active partition leaf has `bsize < BLOCK_8X8` (i.e., `BLOCK_4X4`, `BLOCK_4X8`, or `BLOCK_8X4`).

In rvp9 the partition algorithm in `crates/rvp9-core/src/mode_decision/partition.rs:80–122` (F8.2 variance descent) caps leaf sizes at `Block8x8` and explicitly rejects sub-8 leaves at `partition.rs:838–839` ("Block4x8 leaf is illegal in F8.2"). The motion-aware `nonrd_pick_partition` in `crates/rvp9-core/src/mode_decision/nonrd_partition.rs:380–387` (`subsize_for_split`) returns `None` for `Block8x8`, terminating descent. The fallback at `nonrd_partition.rs:372` explicitly comments "(e.g. a future Block4x4 leaf), treat it as Block8x8".

**Consequence:** Even though the rvp9 *bitstream writer* (`crates/rvp9-core/src/bitstream/modes_writer.rs:698–737`, `infer_inter_partition`) can serialise a sub-8 leaf if one is placed in the mi-grid, no upstream code path ever places one there. All 52 rows below are therefore **unreachable** at runtime — but the **scope of A14 is the sub-8x8 picker as a subsystem**, so each missing helper is itemised.

### 1. RT-path entry (`vp9_pick_inter_mode_sub8x8`, pickmode.c:2822–3070)

The realtime sub-8 picker iterates two ref frames (LAST, GOLDEN), and inside each ref frame walks the 4-quadrant 4x4 grid of the 8x8 cell. For each 4x4 block `i` it:

1. Calls `vp9_append_sub8x8_mvs_for_idx` to seed `b_mv[NEARESTMV] / b_mv[NEARMV]` (pickmode.c:2935–2937).
2. Iterates `this_mode = NEARESTMV..NEWMV` (pickmode.c:2939). For NEWMV runs `vp9_full_pixel_search` + `find_fractional_mv_step` (pickmode.c:2962–2988). For all modes builds inter prediction (pickmode.c:2998–3014) and runs `model_rd_for_sb_y` (pickmode.c:3020) for the rate/dist estimate.
3. Accumulates best per-block `bsi[ref_frame][i]` (pickmode.c:3026–3030), propagates the MV across neighbour 4x4s for BLOCK_4X8 / BLOCK_8X4 (pickmode.c:3040–3041).
4. After both refs finish, writes back `mi->ref_frame[0] = best_ref_frame`, `mi->tx_size = TX_4X4`, copies `bsi[best_ref_frame][block]` into `xd->mi[0]->bmi[block]`, and sets `mi->mode = xd->mi[0]->bmi[3].as_mode` (pickmode.c:3051–3063).

**Status: NOT PORTED.** Row #1.

### 2. RDO-path entry (`vp9_rd_pick_inter_mode_sub8x8`, rdopt.c:4285–4922)

This is the `cpu-used 0..4` non-realtime entry. Iterates `MAX_REFS` ref combinations from `vp9_ref_order[]` (rdopt.c:4361, 4374–4375 — includes compound LAST+ALTREF, GOLDEN+ALTREF, LAST+GOLDEN). For each ref-index:

1. Sub-8x8 thresholding via `rd_less_than_thresh` against `thresh_freq_fact[bsize][ref_index]` (rdopt.c:4417–4421).
2. `setup_buffer_inter` for per-ref-frame plumbing (rdopt.c:4351–4352, helper at rdopt.c:2511).
3. For INTRA_FRAME: calls `rd_pick_intra_sub_8x8_y_mode` + `choose_intra_uv_mode` (rdopt.c:4486–4501).
4. For inter: sweeps `SWITCHABLE_FILTERS` (4 filters: EIGHTTAP, EIGHTTAP_SMOOTH, EIGHTTAP_SHARP, BILINEAR) and per filter calls `rd_pick_best_sub8x8_mode` (rdopt.c:4567–4571), then `super_block_uvrd` for UV residual (rdopt.c:4668–4669), then skip-flag tie-break (rdopt.c:4711–4730), then `store_coding_context` (rdopt.c:4920–4921).

**Status: NOT PORTED.** Row #2 (with rows #3, #20, #22, #36, #38, #43, #44, #49, #50 as decomposed parts).

### 3. Per-segment RDO (`rd_pick_best_sub8x8_mode`, rdopt.c:2077–2428)

Inner-loop kernel of the RDO path. For each of the four 4x4 blocks in the 8x8 cell, walks `this_mode = NEARESTMV..NEWMV`:

- For NEWMV (single-ref): `mi_buf_shift` → `vp9_set_mv_search_range` → `vp9_full_pixel_search` → `find_fractional_mv_step` → cache result in `seg_mvs[block][ref_frame]` (rdopt.c:2169–2251).
- For NEWMV (compound): also calls `joint_motion_search` with `num_joint_search_iters` from `get_joint_search_iters` (rdopt.c:2259–2278).
- `set_and_cost_bmi_mvs` to compute MV bit cost + write back `bmi` entries (rdopt.c:2280–2293).
- `mv_check_bounds` reject if UMV-border crossed (rdopt.c:2296–2299).
- `filter_idx > 0` filter-cache reuse: if MV unchanged and integer-pel, reuse prior filter's `rdstat` (rdopt.c:2301–2337).
- `encode_inter_mb_segment` for the residual RD (rdopt.c:2339–2355).

**Status: NOT PORTED.** Row #3 (with rows #4, #5, #10–#13, #36, #38, #40, #41 as decomposed parts).

### 4. Compound MV refinement (`joint_motion_search`, rdopt.c:1907–2075)

The MV-refinement kernel used by sub-8 compound (and by SB-level compound, but A15 covers SB compound). Up to `MAX_JOINT_MV_SEARCH_ITERS = 4` (rdopt.c:1895) ping-pong iterations between the two refs, alternating fixed/variable. Inside each iteration: builds the "other ref" pred into `second_pred`, calls `vp9_refining_search_8p_c` (small-range full-pel) + `vp9_get_mvpred_av_var` (compound-avg variance) + `find_fractional_mv_step` with `second_pred` passed. Tracks `last_besterr[id]`, breaks if no improvement. `skip_iters` (rdopt.c:1837–1847) bails if both MVs unchanged for 2 iters.

**Status: NOT PORTED.** Rows #5–#9.

### 5. Residual RD (`encode_inter_mb_segment`, rdopt.c:1608–1734)

For the 8x8 cell, walks 4x4 sub-blocks, builds per-ref inter prediction (single or compound average via `is_compound` branch at rdopt.c:1635), subtracts to `src_diff`, runs `fwd_txfm4x4` (DCT-4x4) → `vpx_quantize_b` → `vp9_block_error` → `cost_coeffs(.., TX_4X4, ..)`. Maintains `ta[k&1]`, `tl[k>>1]` entropy contexts via `combine_entropy_contexts`. Early-bails when `RDCOST(rate, dist) >= best_yrd`.

**Status: NOT PORTED.** Row #4. Cross-ref: rvp9 has a different 4x4 round-trip (`mode_decision/inter.rs::reconstruct_via_round_trip`) for SB-level RD, but it is not the 4x4-per-sub-8-block variant.

### 6. BMI write-back (`set_and_cost_bmi_mvs`, rdopt.c:1557–1606)

Sets `mi->bmi[i].as_mv[ref].as_int` from `seg_mvs[ref_frame]` (for NEWMV) or `frame_mv[mode][ref_frame]` (for NEAR/NEAREST/ZERO), then memmoves `mi->bmi[i]` into `mi->bmi[i + idy*2 + idx]` for BLOCK_4X8 / BLOCK_8X4. Returns `cost_mv_ref(mode, mode_context[ref_frame]) + thismvcost`.

**Status: NOT PORTED.** Rows #10, #11.

### 7. Sub-8 intra picker (`rd_pick_intra_sub_8x8_y_mode` + `rd_pick_intra4x4block`, rdopt.c:1061–1360)

Picks TX_TYPE via `get_tx_type_4x4` and dispatches to `vp9_fht4x4` (DCT or ADST × ADST, etc.). Applies `conditional_skipintra` (skip oblique modes if neighbours are non-oblique).

**Status: NOT PORTED.** Rows #17, #18.

## Cross-cutting gaps

### CC-1 — Sub-8x8 leaves unreachable end-to-end

The rvp9 partition algorithm (F8.2) caps at `Block8x8`. No upstream code emits a `ModeInfo` with `block_size ∈ {Block4x4, Block4x8, Block8x4}`. Bitstream-writer support exists (`modes_writer.rs:698–737`, `write_sub8_bmi`), and decoder parsing support exists (`crates/rvp9-core/src/inter/mv_ref.rs:809`), but the encoder picker side is entirely absent. This is the prerequisite gap: **even after porting `vp9_pick_inter_mode_sub8x8` and `vp9_rd_pick_inter_mode_sub8x8`, they must be dispatched from a partition driver that can descend below Block8x8.**

Porting order constraint: partition descent ⊃ sub-8 picker. A4 (Partition logic) and A14 (Sub-8x8 picker) are coupled; A14 cannot be exercised until A4's `nonrd_pick_partition` and the keyframe partition driver are extended to descend through Block8x8 to sub-8 leaves.

### CC-2 — `b_mode_info` is wire-only in rvp9

`crates/rvp9-core/src/mode_info.rs:922` defines `BmiInfo` mirroring libvpx's `b_mode_info`. The encoder writes `bmi: Default::default()` at every `ModeInfo` construction site (e.g. `crates/rvp9-encoder/src/lib.rs:430, 579, 744, 2215, 5875`). The decoder populates `bmi` from the bitstream for sub-8 blocks. **No encoder-side mode-decision code ever writes a non-default `bmi`.** Cross-ref A1 (the SB-level picker writes `mv.as_int` to `ModeInfo.mv` but never spreads it to `bmi[0..4]` because sub-8 leaves don't exist).

### CC-3 — `MV_COST_WEIGHT_SUB` and `sadperbit4` constants missing

Sub-8 RDO uses smaller-than-SB weight constants: `MV_COST_WEIGHT_SUB` (in `set_and_cost_bmi_mvs` rdopt.c:1575) and `sadperbit4` (rdopt.c:2174). rvp9's mv_search uses `sadperbit16`-style scaling exclusively. Once Row #10 / Row #28 are ported, the rate model needs the sub-8 weight values to avoid systematic rate-cost mismatch.

### CC-4 — `inter_mode_cost[mode_context][mode]` already threaded for SB picker (A1-P0) — must be reused

A1 inventory P0 (`inter_mode_ctx` threading) hardcodes `mode_context = 0`. For sub-8, libvpx uses `mode_context[ref_frame]` populated by `vp9_find_mv_refs` (pickmode.c:2977–2978). Once A1-P0 lands, the sub-8 picker can reuse the same `inter_mode_cost` table via `cost_mv_ref` (Row #11). Cross-ref A1-P0.

### CC-5 — `pred_sse[ref]`, `pred_mv[ref]`, `max_mv_context[ref]` thread-locals never populated

rvp9 has no equivalent of `MACROBLOCK`'s `pred_sse[]`, `pred_mv[]`, `max_mv_context[]`. These feed `vp9_init_search_range` (Row #24) and `adaptive_motion_search` (Row #41). Cross-ref A1 (the SB picker also doesn't update these — sub-8 inherits the gap).

### CC-6 — `BEST_SEG_INFO` + `SEG_RDSTAT` state is per-call ephemeral

The 4-filter sub-8 RDO sweep relies on a per-call `BEST_SEG_INFO bsi[SWITCHABLE_FILTERS]` stack (rdopt.c:4515). On each filter iteration, prior filters' `rdstat[block][mode_idx]` are consulted for the `filter_idx > 0` reuse path (Row #37). Pure compute-side state, no global plumbing — but it does require ~1 KiB of stack-local scratch per call.

## Conclusion

**Status counts:** PORTED 1 · PARTIAL 2 (rows #16, #28) · NOT PORTED 48 · OUT OF SCOPE 1 (row #52, deferred behind A20).

**Row-count check:** 52 rows for ~2820 effective LOC ⇒ 1.0× picker baseline density. Within expected band (45 × 1.0 ≈ 45, actual 52 is +15%).

**Cross-zone dependencies flagged for master inventory:**
- **A4 (Partition)** — A14 is entirely gated on A4 extending partition descent below Block8x8. Without this, A14 implementation is dead code.
- **A1 (`vp9_pick_inter_mode`)** — P0 (`inter_mode_ctx` threading), P1 (`model_rd_for_sb_y` + `vp9_model_rd_from_var_lapndz`), P9 (`vp9_mv_pred`), P11 (per-context switchable-filter rate) are all prerequisites for sub-8 quality parity.
- **A13 (RDO mode-decision path)** — RDO sub-8 entry sits inside `vp9_rd_pick_inter_mode_sub8x8`, which shares `setup_buffer_inter`, `estimate_ref_frame_costs`, `super_block_uvrd`, `store_coding_context`, `swap_block_ptr`, `vp9_active_edge_sb` with `vp9_rd_pick_inter_mode_sb`. Order A13 first; A14 reuses its helpers.
- **A15 (Compound prediction)** — `joint_motion_search` is the same routine used by SB-level compound NEWMV. Land in A15, reuse in A14 Tier 3.
- **A20 (HBD)** — Row #52 (HBD sub-8 branches) is a follow-up wave gated on A20.
- **A3 (Rate control, 2-pass)** — `vp9_active_edge_sb` / `vp9_internal_image_edge` (Row #23) only fire when 2-pass is active.
- **A12 (Speed features)** — `FLAG_EARLY_TERMINATE`, `FLAG_SKIP_COMP_BESTINTRA`, `adaptive_motion_search`, `sf.comp_inter_joint_search_iter_level` are configured in `vp9_speed_features.c`. A12 sets the defaults; A14 honours them.

**Recommended sequencing for Phase 2:**
1. Land A1 (Tier 0 + Tier 1) — fixes SB-level quality first.
2. Land A4 sub-8 partition descent — opens the door.
3. Land A14 Tier 2 (RT sub-8) — closes RT-path sub-8 quality.
4. Land A13 (RDO SB), then A14 Tier 2–4 (RDO sub-8 + speed features).
5. Land A15, reuse compound infrastructure in A14 Tier 3.
6. Land A20, port HBD branches across A1/A13/A14/A15 simultaneously.

**AUDIT-UNCERTAIN rows:** None. Every row's classification is supported by a direct grep across `crates/rvp9-core/` and `crates/rvp9-encoder/` for the libvpx symbol name and a distinctive body token.
