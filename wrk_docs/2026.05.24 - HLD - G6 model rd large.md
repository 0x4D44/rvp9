# G6 --- `model_rd_for_sb_y_large` for blocks >= 32x32

**Date:** 2026-05-24
**Status:** Design
**Scope:** Port libvpx `model_rd_for_sb_y_large` (pickmode.c:430-634) and wire
`early_term` into the pick_inter_mode loop for blocks >= 32x32.

## 1. Problem

`model_rd_for_sb_y` evaluates skip_txfm using block-level averages: it computes
one variance/SSE pair for the entire block, divides by `num_blk_log2` to get a
per-TX-block mean, and checks that mean against `ac_thr`/`dc_thr`. For blocks
>= 32x32 this is too coarse --- a single noisy 8x8 sub-block hidden in an
otherwise flat 64x64 defeats the skip test even though 63 of 64 sub-blocks
would skip.

libvpx solves this with `model_rd_for_sb_y_large`, which:

1. Computes per-8x8 variance/SSE (the "8x8 grid").
2. Aggregates 8x8 cells to TX-size granularity (16x16 or 32x32).
3. Tests skip_txfm per sub-block at TX granularity (all must pass).
4. When Y skips entirely (AcDc), also tests UV --- if both UV planes skip,
   sets `early_term = true`.
5. `early_term` skips `block_yrd` and triggers hard mode-loop exit after
   2 candidates.

Without this, large blocks in flat/low-motion content run the full DCT
round-trip unnecessarily, and the mode loop evaluates all 4+ candidates
instead of exiting after 2.

## 2. Existing infrastructure

- `model_rd_for_sb_y` (`model_rd.rs:304-397`) --- whole-block variant, already
  ported. Uses `compute_variance` for full-block, `calculate_tx_size`,
  `model_rd_from_var_lapndz`.
- `model_rd_for_sb_uv` (`model_rd.rs:441-494`) --- UV model RD, already ported.
- `evaluate_candidate_for_filter` (`inter.rs:1301`) --- calls `model_rd_for_sb_y`,
  then optionally runs `block_yrd`. The `early_term` flag would gate `block_yrd`
  and propagate upward.

## 3. Design

### 3.1 `compute_variance_8x8` --- 8x8 sub-block variance grid

```
fn compute_variance_8x8(
    src: &[u8], src_stride: usize,
    pred: &[u8], pred_stride: usize,
    bw: usize, bh: usize,          // block dims in pixels (32, 64)
) -> ([u32; 64], [i32; 64], [u32; 64])   // (sse8x8, sum8x8, var8x8)
```

Iterates `(bh/8) * (bw/8)` sub-blocks. For each 8x8 cell at `(i, j)`:
- `sum8x8[k] = sum(src - pred)` over 64 pixels.
- `sse8x8[k] = sum((src - pred)^2)` over 64 pixels.
- `var8x8[k] = sse8x8[k] - (sum8x8[k]^2 >> 6)` (abs-diff, matching
  libvpx's `k_sqr = sum*sum >> 6; var = sse > k_sqr ? sse - k_sqr : k_sqr - sse`).

Also accumulates `total_sse` and `total_sum` across all cells.
Returns `total_sse`, `total_sum`, and the three per-8x8 arrays.

**Note:** libvpx calls `vpx_get8x8var` which is an optimized SIMD intrinsic.
The Rust port uses a scalar loop; SIMD is a follow-up.

### 3.2 `aggregate_to_tx_size` --- 8x8 to 16x16/32x32 aggregation

```
fn aggregate_to_tx_size(
    sse_in: &[u32], sum_in: &[i32],
    nw: usize, nh: usize,              // grid dims at input level
    tx_pixels_log2: u32,                // target TX: 8 for 16x16, 10 for 32x32
) -> (Vec<u32>, Vec<i32>, Vec<u32>)     // (sse_out, sum_out, var_out)
```

Port of libvpx `calculate_variance` (pickmode.c:317-340). Groups 2x2
cells from the input grid:

```
sse_out[k] = sse_in[i*nw+j] + sse_in[i*nw+j+1]
           + sse_in[(i+1)*nw+j] + sse_in[(i+1)*nw+j+1];
sum_out[k] = (same for sum);
var_out[k] = |sse_out[k] - (sum_out[k]^2 >> tx_pixels_log2)|;
```

For TX_16X16: call once with the 8x8 grid.
For TX_32X32: call twice (8x8 -> 16x16, then 16x16 -> 32x32).

Array sizes: 64x64 block has 64 8x8 cells -> 16 16x16 cells -> 4 32x32 cells.
Use stack arrays `[u32; 16]` / `[u32; 4]` (no heap needed).

### 3.3 `model_rd_for_sb_y_large` --- main function

```
pub fn model_rd_for_sb_y_large(
    src: &[u8], src_stride: usize,
    pred: &[u8], pred_stride: usize,
    bw: usize, bh: usize,
    bsize: BlockSize,
    dc_quant: u32, ac_quant: u32,
    dc_thr: i64, ac_thr: i64,
    tx_mode: TxMode,
) -> ModelRdLargeResult
```

**Steps:**

1. Call `compute_variance_8x8` to get per-8x8 `sse8x8`, `sum8x8`, `var8x8`,
   plus `total_sse`, `total_sum`.
2. Compute whole-block variance: `sum_sqr = total_sum^2 >> (bw_log2 + bh_log2 + 4)`,
   `var = |total_sse - sum_sqr|`.
3. Apply `ac_thr_factor`: `ac_thr *= ac_thr_factor(norm_sum)` where
   `norm_sum = |total_sum| >> (bw_log2 + bh_log2)`. For speed >= 8 and
   norm_sum < 5 and small frame, factor = 4; otherwise 1. Hardcode
   factor = 1 initially (rvp9 speed level TBD); the signature accepts
   the pre-multiplied `ac_thr` from the caller.
4. Call `calculate_tx_size` (existing) to pick TX. Clamp `tx_size >= Tx8x8`.
5. If `tx_size >= Tx16x16`, aggregate 8x8 -> 16x16. If `tx_size == Tx32x32`,
   further aggregate 16x16 -> 32x32.
6. Select the TX-level arrays: `(sse_tx, var_tx, num)` from the appropriate
   level.
7. **Per-sub-block skip test** (pickmode.c:536-557):
   - `ac_test = all k in 0..num: var_tx[k] < ac_thr || var == 0`
   - `dc_test = all k in 0..num: (sse_tx[k] - var_tx[k]) < dc_thr || sse == var`
   - If `ac_test`: `skip_txfm = AcOnly`; if also `dc_test`: `skip_txfm = AcDc`.
   - If `!ac_test && dc_test`: `skip_dc = true`.
8. If `skip_txfm == AcDc`: `rate = 0`, `dist = sse << 4`.
   The caller handles UV early_term separately (see section 3.4).
9. Otherwise: model DC + AC components using `model_rd_from_var_lapndz`
   (same as existing `model_rd_for_sb_y`).

### 3.4 `ModelRdLargeResult` --- return type

```rust
pub struct ModelRdLargeResult {
    pub rate: i32,
    pub dist: i64,
    pub var_y: u32,
    pub sse_y: u32,
    pub tx_size: TxSize,
    pub skip_txfm: SkipTxfm,
}
```

Same shape as `ModelRdResult`. Could reuse `ModelRdResult` directly (the types
are identical). Decision: **reuse `ModelRdResult`** --- no new struct.

### 3.5 `early_term` integration

The `early_term` flag is NOT set inside `model_rd_for_sb_y_large` itself.
In libvpx it requires building UV predictions and testing UV skip (pickmode.c:560-603).
The rvp9 port separates concerns:

1. `model_rd_for_sb_y_large` returns `ModelRdResult` with `skip_txfm`.
2. In `evaluate_candidate_for_filter`, when `mrd.skip_txfm == AcDc` AND
   `bsize >= Block32x32`:
   - Build UV prediction (already done later in the flow for color_sensitivity).
   - Run per-plane UV skip test: `var_uv < uv_ac_thr && (sse_uv - var_uv) < uv_dc_thr`.
   - If both U and V pass: set `early_term = true` on the result.

Add `early_term: bool` field to `InterModeSearchResult`. Default `false`.

### 3.6 Mode-loop early exit

In `pick_inter_mode` (`inter.rs:668`), after evaluating a candidate:

```rust
if best.early_term && idx > 0 {
    break;
}
```

This mirrors libvpx `vp9_pickmode.c:2474-2478`. The check fires only
after at least 2 candidates have been evaluated (idx > 0). When it fires:
- `block_yrd` was already skipped (the `evaluate_candidate_for_filter`
  short-circuits when `skip_txfm == AcDc`).
- The mode loop exits immediately; remaining candidates are not evaluated.

### 3.7 Dispatch condition: `_large` vs regular

```rust
let use_large = bsize >= BlockSize::Block32x32;
```

In `evaluate_candidate_for_filter`, replace:
```rust
let mrd = model_rd_for_sb_y(...);
```
with:
```rust
let mrd = if use_large {
    model_rd_for_sb_y_large(...)
} else {
    model_rd_for_sb_y(...)
};
```

libvpx also gates on `rc_mode == VPX_CBR && !cyclic_refresh_boosted &&
base_qindex > 0`. Simplify: rvp9 only supports CBR-like mode, has no
cyclic refresh, and `base_qindex` is always > 0 during inter frames.
Gate on block size only.

## 5. Test plan

1. **Unit: 8x8 variance grid.** Flat 32x32 block -> all `var8x8[k] == 0`,
   `sse8x8[k] == 0`. Uniform offset -> `var8x8[k] == 0`, `sse8x8[k] == 64*diff^2`.
   Checkerboard 64x64 -> verify per-cell values.

2. **Unit: aggregation.** Hand-craft 8x8 arrays for a 32x32 block (16 cells),
   aggregate to 16x16 (4 cells), verify sum and variance formulas.

3. **Unit: skip_txfm per-sub-block.** 64x64 block where 63 of 64 8x8 cells
   are flat and 1 has texture. Regular `model_rd_for_sb_y` would average
   the variance down and potentially skip; `_large` must NOT skip (one
   sub-block fails `ac_test`).

4. **Unit: early_term fires.** Fully flat 32x32 Y + flat UV -> `early_term = true`.
   Any non-flat sub-block -> `early_term = false`.

5. **Regression: foreman + testsrc PSNR gates.** The `_large` path should
   produce identical or better PSNR (fewer false skips on textured blocks,
   more true skips on flat blocks). Verify no regression beyond 0.1 dB.
