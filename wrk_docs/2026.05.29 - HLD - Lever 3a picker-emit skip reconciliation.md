## 1. Problem

The inter mode picker's skip decision is **decoupled** from the emit's skip
decision. The picker prices most leaves as *skip* (residual costs ~2 bits,
distortion = prediction-only SSE) while the emit actually *codes residual* on
the same leaves. The picker's RD ranking is therefore computed against a cost
that the bitstream never pays, biasing mode selection.

### 1.1 The two decision sites (code-verified)

**Picker tie-break** — `crates/rvp9-core/src/mode_decision/inter.rs:2656-2666`:

```rust
let rd_encode = rd_cost(lambda, rate, dist);          // rate INCLUDES coef_rate
let rd_skip   = rd_cost(lambda, 0, sse_after_pred_u32); // ~0 rate, pred-only SSE
let (final_rate, final_dist) = if rd_encode < rd_skip {
    (rate.saturating_add(skip_false_cost), dist)      // pay residual + skip=0 bit
} else {
    (skip_true_cost, sse_after_pred_u32)              // collapse to skip=1 bit, pred SSE
};
```

When the skip branch wins, `final_rate` collapses to ~1 bit
(`skip_true_cost`, `inter.rs:2654`) and `final_dist` becomes
`sse_after_pred` (SSE of source vs **prediction**, `inter.rs:2642`). The
`rate` it computed — which **includes** the real `effective_coef_rate`
(`inter.rs:2500/2611`) from `block_yrd` — is **discarded**. That `(final_rate,
final_dist)` is what feeds `best_rate` / `best_distortion` (`inter.rs:2677-2678`)
and thus the candidate's `best_rd_cost` (`inter.rs:2667/2676`) used to rank modes.

**Emit re-decision** — `crates/rvp9-encoder/src/lib.rs:5263-5265`:

```rust
if leaf_total_eob == 0 {
    sb_partitions[sb_idx][leaf_idx].skip = true;
}
```

`leaf_total_eob` (`lib.rs:5241`) is the sum of EOBs over every transform tile of
the leaf, produced by the emit's own forward transform + quantize
(`inter_forward_quant_one_tx`, `lib.rs:5784-5857`, which uses **DCT +
`vp9_quantize_b`**). The emit skips **only if every quantized coefficient is
zero**. Critically, just before this, the emit **hard-codes
`sb_partitions[...].skip = false`** (`lib.rs:4708`) — the picker's skip
decision is **thrown away on the floor** and never reaches the emit. The struct
has no field to carry it: `InterModeSearchResult` (`inter.rs:315-371`) returns
no skip flag, and `PartitionRdCandidate` (`lib.rs:3378-3384`) carries only
`(rate, dist, mv, mode, ref_frame)`.

### 1.2 Does the picker quantize the residual? YES — twice, but neither feeds the tie-break

This matters for the fix. `evaluate_candidate_for_filter`
(`inter.rs:2234-2686`) is NOT a pure prediction model:

- It runs `model_rd_for_sb_y` (`inter.rs:2286-2316`) which classifies
  `skip_txfm ∈ {None, AcOnly, AcDc}` from the **variance model**
  (`model_rd.rs:308`, libvpx `vp9_pickmode.c:636-717`). When `AcDc`, it
  short-circuits the whole round-trip and returns `skippable: true`,
  `coef_rate: 0` (`inter.rs:2339-2344`).
- Otherwise `reconstruct_via_round_trip` (`inter.rs:2854-3101`) does a **full
  forward DCT + `vp9_quantize_b` for reconstruction** (`inter.rs:2953-2980`,
  giving the per-tile `eob`) **and** a separate **Hadamard + `vp9_quantize_fp`**
  pass (`inter.rs:2989-3040`) that produces `by.coef_rate`, `by.coef_dist`, and
  `by.skippable` (`by_skippable &= had_eob == 0`, `inter.rs:3032`).

So the picker holds **two** real quantize outcomes — a DCT/`quantize_b` `eob`
(the same quantizer the emit uses) AND a Hadamard/`quantize_fp` `skippable`
(libvpx's `block_yrd` metric). **Neither is consulted by the tie-break.** The
tie-break at `inter.rs:2656` is a pure RD comparison; `by.skippable` is computed
but discarded, and the DCT `eob` is computed for `recon` only and never returned.

This is the root cause in one sentence: **the picker has the information to
predict the emit's skip outcome, but the tie-break ignores it and instead does
a model-RD comparison that, at high q with `coef_rate` undersized (Lever 3b),
almost always declares skip.**

### 1.3 Why this collapses to a ZEROMV/skip mode bias

`rd_cost` (`mode_decision/mod.rs:65-75`) is libvpx-identical:
`RDCOST = ROUND_POWER_OF_TWO(rate·rdmult, 9) + (dist << 7)`. At CBR high-q
(foreman saturates qindex at 255, `stage4a-lambda-units-investigation.md:69`),
lambda ≈ 7.8M, so the rate term dominates for any rate > ~300. The skip branch
zeroes the rate term, so `rd_skip` wins for nearly every candidate, and among
modes the cheapest-rate one (NEARESTMV/ZEROMV) wins. The residual then
self-quantizes to zero at q=255 anyway, so the emit ALSO skips — reconstruction
becomes `LASTFRAME + (0,0) MC` ≈ **stale LASTFRAME**. That is the PSNR floor.

But the prior qp=70 cross-tab shows the divergence is not just a q=255 artifact:
at qp=70 the **picker prices 98.9% of leaves as skip while the emit codes
residual on 97.1%** (mean 78 nonzero coeffs/leaf the picker assumed away). The
picker is mis-ranking modes against a fictional cost across the whole operating
range; the q=255 case is just where it's most visible.

## 2. Prior art — how libvpx couples picker and emit

libvpx's RT path (`use_nonrd_pick_mode`) makes the picker's skip decision
**the same one the bitstream emits, by construction**. Verified in the local
tree (`D:\language\libvpx\vp9\encoder\`):

### 2.1 Picker (`vp9_pickmode.c`)

`vp9_pick_inter_mode` runs `block_yrd` (`:2349`), which sets `is_skippable`
(`block_yrd` line `:804`, `*skippable &= (*eob == 0)`), then:

```c
x->skip_txfm[0] = is_skippable;
if (is_skippable) {                                    // ALL eobs zero
  this_rdc.rate = vp9_cost_bit(skip_prob, 1);          // skip=1, no residual
} else {
  if (RDCOST(rdmult, rddiv, this_rdc.rate, this_rdc.dist) <
      RDCOST(rdmult, rddiv, 0, this_sse)) {
    this_rdc.rate += vp9_cost_bit(skip_prob, 0);       // code residual, skip=0
  } else {
    this_rdc.rate = vp9_cost_bit(skip_prob, 1);
    this_rdc.dist = this_sse;
    x->skip_txfm[0] = SKIP_TXFM_AC_DC;                 // *force* skip
  }
}
```
(`vp9_pickmode.c:2350-2362`.) Two key points rvp9 misses:

1. **`is_skippable` is the FIRST gate.** If `block_yrd`'s real quantize zeroes
   every coefficient, libvpx skips **unconditionally** — it does NOT run the RD
   tie-break. rvp9's tie-break (`inter.rs:2656`) runs the RD comparison
   *regardless* of `by.skippable`. (rvp9's `mrd.skip_txfm == AcDc`
   short-circuit at `inter.rs:2339` is the variance-model analogue, but it gates
   the *round-trip*, not the *skip tie-break* — a candidate can be
   `by.skippable == true` yet still go through the RD tie-break.)
2. When the RD tie-break *does* pick skip, libvpx sets
   `x->skip_txfm[0] = SKIP_TXFM_AC_DC` — **the skip decision is recorded into
   block state**, not just into a local rate/dist.

### 2.2 Pick context → emit (`vp9_encodeframe.c`)

The picker's decision is stored in the pick context: `ctx->skip = x->skip`,
`ctx->skip_txfm[0] = x->skip_txfm[0]` (`vp9_encodeframe.c:5005-5006,
5230-5231`, etc.). At encode, `encode_b_rt` restores it:
`x->skip = ctx->skip; x->skip_txfm[0] = ctx->skip_txfm[0]`
(`vp9_encodeframe.c:2575-2576`).

### 2.3 Emit honors it (`vp9_encodemb.c`)

`vp9_encode_sb` (`vp9_encodemb.c:743-774`):

```c
mi->skip = 1;
if (x->skip) return;     // picker said skip → emit codes NO residual, done
... subtract / transform / quantize / tokenize the residual ...
```

So when the picker decided skip, **the emit does not even build the residual** —
it honors `x->skip`. When the picker did NOT skip, the emit codes the residual
and `mi->skip` is finalized by tokenization (whether any nonzero token survives
— the libvpx analogue of rvp9's `eobtotal == 0` override, but it only *tightens*
a non-skip leaf to skip, it never *overrides* a picker-skip into a non-skip).

**Conclusion:** libvpx is fundamentally **approach (B)** — the emit honors the
picker's skip flag. The picker's skip decision is gated first on the real
quantize (`is_skippable`) and only then on the RD tie-break; whichever fires,
the resulting `skip_txfm[0]` is *the* skip that lands in the bitstream. There is
no second, independent re-decision in the emit that can disagree with the
picker. rvp9's `lib.rs:5263` `leaf_total_eob == 0` override is the analogue of
libvpx's *tokenize-tightening* (libvpx `vp9_encodemb.c:772` `mi->skip = 1` reset
when no tokens emitted), but rvp9 applies it *on top of* a picker that already
decided skip differently — hence the divergence.

## 3. Design — candidate approaches

The three approaches from the brief, assessed honestly. They are not mutually
exclusive; (A) and (C) compose.

### 3.1 (A) — Make the picker PREDICT the emit's `leaf_total_eob == 0` outcome

Replace the RD tie-break's skip branch condition so the picker only takes skip
when the residual would *actually* quantize to zero — i.e. gate the skip branch
on the **same quantize the emit uses**. The picker already computes the DCT +
`vp9_quantize_b` per-tile `eob` inside `reconstruct_via_round_trip`
(`inter.rs:2953-2980`); today it's used only for `recon` and dropped. The fix:
accumulate `sum(eob)` across tiles into the returned `BlockYrdResult` (mirroring
the emit's `leaf_total_eob`), then make the picker's skip branch require
`emit_predicted_eob == 0` (libvpx's `is_skippable` first-gate, §2.1 point 1):

```text
let emit_skip = (mrd.skip_txfm == AcDc) || (by.dct_eob_total == 0);
if emit_skip {
    (skip_true_cost, sse_after_pred)          // genuine skip — emit will agree
} else {
    // residual WILL be coded: price the non-skip path honestly
    (rate.saturating_add(skip_false_cost), dist)
}
```

- **Correctness / bitstream:** valid by construction. The picker's skip set
  becomes a subset of (== ) the emit's skip set, so `lib.rs:5263` becomes a
  *no-op tightening* (it never disagrees). Still need (B)-lite plumbing for the
  *converse* (picker says skip → emit must not code residual) — see §3.4.
- **Cross-decoder byte-exact risk:** LOW-MEDIUM. The skip flag and the
  `skip_context` derived from neighbour skips (`vp9_get_pred_context_skip`,
  used at `lib.rs:4066`) are decoder-sensitive, but as long as the *emitted*
  skip equals the *emitted* eob outcome (which it does today via `lib.rs:5263`,
  and continues to under A), the bitstream stays self-consistent. The
  cross-decoder gate compares two decoders on an rvp9 bitstream — A changes
  *which* bitstream, not its validity.
- **Lever 3b interaction:** A **removes** the masking. Today the skip branch
  discards `coef_rate`, so `coef_rate`'s mis-scale (K1, F4 §3.1) is invisible
  whenever skip wins (98.9% of leaves). Under A, the non-skip path's
  `rate.add(skip_false_cost)` carries the full `coef_rate` into the mode RD for
  the 97% of leaves that actually code residual → **K1 calibration becomes
  load-bearing**. This is the point of §4.
- **Speed:** ~free. The DCT eob is already computed; we sum a value already in
  the loop and add one comparison.
- **Complexity:** LOW. One new `u64`/`usize` field on `BlockYrdResult`
  (`block_yrd.rs:59`), an accumulator in `reconstruct_via_round_trip`, and a
  changed branch condition at `inter.rs:2658`. The `AcDc` short-circuit
  (`inter.rs:2339`) is already an `emit_skip == true` case (no residual), so it
  composes.
- **Why the DCT eob, NOT `by.skippable`:** the picker has two quantize outcomes
  (§1.2), but only the **DCT + `vp9_quantize_b`** pass matches the emit's
  transform *and* quantizer (`inter_forward_quant_one_tx`, `lib.rs:5784`, uses
  DCT + `quantize_b`). The Hadamard + `quantize_fp` `by.skippable` is libvpx's
  `block_yrd` metric on a *different* transform and a zbin-free quantizer, so it
  is **not** a faithful emit-eob predictor for rvp9 (note: libvpx's RT emit
  reuses the *same* `quantize_fp` the picker used — `vp9_encodemb.c:591` — so
  libvpx has no such transform/quant split; rvp9 does, §1.2). Keying (A) off the
  DCT eob is the correct, faithful choice.
- **Residual divergence — tx-size mismatch (documented caveat).** The picker's
  recon-pass DCT eob is computed at `mrd.tx_size` (the `model_rd`-chosen size,
  `inter.rs:2320`), whereas the emit re-quantizes at
  `choose_inter_luma_tx_size`'s RD-chosen size (`lib.rs:5143`). When the two tx
  sizes differ, the eob (and thus the `eob==0` predicate) can differ between
  picker and emit on a minority of leaves. This is the one residual source of
  picker/emit skip divergence (A) does not fully close. It is **far** smaller
  than today's 97% (the transform and quantizer now match; only the tx size can
  differ), and the cross-tab (§6.1) quantifies it. Exact-tx prediction would
  require pulling `choose_inter_luma_tx_size` into the picker — out of scope; if
  the cross-tab shows it material, it is a follow-up (see R4).

### 3.2 (B) — Propagate the picker's skip decision to the emit

Add a `skip` flag to `InterModeSearchResult` and `PartitionRdCandidate`, thread
it through `lib.rs:4708` (replace the hard-coded `skip = false`), and make the
emit honor it instead of re-deciding via `leaf_total_eob`.

- **Correctness / bitstream:** This is libvpx's actual model (§2). BUT it is
  **dangerous in rvp9's current shape**: if the picker says skip via the *model*
  (`AcDc`) but the emit's DCT+`quantize_b` would have produced nonzero
  coefficients, honoring the picker-skip means the emit must **not** code that
  residual — and the recon must then be prediction-only. The encoder's recon
  simulator (`lib.rs:5209-5240`) currently always quantizes; making it honor a
  picker-skip means an explicit "skip → recon = pred, emit zero tokens" path
  that must be byte-exactly consistent with the decoder's skip handling. Getting
  that wrong is a direct cross-decoder gate break (skip flag desync, the exact
  failure mode `lib.rs:5258-5262` warns about).
- **Cross-decoder byte-exact risk:** **HIGH**. The skip flag drives both the
  `skip_context` for the *next* block's skip read and the coefficient context.
  A picker/emit/decoder three-way disagreement on a single leaf desyncs the bool
  coder for the rest of the tile. (A) sidesteps this because under (A) the
  picker-skip is *defined* as the emit-eob outcome, so they cannot disagree.
- **Lever 3b interaction:** Same exposure as (A) — honoring picker-skip means
  the non-skip path's `coef_rate` becomes load-bearing.
- **Speed:** free (carries a bool).
- **Complexity:** MEDIUM-HIGH. New field on two structs, plumbing through the
  partition descent, a new skip-honoring recon path, and re-validation of the
  skip-context derivation. The model-skip (`AcDc`) vs emit-eob divergence is a
  genuine landmine.

### 3.3 (C) — Cost the non-skip path with the real coded residual cost

Don't let the skip tie-break discard `coef_rate`: when the emit *will* code
residual, the candidate's mode RD must reflect `rate` (incl. `coef_rate`), not
the ~2-bit skip price. This is **exactly what (A)'s non-skip branch does** — (C)
is the *mode-RD-correctness* half and (A) is the *which-branch* half. Stated
alone, (C) means: always feed the honest `(rate, dist)` into mode ranking and
only collapse to skip when skip genuinely wins AND the emit will agree.

- (C) without (A) is incoherent: you can't "cost the non-skip path honestly"
  unless you also know *whether* the path is non-skip — which is (A)'s gate. So
  (C) is not a standalone option; it's the rationale for keeping `coef_rate` in
  the surviving non-skip branch. **Folded into (A).**

### 3.4 Recommendation — **(A), composed with a minimal (B)-lite back-edge**

**Land (A): gate the picker's skip branch on the emit-predicted eob, keep the
full `coef_rate` in the non-skip branch (= C).** This makes *picker-skip ⊆
emit-skip* by construction, so:

- For leaves the picker now prices as non-skip (the ~97% it wrongly skipped),
  the mode RD carries the real residual cost → mode ranking is honest → the
  ZEROMV/skip bias breaks.
- For leaves the picker prices as skip, the emit's `leaf_total_eob == 0` already
  agrees (because A's gate IS the emit's quantize), so `lib.rs:5263` stays a
  consistent no-op tightening.

**The minimal (B)-lite back-edge (REQUIRED for the converse):** there is one
case (A) alone doesn't fully close — the picker's *model* skip via `AcDc`
(`inter.rs:2339`, variance model says zero residual) where the emit's
DCT+`quantize_b` might still find a coefficient. To keep picker-skip ⊆
emit-skip *exactly*, drop A's reliance on `AcDc` for the skip *decision* and use
the DCT-eob accumulator uniformly (the `AcDc` short-circuit can still skip the
*round-trip work* for speed, but the skip *branch* keys off the real eob when
the round-trip ran). If we keep `AcDc` as a skip trigger, we must propagate that
skip to the emit (true (B) plumbing) so the emit doesn't re-quantize and find a
stray coefficient. **Decision for the lead (§ open question):** simplest is to
make the `AcDc` short-circuit also force the emit to skip (a 1-bool propagation,
much narrower than full (B)), OR drop the `AcDc`-as-skip and always trust the
DCT eob. The former keeps the speed short-circuit; the latter is simpler and
strictly safer. **Recommended: drop `AcDc`-as-skip-trigger, key skip purely off
the DCT-eob accumulator (uniform with the emit).** This is pure (A), no (B)
plumbing, lowest cross-decoder risk.

This is the smallest change that makes picker-skip == emit-skip by construction,
with the lowest byte-exact risk, and it composes cleanly with Lever 3b.

## 4. Interaction with Lever 3b (RD calibration)

**The fix MUST land alone first, measured, before any K1/lambda recalibration.**

Rationale: today the skip tie-break discards `coef_rate` on 98.9% of leaves, so
`coef_rate`'s scale (K1, `block_yrd.rs:165` / F4 §3.1) is **masked** — it almost
never reaches the mode RD. (A) un-masks it: the 97% of leaves that actually code
residual now carry `coef_rate` into mode ranking. So (A) will *expose* whatever
mis-scale exists in `coef_rate`.

F4 already measured the bare exposure: with `coef_rate` ON and the tie-break
OFF, 250 kbps PSNR collapsed −6 dB (F4 §1.2 table) because `coef_rate`
overprices candidates against rvp9's pixel-SSE `dist` (DV-F1-3) and lambda. (A)
re-creates a controlled version of that exposure, but *only on the non-skip
leaves and with the skip tie-break intact*, so the collapse should be partial,
not total.

**Pre-registered expected outcome:**

- **If (A) alone improves foreman PSNR-delta** (picker stops over-skipping →
  more NEWMV/NEARESTMV with real residual → less stale-LASTFRAME): land (A),
  set the new threshold by measurement (F.0.1 discipline), then run the Lever 3b
  K1 sweep (F4 §3.3 Phase A) *on top of* (A) to recover the residual gap.
- **If (A) alone regresses** (the now-load-bearing `coef_rate` is so mis-scaled
  that honest non-skip pricing picks worse modes): this is the F4 §1.2 result
  reproduced. **Do NOT abandon (A).** Instead co-land (A) + the K1 sweep as a
  pair — (A) is the mechanism, K1 is the calibration, and F4 already proved
  neither works alone. The sweep is cheap (5 setpoints, §6).

**Honest caveat (from the diagnosis):** (A) alone is **unlikely to recover the
full ~6 dB matched-byte gap.** It fixes the *mode-bias mechanism*; the
*magnitude* of recovery depends on `coef_rate` being scaled so the honest
non-skip RD ranks modes like libvpx. That is Lever 3b. Pre-register: (A) buys
the *direction* (ZEROMV% drops, NEWMV/NEARESTMV rises), Lever 3b buys the
*magnitude*. Measure (A) alone to attribute, then calibrate.

## 5. Non-goals

- **No full (B) pick-context plumbing** unless §3.4's open question resolves
  toward keeping `AcDc`-as-skip-trigger. Default recommendation avoids it.
- **No K1/lambda/`compute_rd_mult` changes in this PR.** Lever 3b is a separate,
  sequenced landing (§4). This HLD ships the *mechanism*; calibration follows.
- **No change to the emit's `leaf_total_eob == 0` override** (`lib.rs:5263`).
  Under (A) it stays correct and becomes a consistent no-op tightening; touching
  it is out of scope.
- **No intra-path skip changes.** This is the inter picker only (`inter.rs`
  `evaluate_candidate_for_filter`).
- **No new SIMD, no Hadamard re-port** (DV-F1-1 is a separate F-track item).
- **No `cross_decoder_gate` semantics change** — it stays the regression guard.

## 6. Validation oracle / test plan

Success is the **collapse of the picker-skip / emit-code divergence** plus the
downstream mode-mix and PSNR shifts. Reuse existing diagnostics; add no new
heavy tooling.

### 6.1 Primary oracle — picker-skip vs emit-code cross-tab (qp=70 harness)

Reuse the qp=70 cross-tab that produced the diagnosis. The picker's skip
decision and the emit's `leaf_total_eob == 0` outcome are both observable:

- **Picker skip:** instrument `evaluate_candidate_for_filter`'s chosen branch
  (the `RVP9_DIAG_EVAL` hook, `inter.rs:2404`) to emit whether the winning
  candidate took the skip branch.
- **Emit code:** the `RVP9_DIAG_PICKER` hook (`lib.rs:5272-5281`) already prints
  `leaf_total_eob` and the final `skip`. `skipstat::record_leaf`
  (`skipstat.rs:56`, env `RVP9_E4_SKIPSTAT`) already aggregates
  `skip_leaves / nonskip_leaves / nonskip_eob_sum / nonskip_tiny`.

**Cross-tab cells:** `(picker_skip, emit_code)`. **Target:** the
`(picker_skip=true, emit_code=true)` cell collapses from **97% toward ~0**; the
diagonal (`picker_skip == emit_skip`) goes to ~100%. This is the load-bearing
positive control — it directly measures the thing (A) is designed to fix.

### 6.2 Mode-mix shift (ZEROMV% drop)

At CBR-100k on foreman, `RVP9_DIAG_PICKER` / the per-frame mode summary
(`RVP9_DIAG_INTPRO`, ledger:648) reports zero/nearest/near/new counts. **Target:**
ZEROMV% drops from ~90% toward libvpx's NEARESTMV/NEWMV mix. (Direction only —
magnitude gated on Lever 3b per §4.)

### 6.3 Q-mode RD curve shift

Run the F.0.2 per-block oracle (`per_block_oracle`, F0.2/F4 §6) and the Stage 4a
quality gate (`quality_gate_stage4a_realcontent`) at the standard operating
points. **Target:** Q-mode RD curve shifts toward libvpx; foreman PSNR-delta
mean moves below the current threshold (set the new threshold by measurement,
not prediction — F.0.1 discipline).

### 6.4 Matched-byte Y-PSNR gap

## 9. Executive summary

1. **Root cause confirmed in code:** the picker's skip tie-break
   (`inter.rs:2656-2666`) is a pure model-RD comparison that *discards the
   `coef_rate` it computed* and is *not gated on the real quantize* — even
   though the picker already computes the same DCT+`vp9_quantize_b` eob the emit
   uses (`inter.rs:2953-2980`) and throws it away. The emit
   (`lib.rs:5263`) independently re-decides skip from `leaf_total_eob`, and
   `lib.rs:4708` hard-codes `skip = false` so the picker's decision never even
   reaches it.

2. **libvpx couples them by construction** (approach B): the RT picker gates
   skip *first* on the real quantize (`is_skippable`, `vp9_pickmode.c:2350`),
   records it into block state, and the emit honors `x->skip` and codes no
   residual (`vp9_encodemb.c:774`). There is no independent emit re-decision.

3. **Recommended fix: approach (A) + minimal back-edge** — gate the picker's
   skip branch on the emit-predicted DCT-eob (drop `AcDc`-as-skip-trigger, §3.4),
   keep the full `coef_rate` in the surviving non-skip branch (= C). This makes
   *picker-skip == emit-skip by construction*, the lowest cross-decoder risk, ~60
   LOC. Full (B) plumbing is avoided (HIGH byte-exact risk for marginal benefit).

4. **Lever 3b co-design:** (A) un-masks `coef_rate` on the ~97% of leaves that
   actually code residual, exposing its scale (F4 §1.2 showed bare exposure
   collapses 250k by 6 dB). **Land (A) alone first and measure** to attribute,
   then run the K1 sweep on top. Pre-registered: (A) buys the *direction*
   (ZEROMV% drops), Lever 3b buys the *magnitude*; (A) alone likely will NOT
   recover the full 6 dB.

5. **Validation:** primary oracle is the qp=70 picker-skip/emit-code cross-tab
   (target: the 97% disagreement cell → ~0), reusing `RVP9_DIAG_PICKER`,
   `RVP9_DIAG_EVAL`, and `skipstat`; plus ZEROMV% drop, Q-mode RD shift,
   matched-byte PSNR, and `cross_decoder_gate` staying 4/4 with no decode
   failures.

**Single biggest open question for the lead:** §3.4 — do we **drop the
`AcDc`-model-skip-as-decision** entirely and key the picker's skip purely off the
real DCT-eob accumulator (simplest, strictly safest, pure (A), zero (B)
plumbing), or **keep the `AcDc` variance-model skip** for its speed short-circuit
and add the minimal (B)-lite bool to propagate it to the emit (keeps the
fast-path, costs ~20 LOC of skip plumbing + a skip-honoring recon path and a
re-validation of skip-context)? The recommendation is the former; the latter is
only worth it if the `AcDc` work-skip proves load-bearing for the realtime
budget.
