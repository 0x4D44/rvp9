# G3: Wire Coefficient Count Accumulation into Token Writer

## Problem

`adapt_coef_probs` (`adapt.rs:582`) receives zero counts and is a no-op.
`write_block_tokens` / `encode_coefs` (`detokenize.rs:1221/971`) emit
coefficient tokens to the bool coder but never increment
`FrameCounts::coef` or `FrameCounts::coef.eob_branch`. Coef probs stay
at defaults forever.

## Existing count-accumulation pattern (modes_writer.rs)

`write_tile_inter` threads `Option<&mut FrameCounts>` down through:
```
write_tile_inter  -->  write_inter_partition_tree  -->  write_inter_block_leaf
```
At each leaf, mode/skip/tx/partition counts are bumped inline:
```rust
if let Some(c) = counts.as_deref_mut() {
    c.skip[skip_ctx][usize::from(mi.skip)] += 1;
}
```
However `write_inter_block_residual` (called from `write_inter_block_leaf`
at line 2002) does NOT receive `counts` -- it only gets `(bw, fc,
coef_ctx, coef_source, ...)`. The counts chain is broken here.

## Count shape (adapt.rs + detokenize.rs)

```
CoefCountsBank {
    coef:       [TX_SIZES][PLANE_TYPES][REF_TYPES][COEF_BANDS][COEFF_CONTEXTS][4]
                                                                               ^-- ZERO/ONE/TWO/EOB_MODEL
    eob_branch: [TX_SIZES][PLANE_TYPES][REF_TYPES][COEF_BANDS][COEFF_CONTEXTS]
}
```

`adapt_coef_probs` reads these as (per band/ctx slot):
- `n0 = coef[..][ZERO_TOKEN=0]`, `n1 = coef[..][ONE_TOKEN=1]`,
  `n2 = coef[..][TWO_TOKEN=2]`, `neob = coef[..][EOB_MODEL_TOKEN=3]`
- `eob_total = eob_branch[..][band][ctx]`

## libvpx reference (vp9_tokenize.c:386-413 + vp9_encoder.c:3581-3600)

libvpx accumulates full 12-token counts during `tokenize_b`, then reduces
via `full_to_model_count`: ZERO stays, ONE stays, TWO absorbs
THREE..CAT6, EOB_MODEL = EOB_TOKEN count. Since our `FrameCounts::coef`
already uses the 4-token model, we accumulate model tokens directly --
no reduction step needed.

libvpx's per-position logic:
1. `++eob_branch[band][pt]`  (before EOB decision)
2. If ZERO: `++counts[band][pt][ZERO_TOKEN]`
3. If non-zero: `++counts[band][pt][token]` (ONE or TWO+)
4. Terminal EOB: `++eob_branch[band][pt]`, `++counts[band][pt][EOB_MODEL_TOKEN]`

## Design

### Step 1: Thread counts through the residual path

Add `counts: Option<&mut CoefCountsBank>` to `write_inter_block_residual`:

```rust
fn write_inter_block_residual(
    bw: &mut BoolWriter<'_>,
    fc: &FrameContext,
    coef_ctx: &mut TileCoefCtx,
    coef_source: &dyn InterCoefSource,
    mi_row: usize,
    mi_col: usize,
    leaf_bsize: BlockSize,
    luma_tx: TxSize,
    counts: Option<&mut CoefCountsBank>,  // NEW
)
```

At the call site in `write_inter_block_leaf` (line 2002), pass
`counts.as_deref_mut().map(|c| &mut c.coef)`.

### Step 2: Thread counts into write_block_tokens / encode_coefs

Add `counts: Option<&mut CoefCountsBank>` to `write_block_tokens`:

```rust
pub fn write_block_tokens(
    ...existing params...,
    counts: Option<&mut CoefCountsBank>,  // NEW
)
```

Inside `write_block_tokens`, slice the counts to per-block level before
calling `encode_coefs`:

```rust
let mut block_counts: Option<DecodeCoefCounts<'_>> = counts.map(|c| {
    let tx = tx_size as usize;
    DecodeCoefCounts {
        coef_counts: &mut c.coef[tx][plane_type][ref_type],
        eob_branch_counts: &mut c.eob_branch[tx][plane_type][ref_type],
    }
});
encode_coefs(bw, coef_probs, &scan, initial_pt, tx_size, seg_eob,
             raw_coefs, eob, block_counts.as_mut());
```

### Step 3: Accumulate counts inside encode_coefs

Add `counts: Option<&mut DecodeCoefCounts<'_>>` to `encode_coefs`. The
increment points mirror the decoder's existing `decode_coefs` logic
(which already accumulates counts) and libvpx's `tokenize_b`:

```rust
pub fn encode_coefs(
    ...existing params...,
    counts: Option<&mut DecodeCoefCounts<'_>>,  // NEW
) {
    ...
    let mut c = 0usize;
    'outer: while c < eob {
        let band = band_translate[c] as usize;

        // (A) eob_branch: this position attempts an EOB decision
        if let Some(ref mut ct) = counts {
            ct.eob_branch_counts[band][ctx] += 1;
        }

        // EOB decision -- NOT EOB
        bw.write(1, prob[EOB_CONTEXT_NODE]);

        // Inner zero-run loop
        loop {
            let raster_idx = scan.scan[c] as usize;
            let coef = raw_coefs[raster_idx];
            if coef != 0 {
                bw.write(1, local_prob[ZERO_CONTEXT_NODE]);
                break;
            }
            // ZERO_TOKEN
            bw.write(0, local_prob[ZERO_CONTEXT_NODE]);
            // (B) count ZERO
            if let Some(ref mut ct) = counts {
                let b = band_translate[c] as usize;
                ct.coef_counts[b][ctx][ZERO_TOKEN] += 1;
            }
            token_cache[raster_idx] = 0;
            c += 1;
            if c >= eob {
                if c < seg_eob {
                    ctx = get_coef_context(...);
                }
                break 'outer;
            }
            ctx = get_coef_context(...);
            let band_local = band_translate[c] as usize;
            local_prob = &coef_probs[band_local][ctx];
        }

        // Non-zero value tree
        let abs_val = ...;
        if abs_val == 1 {
            bw.write(0, local_prob[ONE_CONTEXT_NODE]);
            // (C) count ONE
            if let Some(ref mut ct) = counts {
                let b = band_translate[c] as usize;
                ct.coef_counts[b][ctx][ONE_TOKEN] += 1;
            }
            token_cache[raster_idx] = 1;
        } else {
            bw.write(1, local_prob[ONE_CONTEXT_NODE]);
            // (D) count TWO (absorbs TWO through CAT6)
            if let Some(ref mut ct) = counts {
                let b = band_translate[c] as usize;
                ct.coef_counts[b][ctx][TWO_TOKEN] += 1;
            }
            // ...emit high-value tree bits (unchanged)...
        }
        // sign bit...
        c += 1;
        ...
    }

    // Terminal EOB
    if eob < seg_eob {
        let band = band_translate[eob] as usize;
        // (E) eob_branch + EOB_MODEL_TOKEN
        if let Some(ref mut ct) = counts {
            ct.eob_branch_counts[band][ctx] += 1;
            ct.coef_counts[band][ctx][EOB_MODEL_TOKEN] += 1;
        }
        bw.write(0, prob[EOB_CONTEXT_NODE]);
    }
}
```

### Step 4: Update all call sites

1. **`write_inter_block_residual`** (modes_writer.rs:2233): pass counts

2. **`write_inter_block_leaf`** (modes_writer.rs:2002): pass

3. **Test call sites** in `detokenize.rs::tests`: pass `None` (no
   counting needed in unit tests).

4. **Any other callers** of `write_block_tokens` or `encode_coefs`:
   grep and update.

## Single-threaded scope

The encoder is single-tile, single-thread. One `FrameCounts` instance
is created per frame in `build_inter_packet` (frame_loop.rs:1068),
passed through `write_tile_inter`, accumulated during the tile write,
and consumed by `adapt_coef_probs` at line 1114. No per-tile merging
is needed. The existing `CoefCountsBank::add` method exists for future
multi-tile support but is not exercised here.

## Verification

After wiring, `adapt_coef_probs` will receive non-zero counts, producing
adapted probabilities that differ from the defaults. Verification:
1. Encode a multi-frame sequence with non-trivial residuals (non-skip).
2. Assert `frame_counts.coef` is non-zero after tile write.
3. Assert adapted coef_probs differ from pre-adapt defaults.
4. Decode the output with rvp9-decoder; round-trip must still match.
