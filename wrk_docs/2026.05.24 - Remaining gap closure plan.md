## 2. Remaining items — ordered by ROI

### G1 — UV RD wiring (P6 completion)
**Effort:** ~30-50 LOC  |  **Impact:** Medium  
**What:** Thread UV plane data (source + recon) into `PickInterModeParams`.
After each candidate's luma model_rd, call `model_rd_for_sb_uv` on
the UV planes and add UV rate+dist to the total RD cost. This prevents
the picker from choosing modes that look good in Y but destroy chroma.

**libvpx ref:** pickmode.c:2378-2393 — UV model_rd is called after
model_rd_for_sb_y and added to `this_rdc.rate/dist`.

**Dependencies:** `model_rd_for_sb_uv` already exists in `model_rd.rs`.

### G2 — Switchable-filter per-context rate (P11)
**Effort:** ~20-30 LOC  |  **Impact:** Low-medium  
**What:** Replace the flat `F5_SWITCHABLE_FILTER_RATE = 2048` constant
with per-context `switchable_interp_costs[ctx][filter]` lookup.
Thread `vp9_get_pred_context_switchable_interp(xd)` into the filter
search loop.

**libvpx ref:** pickmode.c:1541-1545 — `rs = vp9_get_switchable_rate(cpi, xd)`.

**Dependencies:** `switchable_interp_costs` table already built in
`cost::symbol_costs`. Need to thread the context lookup.

### G3 — Coef count accumulation (P5 completion)
**Effort:** ~80-120 LOC  |  **Impact:** Medium-high  
**What:** `write_block_tokens` / `encode_coefs` in `detokenize.rs`
currently emits tokens but does NOT accumulate `FrameCounts::coef`.
Wire count accumulation into the token-writing loop, matching libvpx's
`vp9_record_coefs` / coefficient counting in `pack_mb_tokens`.

Once coef counts are accumulated, `adapt_coef_probs` (already called
in `frame_loop.rs:1114`) will actually adapt coef probs frame-to-frame
instead of being a no-op.

**libvpx ref:** `vp9_pack_bitstream.c` — `pack_mb_tokens` accumulates
coef counts alongside token emission. Also `vp9_bitstream.c:record_coefs`.

**Dependencies:** The adaptation call exists. Need to fill the counts.

### G4 — encode_breakout_test (P7)
**Effort:** ~80-100 LOC  |  **Impact:** Medium  
**What:** Port `encode_breakout_test` (pickmode.c:933-1036). After
model_rd computes var/sse, test whether the prediction alone is
sufficient (no residual needed) based on quantizer-dependent AC/DC
variance thresholds. If Y passes, test UV too. If all pass, set
skip=true and exit the mode loop.

This fires for well-predicted blocks, freeing bits for blocks that
need them.

**libvpx ref:** pickmode.c:933-1036 called at pickmode.c:2415-2425.

**Dependencies:** model_rd_for_sb_y (done), model_rd_for_sb_uv (G1).

### G5 — Intra-in-inter residual coding (P3 completion)
**Effort:** ~80-100 LOC  |  **Impact:** Medium  
**What:** The encoder simulator (lib.rs:3456-3565) currently runs
intra prediction for intra-in-inter blocks but forces skip=true
(no residual). Port the forward DCT + quantize + coef collection
path for intra blocks, mirroring the existing inter residual path.

This recovers quality on intra-in-inter blocks where the prediction
isn't perfect (the residual carries useful information).

**libvpx ref:** Not a direct port — libvpx handles intra residuals
through the same block_yrd + encode path as inter. The encoder
simulator needs its residual path extended to handle intra pred input.

**Dependencies:** Phase 2b wire-format (done).

### G6 — model_rd_for_sb_y_large + early_term (P10)
**Effort:** ~200 LOC  |  **Impact:** Medium-high  
**What:** Port the extended `model_rd_for_sb_y_large` variant
(pickmode.c:430-634) for blocks ≥32×32. It computes 8×8-granularity
variance/SSE, aggregates to TX-size level, evaluates skip_txfm
per sub-block, and produces the `early_term` flag when UV planes
also pass the skip test.

The `early_term` flag is critical: it short-circuits the entire
block_yrd step (pickmode.c:2348) and triggers a hard early-exit
from the mode loop after 2 candidates (pickmode.c:2474-2478).

**libvpx ref:** pickmode.c:430-634.

**Dependencies:** model_rd_for_sb_y (done), model_rd_for_sb_uv (G1).
Also needs `block_variance` / `calculate_variance` helpers
(pickmode.c:264-340, currently NOT PORTED).
