# AArch64 scalar transform helpers under Miri

RVP9-BUG-FLU-00037 is fixed by including the scalar forward-transform helpers and their function-pointer aliases under `cfg(miri)`. On AArch64, Miri dispatches to these scalar paths while the NEON implementation is disabled, so the ordinary non-test library build must retain the helpers.

Before the fix, the dependent-library Miri build failed with five E0425 errors for `fdct4x4_scalar`, `fht4x4_scalar`, `fht8x8_scalar`, `fht16x16_scalar`, and `fdct32x32_scalar`. After the fix, the same locked, offline Miri `frame_alloc` integration test compiled and passed all three tests.

`cargo check -p rvp9-core --lib --locked`, `cargo fmt --all --check`, and `git diff --check` passed. Miri reported existing unused-code warnings from AArch64 SIMD modules while exercising the scalar fallback.
