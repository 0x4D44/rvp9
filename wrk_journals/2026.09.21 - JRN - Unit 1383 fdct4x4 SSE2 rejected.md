# Unit 1383 — x86 SSE2 fdct4x4 screen (rejected)

Date: 2026-09-21  
Base: integrated `7403c904`  
Decision: reject the candidate; keep the source unchanged.

## Candidate

The fresh Crucible profile attributed 426,930 weighted samples to
`transforms::forward::fdct4x4` (1.98% of 21,564,981 user-symbol samples).
The x86-64 path still used the scalar 4×4 transform. This experiment added an
SSE2 implementation using four i32 lanes, exact SSE2 32×32 products, two
transposed passes, and the existing scalar dispatch on ARM, Miri, and other
portable targets.

## Correctness

- Local AArch64 `cargo test --locked -p rvp9-core --lib transforms::forward -- --nocapture` passed 46/46.
- Crucible x86-64 release `cargo test --locked --release -p rvp9-core transforms::forward::sse2 -- --nocapture` passed 3/3 focused SSE2 tests, including 1,024 random 4×4 residuals, non-tight strides, constants, and extreme impulses.
- Cross-compiling the focused x86 target completed successfully.
- Deliberately changing the final reduction bias from `+1` to `+2` made the new differential test fail on random residual case 0. The mutation was restored before timing.
