# v0.2.0-alpha.2 publication

RVP9 `v0.2.0-alpha.2` was published from integrated commit
`bf11bc5c999e70c794ef18cfa9f20a980189512d` after the release qualification
recorded in `wrk_journals/2026.08.14 - JRN - v0.2.0-alpha.2 release
qualification.md`.

## GitHub

- Annotated tag: `v0.2.0-alpha.2`; tag object
  `10a96663f969aa5031109f951f3a4a266f639a0e`, dereferenced target
  `bf11bc5c999e70c794ef18cfa9f20a980189512d`.
- Prerelease: `https://github.com/0x4D44/rvp9/releases/tag/v0.2.0-alpha.2`.
- Apple Silicon archive:
  `rvp9-0.2.0-alpha.2-aarch64-apple-darwin.tar.gz`, 1,403,009 bytes,
  SHA-256
  `29ff5a2ba90d537baeb1f47f9dcbdeb136c57c3a7aa95be871927bb7bcdb83dd`.
- The matching `.sha256` sidecar is attached. GitHub reports both assets in
  the uploaded state and reports the archive digest above.
- The archive was rebuilt with empty Rust flags from the integrated commit.
  Its checksum passed, both binaries reported `0.2.0-alpha.2`, and a packaged
  12-frame CBR encode decoded byte-identically under the packaged rvp9dec,
  pinned libvpx vpxdec, and FFmpeg.

## crates.io

The five public crates were packaged, verified, dry-run, and published in
dependency order:

1. `rvp9-core 0.2.0-alpha.2`
2. `rvp9-io 0.2.0-alpha.2`
3. `rvp9-decoder 0.2.0-alpha.2`
4. `rvp9-encoder 0.2.0-alpha.2`
5. `rvp9-cli 0.2.0-alpha.2`

`rvp9-bench`, `rvp9-harness`, and `rvp9-fuzz` were not published. The reserved
`rvp9 0.0.0` facade was not changed or published.

A clean registry-only install completed with:

```bash
cargo install rvp9-cli --version '=0.2.0-alpha.2' --locked
```

The install resolved all four exact internal crate versions from crates.io,
built both binaries, and both `rvp9enc --version` and `rvp9dec --version`
reported `0.2.0-alpha.2`.

## Continuing work

This prerelease does not close production parity. CPU-used 8 three-layer
temporal-SVC relative speed still needs a quiet-host confirmation, and the
final combined CPU6--8 CBR/VBR, AQ, denoiser, temporal-SVC, and spatial-SVC
matrix remains open.
