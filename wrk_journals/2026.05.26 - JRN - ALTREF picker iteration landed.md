# 2026.05.26 — JRN — ALTREF picker iteration landed

## Goal

Make the show-frame inter-mode picker iterate ALTREF (ref-pool slot 2) as
a single-reference candidate, gated to `enable_alt_ref = true`. Direct
follow-on to the keystone commit 0ad7e7d (slot 2 became a real ALTREF
reconstruction). Before this wave the picker was LAST/GOLDEN-only and the
slot-2 ALTREF reconstruction was unused by the picker.

## Outcome: LANDED

The transform-domain RDO dispatch picker (speed ≤ 4 path,
`rdo/inter_dispatch.rs` + `rdo/pick_inter_sb.rs`) now iterates ALTREF as a
first-class single-ref candidate: real ME (diamond + sub-pel) against slot
2, real MC prediction, real forward-quantised residual RD — exactly the
same machinery LAST/GOLDEN use. No synthetic/SAD model.

## libvpx parity

- `vp9_rdopt.c:3533` / `:3545` / `:4349` — the ref-candidate loop
  `for (ref_frame = LAST_FRAME; ref_frame <= ALTREF_FRAME; ++ref_frame)`
  iterates ALTREF as a single-ref candidate.
- `vp9_rdopt.c:2511` `setup_buffer_inter` — wires the ALTREF buffer for
  the candidate's motion search.
- `vp9_encoder.c:5034-5049` `set_ref_sign_bias` — ALTREF is a backward
  (future display-order) reference → `sign_bias[ALTREF] = true`.

## Gate-safety (the inviolable constraint)

A single boolean — `enable_alt_ref && altref_slot_emitted` (a real ARF has
fired this GOP) — gates *everything*:

- picker ALTREF candidate availability (`InterDispatchLeaf.altref`),
- the picker's `find_mv_refs` `sign_bias` (`[false,false,altref_live]`),
- the show-frame header's `ref_frame_indices` (`[0,0,2]` vs `[0,0,0]`) and
  `ref_frame_sign_biases` (`[false,false,altref_live]`).

When `enable_alt_ref = false` (the cross-decoder gate's config) the
boolean is always false: the picker never enumerates ALTREF, no ALTREF
neighbours can ever exist, and the header bytes are byte-identical to the
LAST/GOLDEN-only path. **Sacred gate verified 4/4 BYTE-EXACT, unchanged.**

## Wire path

The show frame following an ARF now sets `ref_frame_indices[2] = 2` so a
block with `ref_frame == ALTREF` resolves to decoder ref-pool slot 2 (where
the ARF refreshed via `refresh_frame_flags = 0x04`), with
`sign_bias[ALTREF] = true`. The encoder simulator's residual-coding MC
reads slot 2's reconstruction for ALTREF leaves (mirrors the decoder's
`reconstruct_inter_block`), keeping the recon byte-exact. The per-block
single-ref ALTREF write path (`inter/mode_info.rs:1078`, bit0=1/bit1=1)
was already in place and tested.

## Scope (honest)

- **RDO dispatch picker only (speed ≤ 4).** The realtime picker
  (`rvp9_core::mode_decision::inter::pick_inter_mode`, speed 6/7) stays
  LAST/GOLDEN-only this wave — wiring ALTREF into that core picker is a
  separate, larger task. The PROOF runs at speed 3.
- **The ARF's own per-leaf coding** still predicts from LAST/GOLDEN only
  (it cannot reference a future ARF) — `None` passed for its picker.
- **Compound** is a separate later task (single-ref ALTREF only here).

## PROOF (`tests/w_altref_picker.rs`)

1. `show_frame_picker_selects_altref` (always-live, anti-G3): encodes the
   synthetic noisy-base clip twice. With `enable_alt_ref=false` the
   `RDO_DISPATCH_ALTREF_PICKS` delta is **0** (gate-safe); with
   `enable_alt_ref=true` it is **966** (≥1 required). Fails if ALTREF
   iteration is stripped or the gate inverted.
2. `altref_picker_stream_byte_exact_vpxdec` (`#[ignore]`): the
   ALTREF-referencing stream (966 ALTREF leaves, 1 non-show ARF, 16 show
   frames) decodes **BYTE-EXACT** through both rvp9-decoder and
   libvpx-stock vpxdec.

Content: a fixed structured base (gradients + constant-luma rectangles)
plus deterministic per-frame additive noise. The temporal filter denoises
the ARF; predicting a noisy show frame from the clean ALTREF leaves a
smaller residual than from the previous noisy LAST recon → the RD picker
selects ALTREF for many leaves. Real residual RD, no model.
