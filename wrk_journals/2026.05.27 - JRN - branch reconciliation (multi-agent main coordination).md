# Branch reconciliation — 2026-05-27

Concurrent multi-agent state issue surfaced + resolved. Recorded for the audit trail.

## What happened

- Session started on `main` per the harness git-state report.
- Iter8 of Track-F committed cleanly on main as `9114d46`.
- Between iter8 and the next commit, the decoder/AVX2 team's agent
  switched the shared working tree's HEAD to their branch
  `decoder/convolve8-horiz-avx2` to do their kernel-audit harness work.
- My next commit (the spatial-SVC plan HLD) landed on `decoder/convolve8-horiz-avx2`
  as `626614a` instead of main — same content, wrong branch ref.

## Why this is a recurring shape

Shared working tree across concurrent agents means shared HEAD; whoever
does `git checkout` last wins, and the next committer doesn't realise.
The pre-commit `git status` reminder is snapshot-at-session-start, not
live, so it can mislead.

## Resolution (Arthur-steered)

1. **Branch coordination decision**: both agents work on main going
   forward. Decoder agent moved their harness commit (originally
   `891b08f` on `decoder/convolve8-horiz-avx2`) onto main as `0af7e58`
   while branch sorting was in progress — implicit alignment.
2. **HLD migration**: cherry-picked the HLD commit from
   `decoder/convolve8-horiz-avx2` (originally `626614a`, then `72e4ada`
   on a throwaway `feat/spatial-svc` branch) onto main as `474c9d1`.
3. **Throwaway branch deleted** (force-delete authorised since the
   content was duplicated on main): `feat/spatial-svc` was a one-commit
   intermediary used during the maneuver.
4. **Decoder team's tracked WIP** was briefly stashed mid-maneuver
   (stash@{0} when the maneuver started); the decoder agent restored
   their journal-edit WIP after their own checkout of main.
5. **Orphan duplicate**: the HLD commit `626614a` still exists on
   `decoder/convolve8-horiz-avx2` as orphan history. Harmless for now;
   Arthur can clean up that branch later if desired.

## Lesson for future agents in this tree

- **Never assume the branch reported at session start is still active.**
  Re-check `git branch --show-current` immediately before any commit if
  the session has been long-running or if there's evidence of concurrent
  work in the tree.
- **Coordinate branch choice up-front** when multiple agents share a
  working tree. The simplest convention: everyone on `main` unless
  Arthur designates a feature branch.
- **Worktree isolation** (`isolation: "worktree"` on Agent dispatch) is
  the safest pattern for dispatched agents in this environment — it
  gives each agent its own HEAD and tree, so concurrent commits don't
  cross-contaminate.
- **Stash-with-clear-label** is the established convention for preserving
  concurrent agent WIP if a branch swap is unavoidable:
  `stash push -m "<team>-WIP-<context> - preserve for other session"`.
