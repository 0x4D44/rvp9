## Scope reductions in F10.0 (the integration honest-list)

F10.0 landed as a SCAFFOLD: the public API shape is right and end-to-end works, but the F8.x mode-decision modules are **not yet driven by the frame loop**:

- F8.0 intra mode search is in the codebase + tested, but KF leaves are forced to DC_PRED in `frame_loop.rs`
- F8.1 inter mode search is in the codebase + tested, but Inter leaves are forced to ZEROMV/skip=true
- F8.2 partition search is in the codebase + tested, but every SB is forced to Block64x64

These are documented in the F10.0 commit message as `F10.1` punch-list. The integration is non-trivial because:
- F8.0 needs the F5.1 residual simulator generalised to accept arbitrary intra modes (not just DC)
- F8.1 needs a real InterCoefSource impl + an encoder-side recon mirror of `reconstruct_inter_block`
- F8.2 needs an adapter from `PartitionDecision.cells[8][8]` to the mi-grid splat the writers expect
