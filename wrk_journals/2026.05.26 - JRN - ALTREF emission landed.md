## What landed

1. **`EncoderConfig.enable_alt_ref: bool`** (default `false`). Plumbed
   to every literal via `scripts/w8_add_enable_alt_ref.py` (script
   mirrors `w7_add_lag_in_frames.py`; anchor on the EncoderConfig-
   unique `lag_in_frames: <expr>,` line, idempotent). 23 files touched
   by the script.

2. **`StreamEncoder.altref_recon_{y,u,v}: Vec<u8>`** plus
   `pending_arf_packet: Option<Vec<u8>>` and
   `inter_frames_since_arf: u32` fields. Allocated unconditionally;
   seeded from the KF reconstruction every keyframe (mirrors the
   decoder's implicit `refresh_frame_flags = 0xFF` on KF). Slot 2
   never refreshed when ALTREF gate is closed — same byte-state as
   pre-W8.

3. **`build_inter_packet_with_residuals` gained a `show_frame: bool`
   parameter.** Threaded into the `UncompressedHeader` literal at
   the existing single call site (`/* show_frame = */ true`). The
   writer's `intra_only = 0` bit is emitted when `!show_frame`
   (`crates/rvp9-core/src/bitstream/header.rs:675-678`).

4. **`StreamEncoder::encode_altref_internal`** + helper
   `try_build_arf_packet`. The ARF path:
   - Builds an `ArnrFilterData` with the just-popped frame as the
     alt-ref source (`alt_ref_index = 0`) plus up to 2 forward-peeked
     neighbours from the lookahead. Strength fixed at 3 (libvpx's
     `adjust_arnr_filter` default).
   - Runs `temporal_filter::vp9_temporal_filter`.
   - Emits via `build_inter_packet_with_residuals` with
     `show_frame = false` + `refresh_frame_flags = 0x04`
     (bit 2 = `ALT_REF_FRAME_IDX`). The all-skip ZEROMV partition
     produces a valid VP9 inter frame whose slot-2 reconstruction
     mirrors LAST (decoder's slot 0).
   - Persists the post-ARF `decoder_fc_state` (the decoder's FC bank
     advances on every decoded frame, visible or not).
   - Does NOT touch `last_recon_*`, `me_ref_*`, `golden_recon_*`,
     `prev_mv_grid`, `cyclic_refresh`, `pre_analysis.consec_zero_mv`,
     `rate_control`, or the encoder-side `frame_context`. Stream
     state isolation by construction (the all-skip ZEROMV path
     reads from these but mutates only `altref_recon_*` +
     `decoder_fc_state`).

5. **Cadence + superframe pack** inside `try_encode_one_popped`:
   - Trigger: `frame_kind == Inter` AND `config.enable_alt_ref` AND
     `inter_frames_since_arf >= gop_length / 2` AND lookahead has
     ≥1 neighbour peek-able. Defends against accidental fires:
     `pending_arf_packet.is_none()` guards re-entry.
   - Emit: stash the ARF bytes in `pending_arf_packet`, reset
     `inter_frames_since_arf = 0`. Encode the show frame normally.
     Pack `[arf, show]` into a `SuperframeBuilder` (libvpx
     `vp9_encoder.c:5093-5142` `vp9_pack_bitstream`). The
     `EncodedFrame::data` carries the superframe bytes; the
     `frame_kind` and rate-control bookkeeping reflect the visible
     frame.

6. **PROOF test (`crates/rvp9-encoder/tests/w8_altref_emit.rs`):**
   - `w8_altref_emits_non_show_packet`: 16 inputs at
     `gop_length=16, lag=8, enable_alt_ref=true` → decoded stream has
     16 show frames + ≥1 non-show frame. Anti-G3: asserts strict
     `non_show >= 1` (a stub that doesn't emit an ARF would pass
     the show-count check otherwise).
   - `w8_altref_disabled_emits_no_non_show_packet`: same shape,
     `enable_alt_ref = false` → zero non-show frames. Guards the
     cross-decoder gate's invariant.
   - `w8_show_frame_count_matches_input_count`: 3 sweep configs
     ((20,10,6), (32,16,9), (48,24,13)) all map input frames to
     decoded show frames 1:1.

## Scope-down honesty

What I did NOT do (vs the assessment's full vision):

- **No per-leaf inter pick on filtered ARF pixels.** The ARF emission
  uses an all-skip ZEROMV partition. The slot-2 reconstruction is
  therefore just a copy of LASTFRAME, not the filtered pixels. Real
  ARF residual coding would feed the filtered YUV into the inter
  picker + simulator (the `pick_and_simulate_inter_encode_partitions`
  path), producing residuals that reconstruct the filtered pixels.
  That requires either a state-snapshot/restore around the full inter
  encoder (~200 LOC + complexity around the picker's per-leaf
  filter/coef bookkeeping) OR an `is_arf` flag plumbed through every
  `self.*` mutation inside `encode_inter_internal` (~150 LOC).
  Deferred — the wiring PROOF doesn't require it: no picker iterates
  slot 2 today (`picked_ref_frame ∈ {LAST, GOLDEN}`), so the slot's
  contents are unreachable.

- **No widening of the per-leaf picker to enumerate `RefFrame::AltrefFrame`.**
  That's the only path through which slot 2 could actually be read.
  The "make ARFs reduce inter-frame residuals" benefit only lands
  when the picker iterates ALTREF too — a follow-up wave.

- **No CLI flag for `--auto-alt-ref`.** The CLI literal carries
  `enable_alt_ref: false`; opting in is currently a build-time
  config-struct field change. CLI plumb is a 5-LOC follow-up.
