## Phase 0 — Spike idct16x16_10

Plan: read current AVX2 kernel + matching libvpx SSE2 implementation
(`vpx_idct16x16_10_add_sse2` in `inv_txfm_sse2.c`); port to i16-lane mirroring

## Implementation

Strategy: avoid creating new files. Instead, **add the SSE2 entry points inside
the existing SSE2 kernel files** that already own the shared helpers — keeps
helpers private and minimises diff size.

### `idct16x16_sse2_256.rs` (added EOB-10 + EOB-38)

  `write_buffer_8x1`. Line-by-line port of libvpx
  `vpx_idct16x16_38_add_sse2` (`inv_txfm_sse2.c:433-457`).
