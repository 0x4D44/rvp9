# Unit 1364 — zero-vertical-phase horizontal sub-pel shortcut

## Decision

Keep the direct horizontal path for `yoffset == 0` in
`crates/rvp9-core/src/dsp/x86_64/subpel_variance_avx2.rs:228-267`. The vertical
bilinear taps are `[128, 0]`, so the second pass is an identity. Computing the
horizontal result directly into the byte temp removes the extra widened row and
the vertical pass while preserving the existing exact variance reduction.

## Evidence

Against a binary built from Unit 1363, the full relaxed Crucible screen measured
`0.991543x` paired and `0.993984x` separate across ducks, in-to-tree, and
old-town. The paired corpus gain is 0.85%, and every candidate and anchor stream
hash matched.

The x86 red mutation shifted the helper's right-neighbour load by one byte; the
focused differential failed at `w=4, h=4, xoff=1, yoff=0`. Restoring the load
made the focused test pass.
