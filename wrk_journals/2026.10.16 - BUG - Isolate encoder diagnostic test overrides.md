# RVP9-BUG-FLUX-00024 — Isolate encoder diagnostic test overrides

The encoder's unit tests changed process environment variables to select
diagnostic policies. Their mutex covered only participating tests. Ordinary
encoder tests could read an override between two otherwise identical encodes,
causing intermittent packet mismatches such as the tight/strided frame test.

The bounded fix introduces a private diagnostic environment shim. Production
builds reexport the standard environment readers unchanged. Unit tests use
thread-local overrides with explicit missing-value masks and scoped restoration
on normal return or unwind. All encoder test setters and relevant readers use
that shim. Existing serialization for shared diagnostic counters remains.

Submitted encoder worker jobs inherit a snapshot of the submitting test's
overrides, then restore the worker's previous state when the job finishes. This
keeps parallel encoding tests meaningful and prevents persistent workers from
retaining an earlier job's settings. The production job wrapper is an identity
function. No public configuration or dependencies change.

## Deterministic regression evidence

The encoder regression orders two threads with channels. One holds a fixed-Q
override and proves its own encoder sees that Q. While it remains active, an
ordinary thread constructs and encodes the same frame, then compares its Q and
packet bytes to a clean baseline. This avoids scheduling-dependent sleeps.

The fails-before reversal uses a synchronized shared-map backend to recreate
the old process-global visibility safely. The named regression failed its Q
assertion: the unrelated encoder selected 100 instead of the clean baseline 4.
This is a root-cause reversal, not a repeated attempt to reproduce the original
intermittent full-suite failure. It performs no unsafe environment mutation.

Two supporting tests were each calibrated separately. Omitting snapshot
installation failed the real high-precision-MV policy assertion on a persistent
worker. Omitting scope restoration failed the nested-value assertion with
`Some("100")` instead of `None`. All three runs selected their intended test
and exited 101 from an assertion failure. The real implementation was restored
after every reversal. The final worker test also checks snapshot-at-submission,
explicit absence, caller isolation, and cleanup between jobs on the same thread;
the scope test checks restoration after an unwind.

`git diff --check` passed. Clippy emitted no warnings. Final source inventory
found no standard-environment setters/removers in encoder source and no
unadapted readers of mutated keys in core. Production reads retain the standard
environment implementation; existing OnceLock policy caches are unchanged.

The selected final smoke is `cargo test -p rvp9-encoder --lib
diagnostic_override`, bounded to 60 seconds after the final fetch/catch-up.
Independent read-only review found no issues in the final 13 Rust files,
combined SHA-256
`0ba6b4686c8857cc115d5a44fc169f39401d451d0d60c36f8879f05682d3ac0b`.
