# Pin Stage 4a final source validation wiring — KILN-00068

The Stage 4a finalizer re-hashed the ignored corpus before choosing PASS, but its regression tests exercised only a reason-string formatter. Removing the real file-hash block therefore left those tests green. Finalization also overwrote the startup source hash, losing the first value named in its drift reason.

The selected correction tests the actual finalization and JSON-writing path using tiny ignored source files in isolated Git fixtures. Each fixture keeps unrelated worktree and source-tree validation clean so a different failure cannot hide missing source validation. Startup `source_sha256` remains intact and a new additive `source_final_sha256` field records the final read.

The current report initializer is shared with the fixtures. Production initialization and the startup check retain the fixed Foreman SHA-256 pin; no environment, command-line, or deserialization override is introduced. Final refresh uses the existing expected-hash report field so a test can supply a tiny source and exercise the same finalizer instead of a separate test-only path. The initial Git identity is still captured once and passed to the initializer.

Observed regression proofs:

- Removing the actual final `sha256_file` wiring block selected all six tests. Each of the three negative report cases failed `final source validation must block PASS`: actual PASS, expected FAIL, while `validation_clean` remained true. The new positive case also failed because its final fingerprint was null. Both retained formatter tests stayed green, reproducing the original coverage gap directly.
- Restoring real hashing but reinstating the original overwrite of `source_sha256` failed the changed-source test at `retain run-start corpus fingerprint`: observed changed digest instead of the initial digest. The intended preservation was restored manually.
- Giving the unchanged-input control a deliberately wrong expected pin selected its one test and failed `unchanged pinned input must pass finalization`: actual FAIL, expected PASS. The correct fixture pin was restored.
