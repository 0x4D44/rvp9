# Reject duplicate F02 schema fields — KIL-00090

The queue selected KIL-00090 and the task claimed it before inspection. `parse_jsonl_line` assigns each recognized top-level field into an `Option` slot without checking whether it is already populated. A repeated identity or decision key therefore overwrites an earlier value before strict oracle comparison.

The bounded correction rejects a repeated recognized field, including repeated identical values and fields whose first value is false, zero or an explicit NONE tag. Existing unknown-field forward compatibility, optional/default fields and valid writer round trips remain intact. A shared set-once helper over the existing slots avoids a second schema-key list or a parser rewrite.
