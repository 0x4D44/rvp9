# Unit 1367 — fixed-shape sub-pel wrapper inline hint rejected

The fresh Unit 1366 profile left the AVX2 16×16 sub-pel variance kernel at
6.97% of weighted x86 samples. I tested the smallest plausible compiler hint:
`#[inline]` on the eleven generated fixed-shape wrappers, hoping LLVM would
constant-propagate each block shape into the shared implementation.

The Crucible x86 release differential passed 5/5. A ten-pair alternating timing
screen produced identical hashes but a roughly 0.4% three-clip regression;
the ducks-only 20-pair screen also regressed. The hint was removed. See
`wrk_docs/evidence/2026-09-19-unit1367-inline/summary.txt`.

Decision: do not retain the hint. This is exactly the kind of Tesco-sized
change worth screening, but it does not buy time in the production-shaped
encode loop.
