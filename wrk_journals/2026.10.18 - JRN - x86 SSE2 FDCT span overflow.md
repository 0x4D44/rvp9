# x86 SSE2 FDCT span overflow

RVP9-BUG-FLU-00049 is fixed by computing the SSE2 8x8 DCT input requirement with `checked_mul(7)` and `checked_add(8)` before the unsafe row loads. The helper returns no span when either operation overflows, so the wrapper rejects the geometry before raw pointer arithmetic.

The regression first ran with overflow checks disabled and failed safely: `stride = usize::MAX / 7` produced the wrapped `Some(6)` instead of `None`. After the fix, the native arithmetic regression passed. Under Rosetta, the x86_64 `fdct8x8` test filter passed all eight tests, including the overflow regression and existing SSE2 scalar-parity/guard tests. Scoped x86_64 Clippy with `-D warnings`, `cargo fmt --all --check`, and `git diff --check` passed. The exact overflow regression smoke completed in 18.62 seconds.
