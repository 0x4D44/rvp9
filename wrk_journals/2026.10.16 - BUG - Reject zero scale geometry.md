# Reject zero scale geometry — KIL-00079

`valid_ref_frame_size` checks the reference/current ratio using widened arithmetic, but a pair of zero dimensions satisfies those inequalities. `ScaleFactors::new` then reaches division by the zero current axis. A single zero opposite a positive dimension is already rejected; paired zero widths, paired zero heights and the all-zero tuple expose the missing precondition.

The bounded fix rejects any zero reference/current axis before the ratio checks. It reuses the constructor's existing invalid-scale return, including both invalid scale factors and zero step fields. Positive dimension ratios and valid VP9 stream behavior retain their existing implementation. This extends the public safe API's invalid-geometry guard; it does not introduce a different scaling rule for valid codec frames.

Observed reversal 1: the new predicate regression selected one test against the old implementation and failed at `accepted zero dimensions for (0, 0, 0, 0)`.

Observed reversal 2: the independent constructor regression selected one test against the old implementation, caught its division-precondition debug panic, then failed its own `result.is_ok()` assertion with `ScaleFactors::new panicked for (0, 0, 0, 0)`. Thus the predicate assertion does not mask the constructor defect. The lead inspected both captured failure logs.

Both regressions passed after the guard was added. The worker's formatting and scoped `cargo clippy -p rvp9-core --lib --tests` checks passed. The lead independently reviewed the diff, checked whitespace, and ran `TMPDIR="$PWD/.scratch" deltic timeout 180 cargo test -p rvp9-core inter::scale::tests:: </dev/null`: all 22 selected tests passed, including existing positive ratio boundaries, identity, reference interpolation and differential cases.

Before final catch-up, the final smoke was selected as `TMPDIR="$PWD/.scratch" deltic timeout 60 cargo test -p rvp9-core inter::scale::tests:: </dev/null`. No decoder conformance, throughput or quality claim is made.
