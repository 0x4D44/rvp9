# RVP9-BUG-KILN-00069: ALTREF partial-height frames

Fixed the existing Open bug under the manual bug-drain instruction. The claim
is `fix-20261015T222031Z-c71ab272`; this change addresses only that bug.

The temporal filter rejected dimensions not divisible by 32, despite the stream
encoder accepting positive even heights. Its source slabs and output loops also
assumed complete blocks. Partial blocks now use replicated source edges and write
only visible pixels; block traversal rounds up. The public row routine retains
source strides and the dispatcher returns packed visible planes.

ALTREF reconstruction separately allocated visible-height planes, while
`InterReconLayout::full` and the reference pool require height rounded up to 64.
Its allocation now uses `reference_storage_height`, keeping the visible dimensions
passed to the codec unchanged.

## Regression evidence

`w_altref_partial_height` exercises 1280x720, 1920x1080 and 64x96 in both delayed
encoding and flush. Each case requires a non-show ALTREF inside a superframe,
checks its emission phase, actually decodes every subframe, and checks nine show
frames for nine inputs. A seventh test checks patterned pixels at partial right
and bottom edges, strided planes, untouched row padding, and a 2x2 source.

Independent root-cause reversals, with fixed tests retained:

- Replacing the temporal-filter changes with the original implementation makes
  `altref_partial_height_720p_delayed` fail on the BW/BH alignment assertion and
  the regression's explicit no-panic assertion.
- Replacing only the reconstruction allocation with visible-height planes makes
  `altref_partial_height_32_not_64_delayed` fail on the reconstruction layout
  assertion: 6144 bytes supplied versus 8192 required, followed by the regression's
  no-panic assertion.
- Replacing the temporal-filter changes with the original implementation also
  makes `altref_partial_blocks_preserve_visible_pixels_and_strides` execute and
  fail on the alignment assertion; restoring the implementation passes it.

Focused checks passed with both fixes applied:

- `cargo test -p rvp9-encoder --test w_altref_partial_height -- --test-threads=1`:
  seven passed.
- `cargo test -p rvp9-encoder --test w8_altref_emit --test w_altref_picker --test w_altref_real_coding -- --test-threads=1`:
  six passed; two existing external-vpxdec tests ignored.
- `cargo test -p rvp9-encoder --lib temporal_filter::`: six passed.
- `cargo fmt --all --check` and `git diff --check`: passed.

Validation uses in-memory codec state and worktree-local build/scratch files.
External libvpx parity and the full workspace suite were not run for this focused
geometry fix. Independent closure remains for a different verifier after landing.
