# RVP9-BUG-KIL-00125 — Asymmetric CLI plane and geometry oracles

The CLI fixtures generated identical U and V samples, allowing the decoder's
YV12 swap comparison to pass even if its two chroma planes were never swapped.
Most ordinary roundtrip coverage also used square dimensions and size checks,
which cannot distinguish width from height.

Both existing fixture generators now use different chroma patterns. The existing
`dec_yv12_swaps_u_and_v_vs_i420` first requires distinct decoded U and V planes in
every frame, then checks the YV12 positions against their I420 counterparts.

A new ordinary 128×64 roundtrip checks IVF width, height and frame count, Y4M
width and height tokens, exact frame boundaries, and corresponding Y/U/V slices
against I420 output. It also checks decoded U/V inequality and a wide plane-mean
gap grounded in the source fixture, so shared output packing cannot silently
reverse the two chroma identities. Pixel values are not compared exactly with
lossy source samples. No production code remains changed.

## Evidence

- The strengthened existing YV12 test failed against the old fixture at frame
  zero's `assert_ne!`: decoded U and V were identical. After changing the fixture,
  the selected test passed.
- A temporary decoder mutant omitted the YV12 swap. The same selected test then
  failed its U-to-YV12-second-half equality. The production file was restored
  byte for byte, its hash matched, and its git diff was empty. The restored test
  passed again.
- The new rectangular test failed with actual IVF height 64 against a deliberately
  transposed expected height of 128. The correct expectation was restored and
  the test passed. This is geometry-oracle calibration, not a production defect.
- The complete `cli_roundtrip` integration target executed 12 tests; all passed
  with the new fixtures. The focused YV12 regression separately selected and
  passed one test. The adjacent `dec_format_flags_last_wins` also passed.
- `cargo fmt --all --check` and scoped Clippy checks (both CLI test targets and
  CLI `--all-targets`) exited successfully with no warnings.

All test commands used stdin at EOF, harness timeouts, and `TMPDIR` set to this
worktree's `.scratch`, keeping the existing temporary-fixture helpers isolated.
No external corpus or full workspace test suite was needed. The preselected final
smoke is the exact rectangular test, bounded to 60 seconds after fetch/catch-up.

The lead reviewed the two test-file changes and the red/green logs. This fixing
pass leaves the bug Fixed for a different verifier rather than self-closing it.
