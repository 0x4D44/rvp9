## Update — entropy HLD signed off, implementation dispatched

H5/H6 two-pass dequant split** taxes the eob-dominated token loop — 95.5%
of transform blocks are all-zero (libvpx: one read + return), yet we pay a
RefCell borrow + token_cache memset + 4 Vec clears + OnceLock atomic load +
indirect `plane_dequant_finisher` call per block, to vectorize a path that
fires on only 2.6% of blocks. Bool reader (H1) refuted — it's a faithful
libvpx port. Oracle plan is excellent (reuses verbatim
`decode_coefs_libvpx_ref` differential + `RVP9_DEBUG_REFCOEFS=1` + 201/201).
