### S4.16b — `write_inter_block_mode_info` (`f16d856`)

Agent dispatch. Per-inter-block mode-info writer in
`inter/mode_info.rs`, mirror of `read_inter_block_mode_info`
(lines 760-842) for parent blocks (`block_size >= Block8x8`). Sub-8
deferred to S4.16b-sub.

Wire-order replicates the decoder step-for-step:

1. **Reference frames** — `is_compound` derived from
   `mi.ref_frames[1].is_inter()`. `ReferenceMode::Select` triggers
   one `comp_inter` bit; `Compound`/`Single` are debug-asserted.
   - Compound: `sign_bias[comp_fixed_ref]` picks the variable slot;
     emit `bit = (var_slot == comp_var_ref[1]) as u8`.
   - Single: LAST→`0`, GOLDEN→`1,0`, ALTREF→`1,1`.
2. **Inter mode** — `INTER_MODE_TREE` walked via `write_tree` against
   `fc.inter_mode_probs[ctx]`.
3. **Switchable interpolation filter** — only when
   `params.interp_filter == Switchable`. `SWITCHABLE_INTERP_TREE`
   walked via the same generic helper.
4. **MV residuals** — only for NEWMV. Per active ref slot, replicate
   the decoder's `resolve_parent_mvs` ref-mv computation
   (`find_mv_refs → mvs[count-1] → lower_mv_precision`) and emit
   the diff via `write_mv`. NEAREST/NEAR/ZERO emit zero MV bits.

To keep the inter writer from re-inventing the tree-walk inverse,
the existing `inter/mv.rs::write_tree` helper (from S4.16a) was
promoted from private `fn` to `pub(crate) fn` so both
`INTER_MODE_TREE` and `SWITCHABLE_INTERP_TREE` can reuse it.

New error type: `InterModeWriteError { Sub8NotSupported, NotInter }`
with hand-rolled `Display + std::error::Error` (matches repo
convention — `thiserror` is not a dep).

7 round-trip tests cover NEAREST/ZERO/NEW single-ref, compound
ZERO with sign-bias-driven `comp_fixed_ref`, switchable interp
filter emission, and structured rejection of sub-8 + intra inputs.
rvp9-core: 658 → 665.

### S4.16c — `write_tile_inter` partition walker (`5d672db`)

Agent dispatch. The biggest commit of this session (+1340 ll
modes_writer.rs). Three new functions:

1. **`pub fn write_tile_inter`** — SB-major frame-encoder entry,
   mirror of `write_tile_intra_keyframe` for non-keyframes.
2. **`write_inter_partition_tree`** — private recursive walker.
   Structurally identical to S4.13's `write_partition_tree` but uses
   `fc.partition_prob[ctx]` instead of `VP9_KF_PARTITION_PROBS[ctx]`
   and dispatches to the inter leaf emitter.
3. **`write_inter_block_leaf`** — private per-leaf emitter mirroring
   the decoder's `decode_inter_block`. Wire order: `skip` / `is_inter`
   / `tx_size` / `write_inter_block_mode_info`.

Plus a private `MiGridNeighbourLookup<'_>` adapter that builds a
`NeighbourLookup` view rooted at each leaf's (mi_row, mi_col), so
the context-derivation helpers from S4.16b can resolve above/left
neighbours from the encoder's mi_grid.

The agent's structural refactor: the existing private
`write_partition(bw, ctx, partition)` was widened to
`write_partition(bw, probs: &[u8; 3], partition)`. Keyframe callers
now pass `&VP9_KF_PARTITION_PROBS[ctx]`; inter callers pass
`&fc.partition_prob[ctx]`. The bit-walk topology was already
identical so this is a strictly additive simplification — both
paths share one helper, the keyframe path is unchanged.

v1 invariants (enforced by structured rejection):
- `segment_id == 0` and `!seg_id_predicted` (no segmentation).
- `skip == true` at every leaf (residual coefs deferred).
- No intra-in-inter (`mi.mode` must be `BlockMode::Inter`).
- Sub-8 inter leaves bounce through
  `InterModeWriteError::Sub8NotSupported` surfaced via the new
  `ModesWriterError::InterModeWrite { source }` variant.

The `allow_select` flag for tx_size collapses: under v1's
`skip=true && is_inter=true`, libvpx's
`allow_select = !skip || !is_inter` is always `false` for our
leaves. So `write_tx_size` always takes the non-select path (zero
bits emitted) and the writer derives `effective_tx_size =
min(max_tx, tx_mode_to_biggest_tx_size(tx_mode))` for the
debug-assert.

11 new tests — 5 round-trip (NONE-ZERO / SPLIT 4× mixed-modes /
HORZ / VERT / NEWMV with non-zero MV) + 6 scope-rejection
(intra-leaf / non-skip / non-zero seg / missing cell / non-mult-of-SB
/ sub-8). The test-side replay uses an in-test `TestPartCtx` mirror
of the decoder's tile-level partition context (the real one is
private to `rvp9-decoder`). rvp9-core: 665 → 676.

### S4.16d — end-to-end inter-frame round-trip (`1a8ab75`)

Agent dispatch. The S4.13 sibling for inter frames: build a 2-frame
sequence (keyframe + inter), feed both packets through one
`Decoder`, assert the recovered inter mi_grid matches the input.
First proof-of-life for the encoder's inter-frame path through the

Frame 1 (keyframe): 64×64 PARTITION_NONE DC-skip intra-only. Same

Frame 2 (inter): 64×64 PARTITION_NONE LASTFRAME ZEROMV skip=true.
Uses `write_tile_inter` with `InterModeReadParams` single-ref

AllowTx32x32`.

new FrameBuf across all 8 `ref_frame_map` slots regardless of the
`refresh_frame_flags` mask** (mirrors libvpx implicit 0xFF behaviour
at `lib.rs:983-985`). So whatever refresh mask the keyframe header
advertises is ignored at decode time. The inter frame's
`ref_frame_indices = [0, 0, 0]` resolves cleanly regardless.

rvp9-decoder: 101 → 102.

### S4.13 — recursive partition writer (`2fdf76c`)

Dispatched to agent. The writer's v1 had pinned every 64×64 SB to
`PARTITION_NONE`; this commit replaces the inner SB loop with a fully
recursive `write_partition_tree` mirroring the decoder's
`decode_partition` 1:1.

New module pieces:
- `infer_partition(grid, ..., bsize) -> Result<PartitionType, _>` —
  inspects the leaf at the parent's top-left cell, matches against
  `bsize`, `subsize(bsize, HORZ)`, `subsize(bsize, VERT)`; falls
  through to `SPLIT` if the parent supports it. BLOCK_8x8 parents are
  scope-pinned to `NONE` (sub-8 partitioning still out of scope).
- `write_partition(bw, ctx, partition)` — emits the canonical 4-way
  tree-walk bit-sequence (`0` / `1,0` / `1,1,0` / `1,1,1`) against
  `VP9_KF_PARTITION_PROBS[ctx]`, exactly the inverse of
  `read_partition`.
- Recursive `write_partition_tree` — bsl/ctx/num_8x8/hbs match the
  decoder; switch on partition into one (NONE) / two (HORZ/VERT)
  `write_block_intra_keyframe` calls or four recursive calls (SPLIT);
  applies the libvpx partition-context-update gate.
- `write_block_intra_keyframe` widened to take a `leaf_bsize`
  parameter; neighbour-grid splat uses `leaf_bsize.n_8x8_wide()` /
  `.n_8x8_high()`.
- New `ModesWriterError::InconsistentPartitionTree {parent_bsize,
  leaf_bsize}` for malformed input grids.

11 new tests + 1 new whole-loop integration test
(`s4_13_round_trip_partition_split_64x64_through_decoder` —
encodes a 64×64 keyframe with SPLIT into 4× 32×32 leaves, decodes it
back through `Decoder::decode_frame`, asserts recovered mi_grid).
**Critical:** the all-NONE path produces byte-identical output, so
the two existing regression-guard tests

### S4.15 — encode_coefs (token writer) (`0a080f5`)

The big one. Dispatched to agent with the existing `decode_coefs`
test patterns as the bit-sequence ground truth (those tests at

New `pub fn encode_coefs` in `entropy/detokenize.rs` (+618 ll). The
agent flagged the load-bearing detail: the outer-NOT-EOB +
inner-ZERO-run loop structure is the only one the decoder parses

+ value tree + sign + terminal EOB. Three tests caught this on first
run.

Coverage: 16 round-trip tests across every token category
(ZERO/ONE/TWO/THREE/FOUR/CAT1..CAT6), boundary values (5,6 / 7..10 /
11,18 / 19,34 / 35,66 / 67,16450), zero-runs, block-full-to-seg-eob
(no terminal EOB bit), 100-iter random fuzz, all 4 TxSize values.
For Tx32x32 the test helper uses `dequant=(2,2)` so `(val*2)>>1`
cancels the `dq_shift=1` right-shift cleanly.

**Encoder is now wire-complete for non-skip residual.** The remaining
gap is integration into the encoder API (the writers exist; the
mode-decision driver doesn't yet feed them).

### S4.16a — write_mv_component + write_mv (`e3ccdf0`)

MV-difference encoder primitives. Dispatched to agent. New module

`use_hp == false` contract: encoder must only be called with
`abs(diff)` even (so composed magnitude has LSB=1). Debug-asserted.
