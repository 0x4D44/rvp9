# Unit 1378 — AVX2 horizontal final-pair tail

## Decision

Retain and integrate. The x86 AVX2 horizontal 8-tap kernel now keeps the
final pair of rows on the existing 2-row SIMD path for even heights. It stages
only the final row into the existing zero-padded scratch, preserving the tight
source-footprint contract. Width 4 keeps the prior scalar tail split.

## Why this candidate

The preceding Crucible audit identified
`crates/rvp9-core/src/dsp/x86_64/convolve8_horiz_avx2.rs` as a measurable
production path. The old loop stopped before the final pair because the last
row cannot be over-read; both rows then paid the 128-bit single-row path. The
new path removes that avoidable tail cost without changing arithmetic or
source reads.
