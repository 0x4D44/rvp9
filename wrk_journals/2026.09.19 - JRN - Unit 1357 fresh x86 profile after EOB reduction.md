# Unit 1357 — fresh x86 profile after EOB reduction

Date: 2026-09-19
Base: `033bbd35c0549cc5c6db2ec71ff748fb2619d404` (Unit 1356 integrated)

## Purpose

Re-profile the integrated trunk on Crucible before choosing another bounded
kernel. The prior Unit 1356 AVX2 EOB reduction is now part of the control, so
this profile checks which work remains dominant rather than assuming the old
quantizer share is unchanged.

## Method

The Unit 1356 plain release encoder was run for twenty serial 60-frame
CPU-used-6 CBR encodes of the canonical ducks clip. Windows Performance
Recorder used the `CPU` profile in file mode. `xperf -symbols -a profile
-detail` decoded the ETL with the matching release PDB. The complete report,
manifest, hashes, and ranked table are in
`wrk_docs/evidence/2026-09-19-unit1357-profile/`.

The report contains 28,919,526 weighted samples mapped to `rvp9enc` symbols.
The top three are sub-pel variance (18.06%), the required inter-partition
simulation closure (11.14%), and the AVX2 quantizer inner loop (8.47%). The
next transform and search kernels are each about 3–4%.

## Decision

No new shipped code is justified by this profile alone. The required picker
work cannot be removed without changing strict decisions, and the two closest
local SIMD ideas already have negative screens: the mixed DC/AC quantizer had a
three-run production-PGO geomean of `0.996991x`, while the fused sub-pel pass
had a plain paired corpus of `1.004094x`. Repeating either would not be a
reproducible gain.

The safe resume point is a source-level attribution of the 18.06% sub-pel
kernel followed by a materially different implementation only if its measured
ceiling clears the retention bar. The latest direct pinned-libvpx screen is
`1.221x` on the relaxed Crucible protocol; reaching the `<=1.05x` target still
needs about 16% less RVP9 wall time from that measurement. Unit 1356's source,
tests, evidence, and integration journal are already on `origin/main`.
