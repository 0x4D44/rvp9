# Prime selected bitstream comparisons — KIL-00085

`diff-bitstream --frame N` skipped earlier packets before Level 3 probability-bank updates and Level 4 decoder state changes. Selecting an interframe could therefore make both fresh decoders fail identically and suppress the very comparison requested.

The correction primes each side independently before the selected packet range while suppressing diagnostics for that prefix. Level 3 retains its existing documented simplified probability-bank model; this task does not redesign reset/refresh semantics. Level 4 replays all subframes of each prior packet through its own decoder, with `--max-frames` checked before processing. Selected-range reporting and existing symmetric error suppression remain unchanged.

The Level 3 regression uses compressed headers generated by the production writer: prefix A leaves defaults intact, prefix B changes `skip_probs[0]`, and a common no-update inter header parses successfully from both calibrated banks and preserves them. Its synthetic pre-parsed FrameEntry objects exercise the Level 3 parser model; they are not complete VP9 frames. The selected packet must report the bank difference, match the packet-2 subset of the unfiltered comparison, and emit no prefix diagnostics.

The Level 4 fixture uses actual encoder output. Packet 1 is a two-subframe superframe (keyframe plus common interframe); packet 2 is the selected interframe. Both legs successfully parse and decode all three subframes with history, and their selected MI grids differ. A fresh decoder fails on the valid selected interframe with `DecodeError::EmptyInterRef { slot: 0 }`. The selected comparison must report actual MI paths, equal the packet-2 subset of unfiltered records, and remain silent before the selection. Controls cover a packet cap before the selection and an asymmetric malformed prefix, ensuring the valid leg still primes independently.
