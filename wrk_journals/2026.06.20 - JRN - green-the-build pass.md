### Clippy policy clarification (important)

`rust-toolchain.toml` (1.95.0) has been pinned since the Stage-0 scaffold (no
recent bump), and there is **no CI**. The root `Cargo.toml [workspace.lints]`
sets `clippy::all = warn` and **denies only** `undocumented_unsafe_blocks`,
`print_stderr`, `print_stdout` (`missing_docs`/`unsafe_op_in_unsafe_fn` are also
`warn`). So the project's real clippy gate = `cargo clippy --workspace
--all-targets` (no `-D warnings`), which fails **only** on the denied lints. The
green-the-build template's `-D warnings` surfaces 37 type_complexity / 21
needless_range_loop / 19 too_many_arguments / 12 collapsible_if / … — warnings
the project deliberately left non-blocking. Mass-refactoring those would impose a
stricter policy than the repo adopted → out of scope for this pass; parked for
Arthur.

### The 9 test failures, triaged

**SIMD differential proptests (4) — out-of-valid-domain test bugs, NOT kernel bugs:**
- `lpf_horizontal_4_avx2::scalar_eq_avx2_proptest`, `lpf_vertical_4_avx2::…` —
  both minimal failing inputs have **blimit=255**. The AVX2 kernel computes the
  `mb_diff` mask term in **saturating u8** (`_mm_adds_epu8`, capped at 255),
  mirroring libvpx's SIMD design; the scalar reference uses i32 (max 637).
  Divergence happens **iff blimit==255 and true mb_diff>255** (saturated 255 is
  not `> 255`). blimit=255 is **unreachable** in valid VP9 (libvpx

  two **full-density** (256 nonzero ±2047) strategies fail; `sparse_12`/`eob_38`

## Diagnosis — SIMD root causes (confirmed from kernel docs)

- **idct16x16 SSE2-vs-AVX2**: the SSE2 kernel uses *saturating* `_mm_packs_epi32`
  at every wraplow; the AVX2 kernel uses *modular* wraplow (`x as i16 as i32`).
  Identical for spec-bounded inputs (intermediates ≤ i16) → conformance 201/201;
  they diverge only when intermediates exceed i16::MAX. The two FAILING strategies
  (`uniform_12`, `eob_dense`) are full 256-coef density at ±2047, which overflows
  the i16 intermediate range; the PASSING strategies (`sparse_12`, `eob_38`) are
  low-density. The SSE2 module doc (lines 18-29) already states the proptest is
  "bounded ... because [pathological inputs] trip the saturation divergence and
  would fail spuriously" — the full-density i12 strategies violate that intent.

  **KILN-00010** with the triage plan (instrument whether intermediates actually
