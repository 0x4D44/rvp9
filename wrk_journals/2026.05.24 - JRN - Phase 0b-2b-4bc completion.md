## Log

### Phase 0b — Wire adapted FC into encoding pipeline
- Status: COMPLETE
- Changes:
  - `lib.rs`: Added `frame_context: &FrameContext` parameter to
    `pick_and_simulate_inter_encode_partitions`. Cost tables
    (`inter_mode_costs`, `mv_costs`, `intra_y_mode_costs_inter`) now
    built from adapted FC instead of defaults.
  - `frame_loop.rs`: Added `decoder_fc_state: FrameContext` field to
    `StreamEncoder` to mirror the decoder's FC bank. Passes adapted FC
    to both picker and packet builder. The compressed header diff-encodes
    decoder's FC bank → adapted FC, so the decoder reads content-adapted
    probs. `refresh_frame_context: false` preserved.
  - `compressed_header.rs`: Fixed `write_update_mv_probs` to handle even
    MV prob values by rounding to odd (`val | 1`) at the wire layer,
    since VP9 MV probs are always odd on the wire. Replaces a
    debug_assert panic.
- Key design: decoder FC bank tracking. The decoder's FC bank drifts
  from defaults because each frame's compressed header mutates it.
  Without tracking, the encoder's diff base would be wrong after frame 2.
  `decoder_fc_state` mirrors the decoder's bank exactly.
- Tests: 100/100 encoder, 1313/1313 core

## What's remaining (follow-up tracks)

1. **Phase 4b wiring**: `model_rd_for_sb_uv` exists but isn't wired into
   the picker's candidate comparison. Requires threading UV plane data
   through `PickInterModeParams` and adding UV rate/dist to the RD cost.

2. **Phase 2b non-skip**: v1 forces `skip=true` on all intra-in-inter
   blocks. Full residual coding (forward DCT + coef emission) for intra
   blocks would recover additional quality when the prediction isn't
   perfect.

3. **Coef count accumulation**: The writer doesn't accumulate coefficient
   counts during `write_block_tokens`. This means `adapt_coef_probs`
   receives zero counts → coef probs stay at default. Wiring coef counts
   through the token writer would enable coef prob adaptation.

4. **Decision gate**: Needs F.0.2 oracle harness with patched libvpx
   build to measure partition convergence on foreman_cif.
