## Change and correctness

The frame already computes baseline and boosted `InterRdCalibration` values for
the A4 descent. I replaced the final-leaf reconstruction of that value with
the existing `a4_rd_calibration_for_segment` selector. The selector test
passed cleanly. Swapping its arms made that test fail with exit 101; the
mutation was restored. The candidate and control release binaries produced
identical IVF hashes for every screen clip.

## Performance

The first three-pair screen was slower at 1.015899x paired. A second short
screen was effectively neutral at 0.999552x, so I ran a full 15-pair,
two-rotation screen. That decision run measured 1.003949x paired and 1.003106x
separate on the corpus. Per-clip paired ratios were 1.005829x (ducks),
1.000044x (intree), and 1.005986x (oldtown).

The candidate is rejected and reverted in `437e5360`. The evidence and the
rejection rationale are committed separately as docs-only material. No pinned
libvpx run was justified after the candidate lost to integrated control.
