# Mac Foreman pinned-vpxdec soak

Ran a bounded 60-second soak using the exact-candidate release binary and
verified `foreman_cif.y4m` from the evidence worktree. The source list logged
the 256×256 Foreman crop plus the synthetic gradient fallback. Cross-decoding
was enabled with the pinned libvpx `vpxdec`; its binary SHA-256 and checkout
revision are recorded in the qualification JSON.

The run exited 0 after 60.6 seconds with 23 iterations, 690 internally
decoded frames, zero reported errors and positive 174.7 kbps bitrate. The
current harness invokes `vpxdec` once for each iteration and fails if its
exit is nonzero, so each completed iteration passed that decoder exit check.
It does not compare decoded output hashes. The exact encoded-byte total was
not printed; positive bitrate is evidence of nonzero bytes. RSS remained
0.0 MiB and supplies no Mac memory-stability evidence.

The harness uses CBR speed 0 and lag 0; the input is cropped to 256×256. This
does not qualify production CPU6–8, denoiser or spatial modes, full-resolution
workloads, timing, quality, sanitizer, fuzz or long-duration behavior.

Validation: verified the candidate binary/source, pinned `vpxdec`, Foreman
input and libvpx revision before the run; parsed the qualification JSON,
checked all retained evidence hashes, and ran `git diff --check`.
