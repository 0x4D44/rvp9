# Unit 1372: packed AVX2 dqcoeff multiply rejected

This Tesco tried to remove the AVX2 quantizer's qcoeff sign-extension and
32-bit dequant multiply. It packed qcoeff once and used the low 16-bit lane
product, which is exactly the scalar cast's wrap behaviour.

The x86 AVX2 differential suite passed 4/4, the deliberate wrong-dequant
mutation failed as intended, and local AArch64 quantizer tests passed 24/24.
All output hashes matched. Three relaxed Crucible screens produced geomeans
of 1.007832x, 0.967217x, and 0.994512x. The middle result contains a single
13.3% ducks anchor outlier; per-clip medians across all runs produce 1.001522x.

I rejected the candidate as neutral/slower, restored the source on both
architectures, cleaned the exact temporary timing files, and kept this
evidence so the quantizer loop does not revisit an unstable apparent gain.
