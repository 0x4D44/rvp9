# Wave H — apply.rs wiring + lpf_*_dual AVX2 family + G7 full extension

Wave G ended with 19 of 19 transform slots wired and 6 single-variant
loopfilter slots populated with AVX2 impls. But:

1. **apply.rs still calls scalar fns directly** — F10 + G3-G6 wrappers
   are dead code in production.
2. **6 dual-variant lpf_*_dual fns exist as scalar-only** — no slots,
   no AVX2. apply.rs uses them on every SB for chroma + macroblock-
   internal edges.
3. **G7 prototype proves the F12 split-loop is feasible** but only
   the ONE_TOKEN arm is split. CAT1..6 + TWO/THREE/FOUR + sign-bit
   ordering remain fused.
4. **plane_dequant_pair slot stays scalar** until H5 lands.

Wave H closes all four gaps.

  `loop_filter_frame` before refactoring; thread `&SimdDispatch` down.

- **Worktree isolation per gap** with `git -C` discipline.

## Sub-sequencing rationale

H1 first because it activates the existing AVX2 kernels and gives
us the dispatch fixture for H2/H3/H4 to slot into. After H1, the
scalar dual slots are wired but scalar-only; H2/H3/H4 just swap the
slot pointer to an AVX2 impl. Pure additive work, low merge risk.

H5 last because it is the largest scope, but it can proceed in
parallel with H4 once H3 commits land (no file overlap with H4).

H6 is gated by H5.
