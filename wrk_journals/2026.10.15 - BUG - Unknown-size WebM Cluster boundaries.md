## Root cause and intended correction

Both packet walkers assign an unknown-sized element its parent's end offset,
then treat subsequent Cluster siblings as nested containers. A long valid
sequence therefore exhausts the depth limit. Cluster context also leaks across
metadata and root boundaries, allowing out-of-Cluster blocks to appear as packets.

Retain current master ID, parent ID and unknown-size state. Stop an unknown
Cluster before schema-defined Segment siblings or ancestor/root boundaries;
stop an unknown Segment at a new root element. Return the actual stop offset in
the memory walker; pop and reprocess the same header in the streaming walker.
Keep finite payload bounds and the depth cap. Void/CRC-32 remain current-parent
children, and payload bytes are never searched for IDs.

Primary references checked by the lead:

- [RFC 8794 section 6.2](https://www.rfc-editor.org/rfc/rfc8794.html#section-6.2).
- [RFC 9559 section 5.1.3](https://www.rfc-editor.org/rfc/rfc9559.html#section-5.1.3).
