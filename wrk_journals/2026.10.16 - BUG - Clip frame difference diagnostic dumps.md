# Clip frame difference diagnostic dumps — KIL-00088

The queue selected KIL-00088 and the task claimed it before inspection. `dump-frame-diff` renders a fixed 12-column by 8-row luma window and full 4×4 divergent block sections regardless of the visible frame edges. Small frames and bottom-edge blocks can panic. Partial right-edge blocks can also read the following row without a panic, producing a misleading diagnostic.

The bounded correction clips both rendering regions to visible dimensions. Two private writer-based helpers allow tests to exercise the same rendering main uses and inspect the emitted rows and values. The initial extraction preserves the old loops so regression failures can be observed before clipping. Full-size output, comparison statistics, block-grid selection and exit status remain intact; existing optional debug windows and surrounding patches are outside this change.

The revised extraction-only run selected two tests and both failed on combined symptom assertions. The fixed-window fixture caught panics at 1×1, 5×3, 11×8 and 12×7. The divergent-block fixture caught bottom/corner panics and a non-panicking 5×5 right-edge error: the first rendered row contained `[14, 15, 16, 17]` instead of `[14]`. Output checks parse the emitted rows, values and signed differences; a literal full 4×4 control pins existing formatting. The lead inspected the raw revised red log and the extraction-only source, confirming it retained the original unclipped iteration bounds and indexes.
