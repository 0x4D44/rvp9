# 2026.05.26 — JRN — compound (bidirectional) inter prediction LANDED

**Verdict: LANDED.** The rvp9-2 VP9 encoder now emits {ALTREF, LAST}
compound (bidirectional averaging) inter predictions through the RDO
dispatch picker, gated behind `enable_alt_ref && altref_slot_emitted`.
267 compound leaves on engineered content, BYTE-EXACT through vpxdec.
The sacred cross-decoder gate stays 4/4 byte-exact and unchanged.

This is the compound-specific layer on top of the four prerequisites the
prior blocker journal (`2026.05.26 - JRN - compound prediction blocker.md`,
commit cfd7024) identified — all of which were resolved by 0ad7e7d (real
ALTREF + sign bias) and 70f97eb (ALTREF picker iteration).

## What landed

### 1. reference_mode in the frame header
`build_inter_packet_with_residuals` (`frame_loop.rs`) now derives
`compound_allowed` from the header sign biases EXACTLY as the decoder does
(`compound_allowed = sign_bias[1] != sign_bias[0] || sign_bias[2] !=
sign_bias[0]`, libvpx `vp9_compound_reference_allowed`
`vp9/common/vp9_pred_common.c:16-22`; decoder side
`rvp9-decoder/src/lib.rs:2317`). When compound is allowed (the ALTREF
picker is live → header bias `[false, false, true]`) the frame emits
`REFERENCE_MODE_SELECT` and the per-block `comp_inter` bits choose single
vs compound per leaf. When NOT allowed (every bias equal — the gate's
`enable_alt_ref = false` config) the field is absent and the bitstream is
byte-identical. Threaded into both `CompressedHeaderOptions.compound_allowed`
+ `CompressedHeaderResult.reference_mode` (the core writer
`write_frame_reference_mode` / `write_frame_reference_mode_probs` already
existed) and the per-block `InterModeReadParams.reference_mode`.

### 2. Compound candidate in the RDO dispatch picker
`pick_inter_sb_leaf` (`rdo/inter_dispatch.rs`) gained a `compound_enabled`
gate and an `evaluate_compound_candidate` that scores ZEROMV + NEWMV
{LAST, ALTREF} compound modes. RD is REAL: `handle_inter_mode_compound`
(`rdo/handle_inter.rs`) builds the LAST prediction, then averages the
ALTREF prediction into the same buffer via the `_avg` convolve kernels
`(pred0 + pred1 + 1) >> 1`, and runs the same `super_block_yrd` (Y +
chroma) the single-ref path uses. The compound winner overrides the
single-ref winner iff its RD is strictly lower. NO synthetic model. libvpx:
`vp9_rdopt.c:3543-3556` (compound modes when reference_mode != SINGLE),
`vp9/common/vp9_reconinter.c:126-207` (averaged pred).

### 3. Compound MV search — SCOPED DOWN (documented)
libvpx `joint_motion_search` (`vp9_rdopt.c:2386-2480`, iterative fix-one /
search-other) is DEFERRED. We reuse the independent single-ref NEWMV
searches (`single_motion_search`, already run for the LAST and ALTREF
single-ref candidates) and form the compound NEWMV pred from those two real
MV results. The averaging + residual RD are fully real; only the iterative
joint refinement (which would at best tighten residuals a little further)
is deferred. ZEROMV compound is also evaluated. Both MVs are real ME
results, never zero (except the ZEROMV candidate).

### 4. Two-ref / two-MV emit path
`InterPartitionLeafDesc` gained `picked_ref_frame2` + `picked_mv2`. A
compound leaf carries `ref_frames = [LAST, ALTREF]` + `mvs = [last_mv,
altref_mv]` (slot 0 = LAST = the pair's `comp_var_ref[0]`; slot 1 = ALTREF
= `comp_fixed_ref`, derived from `setup_compound_reference_mode` with bias
`[false,false,false,true]`). The core writer derives `is_compound` from
`ref_frames[1].is_inter()` and emits the `comp_inter`/`comp_ref` bits +
both NEWMV residuals (`mode_info.rs:1013-1184`) — it needed ZERO changes.
The byte-exact recon (`build_inter_pred_plane_unscaled`, now with an
`is_compound_avg` parameter) builds slot 0 then averages slot 1, mirroring
the decoder's `for r in 0..num_refs` loop with `is_compound_avg = r > 0`
(`reconstruct_inter.rs:331-476`). The `out_mv_grid` writeback and the
mi-grid builder also carry both refs/MVs.

## The critical rounding detail
The compound average is `(a + b + 1) >> 1` (`round_avg`, `filter.rs:188`,
libvpx `ROUND_POWER_OF_TWO(a+b, 1)` `vpx_convolve.c:59`). The encoder reuses
the SAME `inter_predictor` → `_avg` convolve kernels the decoder uses, so a
1-LSB mismatch is structurally impossible — confirmed by the byte-exact
vpxdec gate.

## Gate-safety
With `enable_alt_ref = false` (the sacred gate's config, speed 7 RT path):
`altref_available = false` → `compound_enabled = false` (no compound
enumerated), `compound_allowed = false` → `reference_mode = SINGLE`, sign
biases all false. Bitstream byte-identical to before.

## Surprise / note
Emitting `REFERENCE_MODE_SELECT` when ALTREF is live also corrected the
ALTREF single-ref byte-exactness: single-ref ALTREF and compound coexist in
the same Select frame, each per-block `comp_inter`-selected, both
byte-exact through vpxdec. Single-ref ALTREF picks are NOT counted as
compound (the `RDO_DISPATCH_ALTREF_PICKS` counter only bumps when
`ref_frame2 == NoRefFrame`), so the two anti-G3 witnesses are disjoint.
