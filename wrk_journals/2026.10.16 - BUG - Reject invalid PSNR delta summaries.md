# Reject invalid PSNR delta summaries — KIL-00087

The queue selected KIL-00087. `psnr_at_bitrate` validates reference samples, but `psnr_delta_summary` can subtract a non-finite rvp9 PSNR and return a present summary containing non-finite statistics. An invalid rvp9 sample outside the reference span can also be silently counted as out of range while other samples produce a present summary.

The bounded correction validates every rvp9 sample before interpolation: bitrate must be positive and finite, and PSNR must be finite. Zero and negative finite PSNR remain valid. A small shared predicate may preserve the reference helper's existing validation without duplication. The summary also declines non-finite derived deltas or aggregate statistics rather than returning an unusable quality signal. This does not redesign interpolation or change valid-point coverage counts.

Three new focused regressions demonstrated assertion failures with one test selected in each run: the original implementation returned a present summary with a NaN mean for an invalid PSNR, and infinite statistics after a finite-input subtraction overflow. Removing only the new upfront input guard reproduced a present partial summary for a zero bitrate mixed with valid points; the guard was restored. Coverage also includes invalid samples on either side of valid points, invalid points outside the reference span, finite zero/negative PSNR, and same-sign accumulation overflow. Raw logs are retained in the task scratch directory.

The lead independently observed all 23 BD-rate module tests passing after reviewing the correction and all three red logs. The preselected final smoke is `TMPDIR="$PWD/.scratch" deltic timeout 60 cargo test -p rvp9-harness --lib bdrate::tests:: -- --nocapture </dev/null`. This pass makes no codec quality, performance, or conformance claim.

The lead also observed `cargo fmt --all --check`, `git diff --check`, and scoped `cargo clippy -p rvp9-harness --lib --no-deps` pass with no warnings after the final documentation correction.
