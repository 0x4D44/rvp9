# Sub-pixel horizontal reuse census

The exact pinned-libvpx profile made Tree and Town sub-pixel work the most
credible remaining hotspot. I measured repeated horizontal keys in successful
two-dimensional variance calls without changing search decisions or output.
The three-clip Crucible result and exact-output evidence are in
`wrk_docs/evidence/2026-09-26-subpel-horizontal-reuse-census/README.md`.

The result is a design input, not a performance result: 18.27% of Ducks 2D
calls and 34.16%/32.64% of Tree/Town 2D calls repeated a horizontal key with a
different vertical phase. Border repeats were under 1% of all repeats. The
diagnostic stays on local task commit `bca02daa`; production trunk remains
unchanged. Next discuss a bounded cache contract before implementing it, then
prove exact costs and outputs and retain it only for paired CPU gain.
