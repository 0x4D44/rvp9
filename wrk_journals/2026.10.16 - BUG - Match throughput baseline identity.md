# Match throughput baseline identity — KIL-00114

The ratchet selected the newest row per fixture from any allowlisted host, without filtering its stored build-profile identity. A newer row from a different host or profile could therefore replace a compatible baseline and produce a misleading comparison.

The correction selects by exact current host and explicit build-profile hash before reducing by timestamp. The ratchet helper enforces current-host allowlist membership; the library selector excludes unpinned rows and invalid metrics. The legacy public selector retains its behavior, with corrected documentation, and shares the timestamp reduction with the new selector. Existing CSV format, profile-token generation, timing collection and writer concurrency are outside this fix.

Observed assertion-red reversals, restored individually:

- Removing both identity filters selected an unexpected `missing.webm` fixture.
- Removing only host equality selected timestamp 90 instead of 20 (`newer incompatible rows must not win`).
- Removing only profile equality selected timestamp 80 instead of 20 at the same assertion.
- Bypassing the ratchet helper's allowlist failed `a host outside the allow-list has no eligible pinned baseline`.
- Replacing the helper's strict selector with the legacy selector selected timestamp 30 instead of 10.

Twenty throughput unit tests and the always-running ratchet identity test passed. The lead independently reran those 20 unit tests and the identity test. The entire ratchet target compiled with `--no-run`; scoped `cargo clippy -p rvp9-bench --all-targets -- -D warnings`, formatting and diff checks passed. Test runtime files used the task's absolute `.scratch` directory as `TMPDIR`. No vectors or benchmark timing measurements were run or claimed; the benchmark's debug/vector early returns do not establish selection correctness. The preselected final smoke after catch-up is `cargo test -p rvp9-bench --test decode_throughput_ratchet ratchet_baseline_requires_allowlisted_current_identity -- --exact`, bounded to 60 seconds.
