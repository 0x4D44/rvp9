Arthur approved prototyping the emit-path change on 2026-09-27, with exact output and paired production-PGO CPU as retention gates. This task worktree starts from integrated `a14c72db`; do not fold the older diagnostic branch's counters into production code.

The [design note](../wrk_docs/2026.09.27%20-%20HLD%20-%20deferred%20inter%20TX%20selector%20on%20final%20skip.md) and [Crucible census](../wrk_docs/evidence/2026-09-27-dead-tx-selector-census/README.md) are the starting evidence. The integrated direct ratio is 1.099305× pinned libvpx equal-clip process CPU. The diagnostic found alternate chroma EOB0 on 298,591/300,732 Ducks eligible leaves; its component wall timers are not a speed claim.

The first green unit extracted the existing inter predictor calls into one helper, preserving the primary and compound paths. A focused test compares the helper against the previous direct sequence with distinct reference pixels and MVs; the test was made red by mutation and restored. The helper test, encoder check, formatting, and existing compact-row and scaled-prediction checks passed on AArch64.

Next green unit: add a behavior-neutral two-TX chroma EOB proof helper with a focused red/green oracle. Then wire a narrowly gated early U/V prediction and selector bypass, checking on/off output, AArch64/x86 tests, canonical IVF hashes, and paired production-PGO CPU before deciding whether to integrate.

The second green unit added a state-neutral U/V TX8+TX4 EOB proof. It rejects partial visible leaves, unsupported UV sizes, and incomplete compact windows. The fixed one-pixel fixture is TX8-EOB0 but TX4-EOB-positive, and deliberately dropping TX4 made the new test fail. The new test, encoder check, formatting, and relevant existing inter tests passed on AArch64. This helper deliberately covers only UV blocks whose maximum TX is TX8; larger UV candidates require a separate proof before any bypass.

Next green unit: call the proof only after exact early U/V prediction on eligible leaves, bypass the selector only on success, and preserve the old path on any false result. First establish exact on/off output locally; then run the Crucible canonical clips and paired PGO CPU gate.
