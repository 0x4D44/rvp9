# Unit 1421 — AVX2 FDCT16 first pass

The current x86 profile gave FDCT16's first pass only about 0.96% of all
direct sample rows. Still, the existing two-batch SSE2 implementation offered
a bounded 16-lane experiment. The AVX2 first pass matched SSE2 intermediates
and scalar final output. An intentional store-index mutation made its new
test fail, confirming the test covered the changed path.

The first 30-pair Ducks encode screen was neutral and highly noisy. A second
90-pair, three-clip screen favored the candidate at 0.984x paired and 0.992x
separate-median corpus runtime, with byte-identical output. Two alternating
kernel measurements independently showed a 7–9% FDCT16 speedup. This is a
small retained gain, not evidence that the 1.05x libvpx parity target is met.
The complete benchmark inputs, commands, hashes, and raw rows are in
`wrk_docs/evidence/2026-09-25-unit1421-fdct16-avx2/`.
