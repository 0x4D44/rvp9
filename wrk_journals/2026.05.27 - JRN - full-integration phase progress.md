ON/OFF streams differ (3525 vs 2992 bytes); ON stream byte-exact across
rvp9-decoder + vpxdec. **Sacred gate 4/4** (both decoders agree on the new
RD-partitioned default stream). Lib 429.

Collateral test reconciliation verified clean (no assertion weakened): the A10
byte-identity golden in `w_buffer_pool.rs` was kept intact by pinning the pre-A4

### SVC temporal (A18) — LANDED (commit dc53eec, task #31)

Wired temporal SVC into the encode path. **Key correction of the brief (verified vs libvpx):** VP9 temporal SVC emits each access unit as a STANDALONE VP9 frame — temporal layers do NOT superframe-pack (only *spatial* layers do, `vp9_svc_layercontext.c:451`); `temporal_layer_id` is encoder-side metadata (`vpx_svc_layer_id`), not a wire field. The on-wire scalability is the per-frame ref/refresh structure (`:626-684`): enhancement frames are non-reference. So SuperframeBuilder was correctly NOT touched.

Wired: `EncoderConfig::temporal_layers` (1=off default); `StreamEncoder` holds `Option<svc::Svc>` via `Svc::alloc_layers`; `svc_assign_layer` drives `apply_temporal_layering` per inter frame (`vp9_one_pass_cbr_svc_start_layer`, `:769-830`); single-LAST-slot projection (tl0 → refresh `0x01`, enhancement → `0x00` non-reference); `EncodedFrame::temporal_layer_id` tag; CLI `--temporal-layers N` through `build_encoder_config`, mutually exclusive with `--auto-alt-ref`.

PROOF (`tests/w_svc_temporal.rs`, #[ignore] corpus tests): anti-G3 tids `[0,0,1,0,1,0,1,0]`, SVC bytes (4414) differ from single-layer (3525); oracle — SVC stream byte-exact through vpxdec (all 8 frames). **Single-layer gate 4/4 BYTE-IDENTICAL** (3525 unchanged, SVC opt-in). Lib 442.

Scope-downs (honest): **spatial SVC deferred** (needs per-layer downscale + inter-layer pred — large); 3-layer temporal tags correctly but the single-LAST-slot pool collapses the mid-layer referencing (true 3-tier needs the scaffold's multi-slot `fb_idx` routing wired to a multi-slot encoder ref model — follow-up). 2-layer temporal is fully faithful. Per-layer bitrate is an even-split placeholder (RC-only, never affects frame structure).

**Second Phase-II zone substantially closed** (temporal SVC real + byte-exact). Spatial SVC + faithful 3-tier tracked as A18 follow-ups.
