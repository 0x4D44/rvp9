# 2026.05.27 — JRN — TPL (A23) integration landed (bounded single-GOP)

## Outcome

**LANDED (bounded).** The ported-but-inert TPL subsystem
(`crates/rvp9-encoder/src/tpl/`) is now wired into the encode path behind
an opt-in `enable_tpl` flag (default OFF). A real single-GOP forward TPL
pass — a `mc_flow_dispenser`-equivalent driver — runs before each inter
frame's mode decision, producing real propagation stats that adjust the
per-superblock rdmult fed to the RDO inter picker.

Both gates green:
- **TPL-off**: cross-decoder gate 4/4 BYTE-EXACT (vpxdec + ffmpeg). The
  gate config (`enable_tpl = false`, speed 7) is doubly inert — TPL is
  gated off AND speed 7 routes leaves through the RT nonrd picker, which
  the TPL hook does not touch.
- **TPL-on**: byte-exact through vpxdec (294912 == 294912 bytes), AND the
  stream differs from TPL-off (8878 vs 8886 bytes over 12 frames).

## What the driver does (`tpl/driver.rs`, ~330 LOC)

`run_single_gop_tpl(window, last_recon_y, w, h, qindex, fc)`:

1. Builds a forward window = `[current_source, peek(0), peek(1), …]` up to
   `gf_interval` downstream source frames from the lookahead.
2. Walks the window in **reverse display order** (last frame first) so
   dependency flow propagates backward toward the coded frame. For each
   8×8 block of each frame:
   - `mode_estimation` (the ported primitive): 4 intra modes (SATD vs the
     block's own SOURCE neighbours) + an inter candidate (SATD vs an
     integer-pel MC predictor from a **real** `diamond_search_sad` full-
     pixel motion search — the encoder's shipped ME).
   - `tpl_model_store` recomputes `mc_dep_cost = intra_cost + mc_flow`.
   - `tpl_model_update` projects the block's dep flow into its reference
     frame's grid.
3. Computes `r0 = Σ intra_cost / Σ mc_dep_cost` over the coded frame's
   grid (libvpx `vp9_encodeframe.c:6162`).

Returns the coded frame's `TplDepFrame` + `r0`.

## Recon staging (matches libvpx — verified, no full recon needed)

Verified in `vp9_tpl_model.c::init_gop_frames` (`:73-96`): libvpx's TPL
does NOT reconstruct the GOP. The golden anchor uses the existing GOLDEN
recon, but `gf_picture[1].frame = cpi->Source` and every P-frame
`gf_picture[frame_idx].frame = &buf->img` (the *lookahead source image*).
`motion_compensated_prediction` (`:304-307`) reads `ref_frame->y_buffer`
directly — i.e. SOURCE pixels for the intra-window chain. So the only
"recon" the linear-P-chain TPL touches is the prior committed LAST
reference (the chain start), which this driver threads in as
`last_recon_y`. **No per-GOP recon staging was needed** — this was the
key scope-saving finding.

## cb_rdmult wiring

- New param `tpl_rdmult: Option<(&TplDepFrame, f64)>` on
  `pick_and_simulate_inter_encode_partitions` (`lib.rs`).
- Per-64×64-SB: `get_rdmult_delta(BLOCK_64X64, base_q_rdmult, r0, …,
  gf_group_index=1, layer_depth=0)` (`vp9_encodeframe.c:3719-3768`).
- Consumer hook (`vp9_encodeframe.c:2235-2242`): at the
  `InterDispatchLeaf::rdmult` site, substitute the SB's `cb_rdmult` when
  `Some` and `!= orig`, bumping `TPL_RDMULT_ADJUSTED_BLOCKS`.

## PROOF (`tests/w_tpl.rs`)

- `w_tpl_rdmult_adjusted_only_when_enabled`: OFF → counter == 0;
  ON → counter == 640. Fails if dispenser stubbed (stub ⇒
  `mc_dep_cost == intra_cost` ⇒ `beta == 1` ⇒ `cb_rdmult == orig` ⇒ 0).
- `w_tpl_on_stream_differs_from_off`: TPL-on ≠ TPL-off bytes; both decode.
- `w_tpl_on_byte_exact_through_vpxdec_and_differs` (#[ignore]): byte-exact
  vpxdec + differs.

## Scope-downs / follow-ups (honest)

- **TPL is non-RT** (matches libvpx `enable_tpl_model` only on Good/Best
  presets). The cb_rdmult hook lives on the RDO `InterDispatchLeaf` path
  (speed ≤ 4). At speed ≥ 5 (RT nonrd picker) the hook is inert. PROOF
  runs at speed 4.
- **Linear P-chain only** — no nested-ARF stack / OVERLAY / USE_BUF_FRAME
  (~400 LOC follow-up: the `arf_index_stack` walk).
- **Integer-pel inter predictor** — libvpx sub-pel-refines
  (`find_fractional_mv_step`); the propagation maths consumes the SATD
  pair, not the MV fraction (~80 LOC follow-up: route through 8-tap MC).
- **No quant roundtrip** (`recon_error`/`rate_cost` feed only the Qmode
  sidecar rvp9 doesn't expose).
- **TPL on the non-show ARF's own coding** is `None` (the ARF is a TPL
  `gf_picture[1]` frame in libvpx — follow-up).
- **Requires `lag_in_frames > 0`** for a forward window; with lag 0 the
  window is single-frame ⇒ honest no-op (no fake stats).
