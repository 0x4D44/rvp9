# v0.2.0-alpha.3 crates.io publication

RVP9 `v0.2.0-alpha.3` was published to crates.io from clean integrated
`origin/main` commit `abaffff4641ed98c2df414d8196df77f361c8285`. The shipped
code commit is `f91347d962bd615df00eb2f5dcf93ac0d850a430`; the final commit
only records the tracked safety fix as Fixed.

No Git tag, GitHub release, or binary archive was created. Arthur's request
was limited to crates.io publication.

## Qualification

- `cargo metadata --locked --format-version 1 --no-deps` reported the intended
  version, README, keywords, and categories for every public package.
- `cargo package --locked --list -p <crate>` included `README.md`,
  `Cargo.toml`, and `Cargo.lock` for every public package.
- `cargo publish --dry-run --locked -p <crate>` passed against registry-backed
  exact-version prerequisites before each upload.
- `cargo clippy --workspace --all-targets --locked -- -D warnings` passed on
  the integrated candidate.
- `cargo test --workspace --release --locked -- --test-threads=1` passed on
  the integrated candidate. The first parallel run hit the already tracked
  `RVP9-BUG-FLUX-00024` environment-variable race in
  `w_lag_zero_tight_and_strided_paths_match`; the focused rerun passed, and the
  full serialized run retained all assertions and coverage while removing the
  known cross-test environment race.
- The new `RVP9-BUG-KIL-00081` tile-view safety regressions failed on all three
  original symptoms before the fix, then passed in debug and release builds.
  The full release decoder suite passed: 225 unit tests, 4 panic-safety tests,
  and its available integration and doctest coverage. The local nightly
  toolchain did not have Miri installed, so this focused fix did not add a new
  Miri run.
- Official 307-vector conformance and both cross-decoder directions were last
  refreshed on ancestor codec commit `c9316971e1393c2270f29673efb64aa5b1c49f8c`.
  The only later shipped codec change is the tile-view geometry hardening above.

A clean registry install resolved every internal crate from crates.io:

```bash
cargo install rvp9-cli --version '=0.2.0-alpha.3' --locked --root <temp-root>
<temp-root>/bin/rvp9enc --version
<temp-root>/bin/rvp9dec --version
```

Both binaries reported `0.2.0-alpha.3`. `cargo uninstall` removed them and the
temporary install root was removed before the session ended.

## Continuing work

This alpha does not close final production parity. The quiet-host relative
speed and absolute-latency matrices remain pending. Experimental VBR and
temporal-SVC quality ceilings remain as declared in `PLAN.md`; the billion-run
fuzz and 72-hour soak are parked for the Intel fleet.
