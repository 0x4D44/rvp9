# Preserve horizontal loop-filter threshold overflow — FLU-00035

The AVX2 horizontal-16 mask doubles the p0/q0 absolute difference and adds half the p1/q1 difference using saturating byte arithmetic. Scalar computes the full metric, at most 637. Saturation preserves comparisons with thresholds below 255, but makes every overflow equal the maximum threshold 255 and incorrectly accepts those edges.

The fix widens the metric and comparison only for `blimit == 255`. Signed 16-bit lanes safely hold the full metric and the comparison masks pack back to byte masks. Other thresholds keep their existing path. The vertical sibling FLU-00034 and the rejected dual-filter fusion remain outside this fix.

The directed regression mixes eight columns with metrics 254, 255, 256, 607, 225, 255, 637 and 256, at two pitches and thresholds 193, 254 and 255. It checks the expected scalar acceptance decisions independently, then compares the full production scalar and AVX2 output buffers. Existing host-feature skips remain for portable test runs; a separate native feature probe must pass before counting runtime evidence.

This Mac's Rosetta environment does not advertise AVX2. The repository lesson points to Crucible, which was reachable over SSH and passed an explicit compiled AVX2 feature assertion. A fresh validation worktree on Crucible was brought from its older ancestor to the exact claimed base `7c784e9892a8328904b345808c8140c2d456d20c` using a local Git bundle; no branch was pushed and no shared worktree was edited. The old isolated fix object mentioned in the September evidence README is unavailable in both clones, so that historical report is not substituted for fresh proof.

Observed reversal: with the original production prefix and the new regression, Crucible selected one test and failed the full-buffer scalar-versus-AVX2 equality assertion at `pitch=8 blimit=255` (exit 101). The lower-threshold scalar controls had passed. The feature probe passed before both runs. Native and local changed-source SHA-256 matched: `9c30efec0343253649ea2b9a2da8530105ba12e7d67dd68b06634bc6c19506c9`.
