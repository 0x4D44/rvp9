# Use the designated variance oracle — CRU-00003

The x86 SSE2 vector-variance test used a handwritten scalar copy, so a defect or drift in the production scalar oracle could escape that comparison. The earlier CRU-00001 scalar-routing fix already restored compilation of the scalar fallback on x86; the remaining gap is the duplicated test oracle.

The correction exposes the existing scalar helper within the crate and uses it in both assertions of the existing SSE2 comparison, removing the duplicate helper. Production math, dispatch, cfg, test inputs and assertions remain unchanged.

The fault experiment added `+1` only to the designated production scalar helper's returned variance. Before rewiring, the exact SSE2 comparison selected one test and passed despite the fault (2,070 filtered out). The fault was restored. After rewiring, the same fault and selected test failed the variance equality assertion at `int_pro_sse2.rs:608`: SSE2 returned `704552`, the scalar oracle `704553` (one failed, 2,070 filtered out). The fault was restored again. This is evidence about test integrity, not a claim that correct scalar and SSE2 results differ.

With the original math restored, all four x86 SSE2 projection tests and 15 native ARM projection tests passed. The lead independently reran the four x86 tests. Native and x86 production-core-library Clippy passed with warnings denied, as did workspace formatting and diff checks. The x86 tests executed through Rosetta using the installed `x86_64-apple-darwin` target and `RUSTFLAGS='-C target-cpu=x86-64'`; no physical x86, AVX2, Miri, Windows or throughput claim is made. All test temporary paths used the task's absolute `.scratch` as `TMPDIR`. Hooks refused removing the empty scratch directory, so it was left for normal integration cleanup.

The preselected final smoke after catch-up is `RUSTFLAGS='-C target-cpu=x86-64' cargo test -p rvp9-core --target x86_64-apple-darwin --lib dsp::x86_64::int_pro_sse2::tests::vector_var_matches_scalar_random_and_extreme_projections -- --exact`, bounded to 60 seconds.
