# Unit 1362 — sub-pel integer-centre identity fast path

## Decision

Keep the `(0, 0)` sub-pel phase shortcut in
`crates/rvp9-core/src/dsp/x86_64/subpel_variance_avx2.rs`. The sub-pel search
evaluates its integer centre for every refinement. At that phase both scalar
bilinear filters are `[128, 0]`, so the source is already the exact temporary
block; invoking the existing variance reduction directly removes both
interpolation passes without changing decisions or output bytes.

## Evidence

Unit 1362's fresh Crucible profile still attributed 18.579% of weighted
samples to `sub_pixel_variance_avx2`, making this the largest exact kernel
surface. The full plain release screen against the trunk control measured a
paired corpus ratio of `0.972633x` and a separate ratio of `0.972765x` across
ducks, in-to-tree, and old-town, with identical hashes for every sample.

The source was deliberately mutated to use `src_stride + 1`; the focused
x86 differential failed at the first `(0, 0)` 4×4 case. After restoration,
that test and the full x86 suite passed. The local AArch64 suite also passed.

## Limits

This unit has fresh plain-release candidate/control evidence. It does not
rerun the longer PGO qualification or the direct pinned-libvpx comparison;
those remain the next resume checks if this branch is integrated.
