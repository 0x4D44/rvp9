## Bug

KILN-00008 (Open, Low, test-coverage): two G-C `decode_inter_block` branches lack
end-to-end (decode_inter_block-level) coverage — (a) the SEG_LVL_REF_FRAME glue
(`seg_ref` lookup + `is_inter` derivation + forced `ref0`) and (b) the Sub8SegSkip
guard Err path. Both verified libvpx-faithful (0/3 skeptics); the unit oracles call
`read_ref_frames`/`read_inter_block_mode_info` directly, bypassing
`decode_inter_block`, and the ROI fixture never lands on these branches.

## Investigate / diagnose

Heavy integration point: `decode_inter_block` has ~20 params (`InterFrameDecodeParams`,
tile ctxs, `TileFrameDst` dst, mv/seg grids…). Mapped every construction:
`FrameDecodeParams` (flat struct, pattern at tile.rs:3709), `InterModeReadParams`
(pattern at lib.rs:6152 via `setup_compound_reference_mode`/`sign_bias_from_header`),
`Yv12Buffer: TileFrameDst` (use a real alloc), `TileDecodeCtx::new_with_grid` /
`TileCoefCtx::new`, valid bool buffer (BoolWriter, per the rvp9-core
`valid_padding_buf` oracle).

Key reachability facts established by reading the code:
- The Sub8SegSkip guard (tile.rs:2496) sits BEFORE `read_inter_block_mode_info`
  ("before the reader runs") → reachable with zero bits read.
- With `seg_ref = Some(idx)`, `is_inter` is DERIVED (`idx != INTRA`) with no bit read
  (tile.rs:2369). With `segmentation_update_map=false`, segment_id is inherited (no
  bits). With `seg_skip` active, the skip flag is forced (no bits). So the guard is
  reached at the reader's start position and the ref pool is never touched
  (`refs:[None;3]`).

Surprise corrected mid-implementation: my first draft asserted `Err(Sub8SegSkip)` for
BOTH `seg_ref=Some(LAST)` and `seg_ref=Some(INTRA)`. The INTRA variant returned
`Ok(())` — because `is_inter=false` routes the block to the INTRA path, and the
Sub8SegSkip guard is **inter-only** (libvpx's check lives in
`read_inter_block_mode_info`). That is correct behaviour; I split the assertions
accordingly (a fact worth pinning).

## Fix (test-only; kernel/shipped code UNCHANGED → no version bump)

`crates/rvp9-decoder/src/tile.rs` (`#[cfg(test)]`): added
`seg_skip_sub8_through_decode_inter_block_errs_without_advancing`, driving the real
`decode_inter_block` with a forced-SKIP + forced-REF_FRAME segment on a 4×4 block:
- `seg_ref=Some(LAST)` → `is_inter=true` derived → asserts `Err(Sub8SegSkip{Block4x4})`
  AND the bool reader did not advance (`before == after`).
- `seg_ref=Some(INTRA)` → `is_inter=false` derived → asserts the result is NOT
  `Sub8SegSkip` (routes to the intra path; the inter guard must not misfire).

This covers (b) end-to-end and (a)'s `seg_ref` lookup + `is_inter` derivation (both
branches).
