# Unit 1407 — fdct16 butterfly inlining

Date: 2026-09-21  
Base: `539f1c5e`  
Candidate: `857c80af`

## Candidate and correctness

Fresh x86-64 profiling had `fdct16_butterfly` at 4.664362% of weighted user
samples. The bounded candidate changes only its Rust annotation from
`#[inline]` to `#[inline(always)]`, allowing LLVM to remove the helper call
boundary in the scalar 16-point transform. It does not change arithmetic or
interfaces.

The local AArch64 release forward-transform differential passed 46 tests. The
Crucible x86-64 release differential passed 40 tests for both candidate and
control. A deliberate `t2` → `t3` output mutation made the local differential
fail two NEON/scalar tests with exit 101; restoring the mutation returned the
suite to green.

## Crucible timing

acceptance clips, CPU-used 6, CBR 1260 kb/s, one thread, tile-columns 0, AQ0,
noise sensitivity 0, one warm-up, and reversed clip-order rotations. Screen A
used five paired samples and screen B used three. Candidate/control IVF hashes
matched on every sample.

clip), so the optimization helps but does not approach the <=1.05x parity bar.

## Disposition

Keep the one-line source change. It passed focused correctness on both
architectures and two independent timing screens. The branch is ready for
integration; the next profile should select a fresh hotspot rather than
revisit the rejected fdct16 second-pass rewrite.
