## Unit 44 — add the pure cpu7 fixed-tree parity seam

Arthur approved the bounded partition architecture change. A partner-tier
source audit agreed that pinned libvpx cpu-used 7 uses a fixed
`choose_partitioning` tree followed by one causal `nonrd_use_partition` pass,
not rvp9 A4's speculative recursive mode/partition search. The audit also set
the safe sequence: prove the pure variance tree against pinned libvpx before
changing the product default.

`crates/rvp9-core/src/mode_decision/partition.rs::choose_fixed_tree_inter`
now accepts a materialized 64x64 source and selected predictor plus the exact
thresholds, visible extents, force flags, segment state, qindex, and noise
tier. It returns:

- the final square/rectangular partition grid;
- all 21 force-split bits;
- the exact sum-square/sum/count accumulators and derived variances for the
  canonical 64x64, 32x32, and 16x16 nodes;
- the separate low-resolution 4x4-average `vt2` nodes;
- parent partition symbols and leaves in VP9 coding order.

The source audit found and the implementation fixed three subtle rules:

- low-resolution `vt2` is local to the 16x16 decision; 32x32/64x64 parents
  still aggregate the original 8x8-average `vt`;
- the low-noise spread rule tests the full frame height, not the visible
  height inside the current superblock;
- partial-mi edge superblocks bypass the 64x64 parent probe before descending.

`PartitionDecision::is_valid_partition` now validates legal HORZ/VERT trees as
well as the legacy square-only tree. Eight new focused tests cover flat,
horizontal, vertical, forced, partial-edge, separate-`vt2`, and invalid
rectangular cases.

- `cargo clippy -p rvp9-core --lib -- -D warnings`: passed;
- `cargo fmt --all` and `git diff --check`: passed.
