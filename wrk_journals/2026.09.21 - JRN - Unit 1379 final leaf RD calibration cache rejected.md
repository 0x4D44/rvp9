# Unit 1379 — final-leaf RD calibration cache (rejected)

Date: 2026-09-21  
Base: integrated `4f413ede` (`perf(core): vectorize convolve8 horizontal final pair`)  
Decision: reject the candidate; keep the source unchanged.

## Candidate

The final-leaf picker rebuilt `InterRdCalibration` and applied
`with_model_only_large` for every leaf. Unit 1377 had already proven that the
same frame-level zero/nonzero cache was exact for the A4 descent. This unit
temporarily reused `a4_rd_calibration_zero` / `a4_rd_calibration_nonzero` in
the final-leaf picker while leaving `spatial_leaf_rd_calibration` unchanged.

The temporary selector oracle compared cached entries with the original
per-leaf construction for cyclic refresh on and off, multiple rate-control,
deadline, speed, exact-VBP, and segment-id combinations. It passed. Swapping
the zero/nonzero selector branch deliberately failed with exit 101, proving
the test distinguished the two paths. The candidate and temporary test were
removed after the timing decision; this journal is the only retained change.

so the calibration reuse does not clear the retention bar.

## Outcome

The final-leaf cache candidate is rejected. The worktree source was restored
to the integrated baseline, and no shipped code from this unit should land.
The fresh profile points future work toward the quantizer, subpel variance,
and remaining picker hot paths, with the already-landed convolution-tail
optimization retained.
