## Scope

This run combines the screened Unit 1342 x86-64 SSE2 picker reduction with the
qualified Unit 1341 x86-64 SSE2 final inter-residual emission kernel.  The
picker kernel computes the exact raw sum of squared byte differences for every
legal VP9 partition shape; the residual kernel remains limited to square final
transform blocks.  AArch64 and non-x86 builds retain their scalar paths.

The remote Crucible source trees were assembled from retained exact source
trees and carried synthetic Git metadata because those copied trees do not
contain the original repository object database.  The local commit and diff
remain authoritative.  Both arms used Rust/Cargo 1.95.0, `target-cpu=native`,
the fixed 28-row production PGO matrix, and 60 frames per training row.

## Correctness and architecture coverage

- Local AArch64 release picker oracle passed:
  `cargo test --locked --release -p rvp9-core --lib hadamard_only_candidate_reuses_exact_model_sse_for_each_block_size`.
- Crucible x86 release `differential_` screen passed 50 tests, including the
  two new `sse_block_sse2` tests and the existing subtraction/variance tests.
- Crucible x86 release picker oracle passed the same focused test.
- Deliberately replacing the high-half prediction operand with the source made
  both new `sse_block_sse2` differential tests fail (`16x8` and `64x64` cases
  reported mismatched totals).  Restoring the operand made both tests pass.
- Every candidate/control timed output hash matched for all three clips in the
  plain screen and both PGO rotations.  Candidate output hashes also remained
  stable in the libvpx comparison.

the exact Unit 1341 control source.
