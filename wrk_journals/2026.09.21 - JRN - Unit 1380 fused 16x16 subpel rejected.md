# Unit 1380 — fused 16×16 sub-pel variance (rejected)

Date: 2026-09-21  
Base: integrated `fcd9deb2`  
Decision: reject the candidate; keep the source unchanged.

## Candidate

The fresh symbolized Crucible profile put
`rvp9_core::dsp::x86_64::subpel_variance_avx2::vpx_sub_pixel_variance16x16_avx2`
at 7.803% of weighted samples. The temporary candidate fused the 16×16
horizontal/vertical interpolation result directly into the exact `(sum, sse)`
reduction for two-dimensional, horizontal-only, and vertical-only phases. It
removed the 256-byte output temporary and its reload while preserving the
existing generic paths for every other shape.

The temporary `differential_fused_16x16_all_phases` test covered four random
stride pairs and all 64 phase pairs. A deliberate wrong-row mutation in the
fused vertical pass failed at phase `(1,1)`, proving that the oracle caught a
real source-row error. The candidate and test were removed after timing; this
journal is the only retained change.

## Crucible screens

Both screens used native release binaries, the three canonical 1280×720 clips
(`ducks`, `tree`, `oldtown`), CPU-used 6, CBR 1260 kbps, 30 fps, one thread,
zero tile columns, AQ0, noise0, 60 frames, keyframe interval 60, one warmup,
15 alternating pairs, two rotations, and no load cap. The harness reported
identical anchor/test IVF output hashes for every pair.

| 1 | 0.978845x / 0.991555x | 0.983764x / 1.011294x | 0.965830x / 0.994132x | 0.976117x | 0.998955x |
| 2 | 0.986267x / 0.996323x | 1.008700x / 1.003927x | 0.998887x / 0.998619x | 0.997909x | 0.999618x |

Each clip cell is `separate / paired` candidate-to-control time. The first
screen's 2.4% separate improvement did not repeat; the paired corpus stayed
near 1.0× in both screens. That is neutral timing, not a reproducible gain,
so it does not clear the retention bar.

## Outcome

The fused 16×16 sub-pel candidate is rejected. The worktree source was
restored to the integrated baseline, and no shipped code from this unit should
land. The next profile-led search should avoid another temporary-buffer fusion
unless it can show a paired corpus improvement above measurement noise.
