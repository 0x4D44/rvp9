# v0.2.0-alpha.2 release qualification

## Identity and scope

- Release base: integrated `origin/main` commit
  `0fe0746a0b638a76ccbcf14f13abf93a2580f36a`.
- Reference encoder and decoder: pinned libvpx v1.14.1 commit
  `12f3a2ac603e8f10742105519e0cd03c3b8f71dd`.
- Release version and tag: `0.2.0-alpha.2` / `v0.2.0-alpha.2`.
- Public crates: `rvp9-core`, `rvp9-io`, `rvp9-decoder`, `rvp9-encoder`, and
  `rvp9-cli`. The test-only `rvp9-harness` and `rvp9-bench` crates remain
  unpublished. The reserved `rvp9` 0.0.0 facade remains unchanged.
- Intended claim: a second 8-bit one-pass realtime VP9 preview for CPU6--8,
  adding qualified two- and three-layer spatial SVC. It does not claim the
  still-open final cross-feature production-parity matrix.

## Qualification plan

1. Stamp the workspace and every publishable internal dependency at the exact
   prerelease version, then verify both workspace lockfiles.
2. Package and independently build/test every public crate from its generated
   crates.io tarball. Run `cargo publish --dry-run` for every crate.
3. Run the repository formatting, clippy, release-test, conformance, and
   encoder cross-decoder gates on the exact candidate.
4. Integrate the candidate before producing any distributable artifact.
5. Build and smoke-test the portable macOS Apple Silicon archive from the
   integrated commit.
6. Publish crates in dependency order, tag the exact commit, then create the
   GitHub prerelease with the archive and checksum.

## Existing acceptance evidence carried by the candidate

- Decoder conformance: 307/307 official vectors, 4,816 displayed frames, in
  native/scalar and one-/two-thread modes; 19,264 checks with no mismatch.
- Spatial SVC: 48/48 curves and 120/120 layer gates pass `+0.5%` BD-rate; all
  18 relative-speed groups and all 48 absolute-latency rows pass.
- Spatial cross-decode: 1,008/1,008 full and extracted streams decode under
  rvp9-decoder, pinned vpxdec, and FFmpeg; rvp9-decoder and vpxdec are
  byte-identical.
- Exact evidence and hashes are recorded in
  `wrk_journals/2026.08.12 - JRN - spatial SVC stage.md`, Unit S7.

## Open limitation

- CPU-used 8 three-layer temporal-SVC relative speed awaits a quiet-host final
  measurement. This alpha is being cut while that host condition settles and
  does not claim final production parity.
