### G5 — tile-threading primitive (closure-form)

## Lessons captured

1. **Branch drift mid-session.** Multi-worktree + cd-into-worktree
   sequences are a foot-gun. Verify branch ID before each commit
   with `git rev-parse --abbrev-ref HEAD`.
2. **Concurrent-agent contamination.** Other sessions can abort
   merges, force-move branches, or modify shared files. The
   "wait + retry" rule from CLAUDE.md is real — don't fight it.
3. **Scope reduction is honest engineering.** G7.0 / G8.0 / G5.0
   precedents: ship the engineering deliverable + file the deep
   work with full attribution. Reviewers caught and confirmed
   this pattern; HLD exit criteria can have "literal" vs "intent"
   readings and the supervisor must call which one.
4. **Reviewer + DA load-bearing.** G5 M1 liveness hole (double
   catch_unwind needed) + G6 per-frame vs per-packet bug + G4
   pub(crate) build UB risk + G8 .gitignore regression — all
   caught by review pipelines. Pure-implementer mode would have
   shipped real bugs.
5. **cargo-fuzz workspace exclusion is non-obvious.** `#![no_main]`
   crates break `cargo build --workspace` on Windows (LNK1561).
   Pattern: don't list in `[workspace.members]`; rely on omission.
