# Unit 1363 — zero-horizontal-phase vertical sub-pel shortcut

## Decision

Keep the direct vertical path for `xoffset == 0` in
`crates/rvp9-core/src/dsp/x86_64/subpel_variance_avx2.rs`. The horizontal
bilinear taps are `[128, 0]`, so materialising widened horizontal rows cannot
change the result. Reading adjacent source rows directly removes one whole
bilinear pass while retaining the existing byte temp and exact variance
finisher.

## Evidence

Against a binary built from Unit 1362, the full relaxed Crucible screen measured
`0.936836x` paired and `0.926730x` separate across ducks, in-to-tree, and
old-town. Every candidate and anchor stream hash matched. The corrected short
screen also produced `0.909364x` paired on ducks with identical hashes.

The x86 red mutation failed at the first `xoff=0, yoff=1` differential case;
the restored source passed the focused test and the full 2053-test x86 suite.
The local AArch64 suite passed 1717 tests.

## Limits

This unit has fresh plain-release incremental evidence. It does not rerun the
longer PGO qualification or direct pinned-libvpx comparison; those remain
resume checks after integration.
