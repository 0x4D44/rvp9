The constructor allocates full-frame reconstruction, MV and partition vectors for
each tile. Resizing at inter-frame execution reduces lengths, retaining capacity.
Additionally the parallel keyframe path explicitly expands every reconstruction
vector to a full frame, so fixing constructor sizes alone is insufficient.
Keyframe jobs also clone full-frame partition grids and allocate full-frame
picked-mode/skip grids per tile; the same local adapters will cover these
temporaries so the plan reflects the full allocation pattern.

## Agreed local approach

Reuse existing layout adapters; no new pool, scheduling policy, dependency or
public API. Preserve parallel keyframes and serial wrappers.

- Add an inspectable tile-local geometry allocation plan used by real allocation.
- Adapt keyframe reconstruction access through existing `InterReconPlanes` /
  `InterReconLayout::tile_column`, retaining frame-global source/coefficient coords.
- Reuse `InterPickerMiGridLayout` for tile-local MV output.
- Map global superblock indices to tile-local partition storage at picker,
  partition, merge and return seams. Existing compact-row offset alone does not
  describe strided tile columns; mapping must account for rows.
- Preserve per-tile adaptive state and byte output.
