# Require bounded nonempty soak work — KIL-00109

The soak argument parser accepted zero frames per iteration. The iteration then accepted decoded zero as the expected zero, so a successful run could exercise no codec frames. Setting both duration and iteration limits to zero also removed every stopping condition.

Argument validation now rejects zero frames per iteration and the absence of a finite stop condition before source discovery or soak startup. Main prints the validation diagnostic and exits 2. The successful-iteration boundary requires both a positive decoded-frame count and the existing exact expected count. Defaults and runs bounded by either duration or iteration count remain valid. Comments now describe duration zero as disabling the time limit only when an iteration limit exists.

Observed assertion-red reversals, each restored manually:

- Ignoring `Args::validate()` caused the invalid-parser test to receive `Ok(Args { frames_per_iter: 0, ... })`.
- Removing only the duration-zero/iteration-zero guard, with zero-frame validation active, caused that test's unbounded-run assertion to receive `Ok(Args { duration_secs: 0, iterations: 0, frames_per_iter: 30, ... })`.
- Changing the stopping guard from `&&` to `||` caused the valid-parser control's duration-only assertion to receive an error.
- Removing the positive decoded-frame postcondition caused the empty-iteration regression to receive `Ok(IterStats { encoded_bytes: 0, y_checksum: 0, decoded_frames: 0 })`.

All five soak tests passed, including the actual 64×64 one-frame encode/decode control and the existing child-timeout test. The lead independently reran all five. Scoped `cargo clippy -p rvp9-bench --bin soak -- -D warnings`, formatting and diff checks passed. Direct CLI checks of both invalid configurations exited 2 with the expected diagnostics before startup output. Tests used the task's absolute `.scratch` directory as `TMPDIR`. No external input, libvpx run or prolonged soak was used. Existing handling of unrelated malformed numeric arguments remains outside this fix. The preselected final smoke after catch-up is `cargo test -p rvp9-bench --bin soak`, bounded to 60 seconds.
