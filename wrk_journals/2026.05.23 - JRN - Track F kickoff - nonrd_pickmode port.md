## Agent-team workflow (in use, validated round 1)

Round 1 (F.0 HLDs):
1. Three HLD-writer agents dispatched in parallel, each producing
   one HLD doc.
2. Team-lead reviewed each HLD against `lld-review` skill checklist:
   problem statement, source citations, scope, risks, open questions.
3. Each HLD received a revision pass (4-9 small revisions per HLD)
   sent back to the originating agent as a structured prompt.
4. Each agent re-applied revisions and confirmed sign-off ready.
5. Team-lead flipped Status header to SIGNED-OFF.
6. Implementer task created (in TaskList) with explicit reference to
   the HLD doc path.

For implementer dispatch:
1. Implementer reads the HLD in full.
2. Implements the changes; deviations halt the agent and report.
3. Runs targeted tests + clippy on touched code.
4. **Invokes `/code-reviewer`** skill on its own diff.
5. **Invokes `/code-review-apply-feedback`** to act on review.
6. Reports back without committing — team-lead reviews and commits.

## Workflow lessons (round 1)

- **HLD-first + lld-review iteration works.** Every agent produced a competent first draft; each got 4-9 revisions then signed off cleanly. No fundamental rework needed on any HLD.
- **Multi-agent CWD interleaving is manageable** if agents work on non-overlapping files. F.0 phase had three concurrent implementers in the same CWD and the diffs separated cleanly into three atomic commits (F.0.1 = harness, F.0.2 = oracle + picker hooks, F.0.3 = config field + frame_loop gate).
- **/code-review-apply-feedback is a workflow gate.** F.0.2 implementer stopped at `/code-reviewer` and left 3 fixable issues unaddressed. Team-lead applied them manually before committing. F.1+F.2+F.3 implementer prompts make `/code-review-apply-feedback` explicit.
- **Two HLD agents discovered existing implementations:** F.0.3 found A18 plumbing was already in place; F.2 found `find_mv_refs` was already libvpx-faithful. Both reduced the implementation scope significantly. The lld-review checklist (read the code first, verify before designing) caught these.
- **The F.3 HLD writer agent stalled** at the watchdog timeout in libvpx exploration. Re-dispatch with explicit scope/time budget worked. Lesson: cap libvpx-source-reading time in HLD prompts.
