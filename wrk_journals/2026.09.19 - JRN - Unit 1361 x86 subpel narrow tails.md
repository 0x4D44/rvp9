# Unit 1361 — x86 sub-pel narrow tails

The fresh Unit 1357 Crucible profile left AVX2 sub-pel variance as the largest
kernel. Earlier fused and fixed-shape rewrites changed code layout enough to
lose under production PGO, so this unit stayed deliberately small: it removed
only stack-copy tails for the common 4- and 8-pixel shapes in
`subpel_variance_avx2.rs`.

The x86 core suite passed 2,053 tests with three documented ignores; its
differential filter covered 50 tests. Deliberately shifting the count-4 store
failed the 4x4 byte-identical temporary oracle, then the implementation was
restored. AArch64 passed 1,717 core tests; x86 cross-target compilation
passed. Workspace `-D warnings` Clippy remains blocked by the existing
`quantize_fp_avx2.rs:141` collapsible-if and `mode_decision/inter.rs:5955`
needless-return diagnostics, neither introduced by this unit.

The exact 15-pair/two-rotation plain screen measured `0.983497739x` paired.
Two independent production-PGO screens measured `0.982765864x` and
`0.981170620x`, with paired geomean `0.981967918x`. All stream hashes matched.
The candidate is retained as a reproducible small gain and is ready for the
integration gate; no trunk files changed in this unit.
