# Unit 1294 — default CPU6 path and parity checkpoint

## Outcome

The accepted Unit 1293 AVX2 SAD4D specialization remains integrated at
`689921af`. A fresh Crucible profile shows that the earlier A4 duplicate-picker
cache is not on the measured production path, and the strongest suggested
sub-pel kernel is too small to move the parity target. No code change is
justified by this unit.

The independent audit found no bounded, output-exact picker or NEWMV micro-
candidate with a credible 1% whole-encode gain. The consultant suggested
rewriting `crates/rvp9-core/src/dsp/x86_64/subpel_variance_avx2.rs`, but the
same WPR report attributes only 153,665 samples to
`subpel_variance_avx2` (0.1494% of direct `rvp9_core` samples). Even an
implausible perfect removal would miss the retention bar, so that experiment
is rejected without a code branch.

The retained accepted timings remain:

- plain candidate/control: `0.987768x` paired;
- production-PGO repeats: `0.984338x` and `0.981972x` paired;
- direct pinned libvpx: `1.516455x` paired and `1.519847x` separate.

The current RVP9 frame times for ducks/in-tree/old-town were 22.333/13.788/
13.080 ms versus libvpx 14.471/9.034/8.776 ms. Reaching 1.05x therefore
still needs about a 30.8% RVP9 runtime reduction. That is not a routine
dispatch or cache cleanup; it likely requires a complete hot-kernel rewrite
with measured coverage, or an algorithmic shortcut that must be judged in the
BD-rate/output-policy lane rather than by byte-exact hashes.

## Safe resume point

The next bounded step is source-level attribution inside the final picker and
its mandatory evaluator, followed by one complete SIMD-kernel experiment only
if the line-level profile gives it at least 5% whole-encode coverage. Do not
revive the A4 cache for default CPU6 CBR, and do not spend a unit on the
sub-pel variance rewrite without new attribution. Any future code candidate
must retain the existing differential oracle, deliberate red mutation, AArch64
and x86 checks, paired Crucible timings, and pinned-libvpx comparison.
