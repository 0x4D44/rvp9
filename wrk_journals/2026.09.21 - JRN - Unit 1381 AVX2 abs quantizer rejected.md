# Unit 1381 — AVX2 absolute-value quantizer (rejected)

Date: 2026-09-21  
Base: integrated `933f7343` (`journal: reject fused 16x16 subpel variance`)  
Decision: reject the candidate; keep the source unchanged.

## Candidate

The AVX2 quantizer spent 10.660% of the fresh Crucible profile in
`vp9_quantize_fp_avx2_inner`. The temporary candidate replaced the AC
magnitude idiom
`(values ^ sign) - sign` with AVX2 `vpabsd`, retaining the existing sign
vector for the signed qcoeff result. `vpabsd` is bit-exact for ordinary values
and preserves the `i32::MIN` bit pattern.

The candidate added release-only differential coverage for `i32::MIN` and
`i32::MAX`, plus near-boundary values. The six-test Crucible x86 release
quantizer suite passed. Replacing the intrinsic with the raw signed values as
a deliberate mutation failed the random and near-boundary differential tests,
so the oracle caught the intended regression. The experiment and tests were
removed after timing.

## Crucible screens

Both screens used native release binaries and the three canonical 1280×720
clips (`ducks`, `tree`, `oldtown`), CPU-used 6, CBR 1260 kbps, 30 fps, one
thread, zero tile columns, AQ0, noise0, 60 frames, keyframe interval 60, one
warmup, 15 alternating pairs, two rotations, and no load cap. Crucible's
Windows load samples reached 27.194 busy logical cores during screen 1 and
25.571 during screen 2; this was within the agreed relaxed-load policy. Every
candidate and control output had one distinct IVF hash, and the hashes matched
per clip.

## Outcome

The quantizer source and temporary tests were restored to the integrated
baseline. This journal preserves the negative result; no shipped code from
Unit 1381 should land.
