## Reproduction

Before editing production code, extracted each exact `actual_bytes=...` plus arithmetic if block from `scripts/qualify-alpha-encoder.sh` and `scripts/qualify-reference-decoder.sh`, with process-local `stat` / `file_size` functions returning `invalid`. A separate digit-only oversized observation also returned ACCEPTED after its arithmetic comparison errored. These probes reproduce the recorded observation without a codec run.

Root cause: shell test errors return false inside `if`, so `if [ "$actual_bytes" -ne "$expected_bytes" ]; then reject; fi` accepts invalid arithmetic input. `stat -f` may succeed with GNU filesystem information rather than BSD byte size, so success status alone is insufficient.
