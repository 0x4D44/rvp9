# x86 32x32 IDCT final-row pointer

RVP9-BUG-FLU-00050 is fixed by advancing the shared SSE2 and AVX2 destination pointer only when another output row remains. The final 8-byte SSE2 store begins at offset 1016 in an exact 1024-byte destination; the old unconditional stride step formed a pointer 32 bytes beyond that final row. The AVX2 helper had the same post-final-row step.

The focused final-row pointer regression failed before the guard because the pointer advanced by one stride, then passed under Miri after the fix (1 test). Under Rosetta, the x86_64 `idct32x32` test filter passed all 70 tests. Scoped x86_64 Clippy with `-D warnings`, `cargo fmt --all --check`, and `git diff --check` passed. The exact pointer regression smoke completed in 12 seconds.
