# Windows FFI declaration safety comments

RVP9-BUG-FLU-00054 identified three Windows `unsafe extern "system"` blocks without nearby safety contracts. The declarations in `path_guard.rs` and the Windows RSS module in `soak.rs` are now documented with their ABI, type-width, and C-layout assumptions. No call behavior changed.

The declarations were checked against Microsoft documentation for the Windows signatures and structures used by file identity and process memory queries. `cargo fmt --all --check`, `cargo check -p rvp9-cli --locked`, and `cargo check -p rvp9-bench --bin soak --locked` passed on the host. The Windows-only declarations were cfg-disabled on this target, so they were not cross-compiled.
