## The math (the crux: AVG3/AVG2 in SIMD)

Scalar helpers (`intra_pred.rs:271-279`):
- `avg3(a,b,c) = (a + 2b + c + 2) >> 2`
- `avg2(a,b)   = (a + b + 1) >> 1`

libvpx's "trick from pascal" (`intrapred_ssse3.asm:165-177`) computes AVG3
**exactly** with two `pavgb` + a parity correction (avoids double-rounding):
```
result = avg(x, z)            ; pavgb (x+z+1)>>1
result -= xor(x, z) & 1       ; subtract the rounding bit when x,z differ in LSB
result = avg(result, y)       ; pavgb
```
AVG2 = `_mm_avg_epu8` / `_mm256_avg_epu8` directly.

These map to `_mm_avg_epu8`, `_mm_xor_si128`, `_mm_and_si128` (pb_1 =
`_mm_set1_epi8(1)`), `_mm_sub_epi8`. This is the shared primitive every
directional kernel uses on its edge array.

## Kernel structure (all 6 reduce to: filter an edge, then splat windows)

| Mode | Inputs        | Edge filter | Row/col fill pattern |
|------|---------------|-------------|----------------------|
| D45  | above (2·bs)  | AVG3 along above | row r = row0 shifted left r, pad above_right |
| D63  | above (2·bs)  | AVG2 + AVG3 rows | shift-copy from rows 0/1, pad above[bs-1] |
| D117 | above+left+al | AVG2 r0, AVG3 r1, AVG3 col0 | dst[r][c]=dst[r-2][c-1] |
| D135 | above+left+al | AVG3 border[2bs-1] | each row = bs-window into border |
| D153 | above+left+al | AVG2 col0, AVG3 col1, AVG3 r0 | dst[r][c]=dst[r-1][c-2] |
| D207 | left (bs)     | AVG2 col0, AVG3 col1, pad | dst[r][c]=dst[r+1][c-2] |

**4×4 specializations** (libvpx `intra_pred_no_4x4`): D45, D63, D207 have
hand-unrolled 4×4 kernels that differ at the bottom-right boundary from the
generic. D117/D135/D153 use the generic kernel for all sizes. The dispatch
must preserve these 4×4 specials (current `intra_predict` already routes
`(D45,true)→d45_predictor_4x4` etc).

## Dispatch wiring plan

Current state: directional modes are called **directly** in `intra_predict`
(`intra_pred.rs:765-773`), NOT through `SimdDispatch`. V/H/TM/DC go through
slots. Wave K adds directional slots mirroring the Wave I pattern:
- New `SimdDispatch` slots, one per mode (size-parametric where the generic
  kernel covers all sizes; the 4×4 special folded into the AVX2 fn by a
  `bs==4` branch, matching scalar).
- caps-gated let-binding in `dispatch.rs::build`: `if caps.avx2 { avx2_fn }
  else { scalar_fn }`, with `#[cfg(not(x86_64))]` scalar fallback.
- `intra_predict` routes directional arms through the new slots.
- Routing tests split into `*_routing_avx2_cpu` (fn-ptr identity) +
  `forced_scalar_caps_installs_scalar_*`.

Signatures (mirror scalar): D45/D63 take `(dst, stride, bs, above)`;
D207 takes `(dst, stride, bs, left)`; D117/D135/D153 take a ctx-equivalent
`(dst, stride, bs, above, left, above_left)`.

## Sequencing (deliverables)

- **K1** — shared AVX2 `avg3`/`avg2` lane primitives + **D45** (above-only,
  simplest; establishes the module + differential-test harness + dispatch
  pattern). Includes 4×4 special.
- **K2** — **D207** (left-only, mirror of D45 structure). Includes 4×4 special.
- **K3** — **D63** (above, AVG2+AVG3 two-row seed). Includes 4×4 special.
- **K4** — **D135** (border-array build, windowed rows).
- **K5** — **D117** (above+left, recursive dst[r-2][c-1] fill).
- **K6** — **D153** (above+left, recursive dst[r-1][c-2] fill).
- **K7** — dispatch wiring of all 6 slots + routing tests + journal close.

(Wiring may fold into each Kn instead of a trailing K7 — decide once K1 lands.)

## Verification oracles

- **Differential**: scalar vs AVX2, bit-exact, across all valid (bs) ∈
  {4,8,16,32} × randomized edge inputs. The correctness oracle.
- **Conformance**: full MD5 suite must stay 201/0/0/0/201.
- **Clippy**: zero new warnings over baseline (68).
- **Unit suite**: no new failures (pre-existing encoder-zone failure ignored).
