  Were on origin too.

  value (see Part 2). KEPT (local + origin).
- **2 keepers**: `main`, `task/fix-kiln-bugs` (active — another agent moving it
  mid-session). `backup/pre-sync-*` self-cleaned during the session (89→88).

Actions (with explicit go-ahead): deleted 85 local (`git branch -D`) + 11 from origin
(`git push origin --delete`). End state: **3 local / 2 remote** (`main`, `track2`).

Root cause for future hygiene: harness creates a branch per `git worktree add` and
doesn't delete it on worktree removal. Mitigation suggested: periodic sweep of
`worktree-(agent|wf_)*` branches not currently checked out; enforce delete-on-integration.
