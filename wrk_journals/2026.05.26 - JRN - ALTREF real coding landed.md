# 2026.05.26 — JRN — ALTREF real coding landed

## Outcome: LANDED

The ALTREF (alternate reference) frame is upgraded from the retired
ZEROMV-skip scaffold (slot 2 was a verbatim LAST copy) to **real
per-leaf coding** of the temporally-filtered ARF pixels, with the
ALTREF-containing superframe **byte-exact decodable by vpxdec**. Sign
bias is wired per libvpx `set_ref_sign_bias`.

## What changed

`crates/rvp9-encoder/src/frame_loop.rs`:

- **`encode_altref_internal` rewritten.** The retired all-skip ZEROMV
  partition (every SB one 64×64 skip leaf, slot 2 = LAST copy) is
  replaced by the SAME real-RD path the show frames use:
  - `choose_partitions_for_frame` on the FILTERED source (variance
    partition picker).
  - `pick_and_simulate_inter_encode_partitions` — the show-frame
    real-RD inter coder — choosing intra or inter-from-LAST per leaf by
    RD, producing real forward-quantised residuals + a genuine
    reconstruction the decoder reproduces.
  - In-loop deblock (`search_filter_level` / `pick_filter_level` +
    `apply_loop_filter_to_tight_recon`), mirroring the show path.
  - Slot 2 (`altref_recon_*`) now holds the REAL post-LF
    reconstruction, not a LAST copy.

- **Sign bias wired.** New `ref_frame_sign_biases: [bool; 3]` parameter
  on `build_inter_packet_with_residuals`, threaded into both the
  uncompressed-header `ref_frame_sign_biases[]` and the per-block
  `InterModeReadParams.sign_bias`. Encodes libvpx's rule
  (`vp9_encoder.c::set_ref_sign_bias`, :5034-5049): a ref is biased iff
  it points at a FUTURE display-order frame. Show frames + the ARF's own
  header pass `[false,false,false]` (no ALTREF in their ref set), so the
  cross-decoder gate wire bytes are unchanged; the helper makes a
  future frame that names ALTREF emit `[false,false,true]`.

- **FC bank-1 routing (the keystone correctness fix).** New
  `frame_context_idx: u8` parameter; new `decoder_fc_state_arf` field
  (encoder mirror of decoder FC bank 1). libvpx routes ARFs to
  `frame_context_idx = refresh_alt_ref_frame = 1`
  (`vp9_encoder.c:818-819`), so the ARF reads/adapts/writes bank 1 and
  the show frames' bank 0 stays pristine across the non-show ARF. The
  encoder mirrors this: the ARF diffs + backward-adapts
  `decoder_fc_state_arf`; `decoder_fc_state` (bank 0) is never touched
  by the ARF.

- Diag accessors: `diag_altref_recon_y`, `diag_last_arf_real_coded`
  (anti-G3 witness).

`crates/rvp9-encoder/tests/w_altref_real_coding.rs` (new PROOF):

- `altref_slot2_differs_from_last_recon` (always-live anti-G3): asserts
  `diag_last_arf_real_coded() == Some(true)` — slot 2 differs from the
  LAST it predicted against. FAILS if real coding is reverted to the
  copy.
- `altref_stream_byte_exact_vpxdec` (`#[ignore]`, the critical oracle):
  encodes an ALTREF stream on testsrc-with-motion, wraps in IVF,
  round-trips through vpxdec, asserts BYTE-EXACT vs rvp9-decoder. Reuses
  the exact `vpxdec --codec=vp9 --i420` invocation from
  `cross_decoder_gate.rs`.

## The blocker I hit and fixed

First vpxdec run REJECTED the stream: "Failed to decode frame 11 /
Corrupt frame detected / Failed to decode tile data" — an FC desync.
rvp9-decoder accepted it (it agreed with the encoder's wrong
adaptation), but vpxdec applied the correct libvpx adaptation. Root
cause: my first cut adapted FC bank 0 on the ARF, corrupting the bank
the post-ARF show frame diff-encodes from. libvpx avoids this by routing
ARFs to bank 1 (`vp9_encoder.c:818-819`). Wiring `frame_context_idx = 1`
+ a separate `decoder_fc_state_arf` mirror fixed it → BYTE-EXACT.

## Scope honestly stated

Real coding = intra OR inter-from-LAST, RD-chosen. The picker's GOLDEN
candidate is default-off stream-wide (libvpx parity, commit 63abe6e), so
every ARF leaf resolves to LAST (slot 0) or intra. Inter-from-GOLDEN/
ALTREF coding for the ARF is deferred until GOLDEN selection is turned
on stream-wide (needs `ref_frame_indices[1]=1` + the encoder GOLDEN-slot
reference). This is still genuine real coding — real MC-from-LAST + real
residual against the filtered source — not the retired ZEROMV copy.
