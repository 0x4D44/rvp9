# Unit 1402 — direct SAD union rejected

Unit 1401 showed that a four-lane SAD union optimization was slower when its
rectangle bounds were computed with iterator min/max and an extra `block_at`
call. Unit 1402 kept the same idea but used direct scalar min/max and checked
arithmetic, while preserving the clipped per-lane fallback.

The candidate passed the local in-plane/clipped differential suite 20/20. A
deliberate one-column mutation failed with `range end index 577 out of range
for slice of length 576`; restoring it made the test pass. The x86 Crucible
focused suite passed 20/20. Both timing screens emitted exactly the same IVF
hashes as the control.

The relaxed-load screens disagreed. Screen A measured paired geomean
`0.996882961x`; screen B measured `1.002722700x`. Because ratios are
candidate/control, A looked 0.31% faster but B was 0.27% slower. This is not a
reproducible gain, so commit `372e5bde` reverted `58cb9b65`. The integrated
Unit 1401 scalar path remains unchanged.
