# Post-alpha acceptance widening

## Unit W1 — complete official conformance matrix

Current source no longer has the decoder limitation carried by the published
`v0.2.0-alpha.1` tag. The official spatial-SVC vector now passes, so the
reproducible source-tree gate must cover the complete corpus instead of
continuing to exercise only the alpha-supported subset.

The conformance binary now has a fail-closed `--official` mode. It requires
exactly 307 pinned vectors, rejects `--limit` and `--non-gating`, and requires
exactly 4,816 displayed-frame matches. `--threads N` selects the decoder
worker count explicitly. `scripts/qualify-conformance.sh` fetches and SHA-1
verifies the pinned corpus, then runs the complete 2x2 matrix:

- native dispatch, one decoder thread;
- native dispatch, two decoder threads;
- forced-scalar dispatch, one decoder thread;
- forced-scalar dispatch, two decoder threads.

All four release runs passed 307/307 vectors and 4,816/4,816 displayed frames,
with zero mismatches and zero skips. That is 19,264 successful frame checks in
total. The corpus came from pinned libvpx v1.14.1 commit
`12f3a2ac603e8f10742105519e0cd03c3b8f71dd`; the provisioning script verified
every stream and ledger against that revision's manifest.

Focused tests cover malformed-packet failure, explicit diagnostic skipping,
missing shown-frame accounting, and the new official-scope exclusions. The
README distinguishes the published alpha's 306-vector claim from current
source's complete 307-vector result.

Exact next unit: add a fast in-process encoder interaction matrix over
CPU6--8, CBR/VBR, AQ3, denoising, and temporal T2/T3. Use deterministic
motion/noise inputs and require every component to parse and decode under
`rvp9-decoder`, with frame counts, dimensions, temporal IDs, and retained-layer
reconstruction checked. Keep the existing 32-row real-corpus three-decoder
matrix as the slower external gate.

## Unit W2 — routine encoder feature-interaction matrix

A non-ignored integration test now exercises 36 one-pass realtime rows:
CPU6, CPU7, and CPU8 crossed with CBR and VBR, then baseline, AQ3, denoiser,
T2, T3, and combined AQ3+denoiser+T3 configurations. Each row encodes twelve
deterministic moving/noisy 128x64 frames, for 432 encoded and decoded frames
per test invocation.

Every row requires one keyframe plus eleven inter frames; exact 0/1 and
0/2/1/2 temporal-layer patterns; non-empty packets with consistent bit counts;
one shown component per temporal access unit; successful packet parsing and
decoding through `rvp9-decoder`; unchanged 128x64 output geometry; every
configured temporal layer exercised; and twelve decoded outputs. Each row
uses one deterministic decoder worker so the routine test does not create a
host-sized thread pool 36 times. For T2 and T3, separate decoder instances
also drop every packet above each retained temporal operating point and
require the surviving reconstructions to remain byte-identical to the same
frames decoded from the full stream.

The focused test passed in both Cargo profiles. Its steady test body took
0.36 seconds in release and 0.43 seconds in the workspace's optimized debug
profile on this host. This fast matrix complements rather than replaces the
32-row real-corpus gate through pinned `vpxdec` and FFmpeg.

Exact next unit: return to spatial SVC with these broad regressions in place.
Add the shared spatial reference-map control needed for a valid two-layer
720p sequence; require the first enhancement inter picture and the following
inter access unit to decode with the expected low/high dimensions before
generalizing the geometry to three layers and 1080p.

## Unit W3 — reverse reference-encoder decode matrix

The broad encoder gates were one-way: rvp9-produced streams were decoded by
three decoders, but pinned-libvpx streams outside the official corpus did not
exercise current realtime feature combinations through `rvp9-decoder`.
`scripts/qualify-reference-decoder.sh` closes that gap with a deterministic,
locally generated 128x64 motion/texture source and a 24-row matrix:

- CPU-used 6, 7, and 8;
- CBR and VBR;
- baseline, AQ3, denoiser, and combined AQ3 plus denoiser.

Pinned libvpx v1.14.1 commit
`12f3a2ac603e8f10742105519e0cd03c3b8f71dd` encodes every row with the scoped
one-pass realtime flags. Both `rvp9dec` and pinned `vpxdec` must emit the exact
expected I420 byte count and byte-identical output. The script fails closed on
the libvpx revision, binaries, source generation, row count, and decoded size,
and records tool identities plus per-stream and decoded SHA-256 values.

The complete default 12-frame run passed 24/24 streams. Every decoder output
was 147,456 bytes and every rvp9/vpx decoded pair matched byte-for-byte.

Exact next unit: land the encoder-side scaled motion-compensation primitive as
the first measured spatial-SVC prerequisite. Prove identity-scale output is
unchanged and scaled output matches the production decoder before wiring
shared reference-map control into `SpatialKeyframeEncoder`.

## Unit W4 — exact encoder-side scaled spatial prediction

The encoder now has a bounded scaled inter-prediction primitive for equal-size
or lower spatial-layer references. It mirrors the production decoder's Q14
coordinate mapping, including the distinct luma-coordinate phase used for
subsampled chroma, scaled convolve footprint, and edge-replicated MC scratch.
The fixed 72x72 scratch deliberately rejects larger-than-current references;
that downscale direction is outside the spatial-SVC dependency path and would
need a larger scratch contract.

A focused differential test compares encoder output directly with
`rvp9_decoder::reconstruct_inter_block` for a 64x32 reference feeding a
128x64 current frame. It covers Y, U, and V; all four concrete VP9 interpolation
filters; fractional motion; an interior block; and top-left and bottom-right
edge replication. All 12 cases pass byte-for-byte.

The identity-scale production path remains unchanged at the bitstream level.
Six deterministic 12-frame encodes (CPU-used 6, 7, and 8, each CBR and VBR)
from pre-change commit `9b72b153d46d229f00653b51e54d572890af8223` and the candidate produced
byte-identical IVF files. Candidate SHA-256 values were:

- CPU6 CBR `a8e2347780770c524a38b5dc378762bae5d6b3363a460ba21428711ef8ec7d25`;
- CPU6 VBR `a92cbfab10d545af54d31cf7fff8dfa1ad3775da8246888cef3eaaf49954c706`;
- CPU7 CBR `89a598e839b8946ffd97a2a2b2dc6941d24225b8b142648bccbe8cf6c97421ae`;
- CPU7 VBR `9864d09c0610fcd0ec0fca3439b670aad93b134ae2470750a11932dbc4df59b3`;
- CPU8 CBR `c1477e93f7eca160e93969c7ebc8e86d9d4f4443b5123cf8955a1d329214df0e`;
- CPU8 VBR `2c75b26d5d72dd9da93ebce72621b3a5e0d2ec61470adca35703d31216a27a1c`.

Validation:

- `cargo test --release -p rvp9-encoder largest_subpel_block_fits_inter_pred_border_scratch --locked`;
- `cargo test -p rvp9-encoder scaled_spatial_predictor_matches_decoder_for_luma_chroma_and_edges --locked`;
- `cargo test --release -p rvp9-encoder --lib --locked` (711 passed, 1 ignored);
- `cargo test --release -p rvp9-encoder --test w_feature_interaction_matrix --locked`;
