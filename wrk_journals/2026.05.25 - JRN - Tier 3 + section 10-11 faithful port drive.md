## Anti-false-pass protocol (G3 lesson)

Every agent prompt MUST require:
1. The function/flag being ported is **called from the picker / encoder hot path** (not just defined)
2. A **PROOF test** that fails if the change isn't actually wired (positive assertion on behaviour)
3. Test count must increase by at least 1 (validates the proof test actually compiles + runs)
4. Cross-decoder gate: encoder output decodes through rvp9-decoder (existing tests catch this)

Before declaring an item done, I will:
- Read the actual implementation (not the agent's summary)
- Confirm the libvpx-source lines are matched
- Confirm the PROOF test exists and has positive assertions
- Run the relevant test scope to confirm green
