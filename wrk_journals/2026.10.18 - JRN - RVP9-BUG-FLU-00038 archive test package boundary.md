# RVP9-BUG-FLU-00038 — Archive test package boundary

Manual Open-queue fixing pass. Claimed with `deltic start-task --bug RVP9-BUG-FLU-00038`; run `fix-20261018T191216Z-cbe17809`.

## Observation

On the unchanged package manifests, fresh `cargo package --locked --offline` verification passed for decoder and encoder. Extracted archive commands then failed: decoder `--test panic_safety` exited 101 with E0432 for `rvp9_encoder`; encoder `--test quality_gate` exited 101 with E0432/E0433 for `rvp9_decoder` and `rvp9_harness`. The normalized manifests had stripped the path-only dev-dependencies but retained those integration-test targets.

## Change

Both distributable library manifests exclude `tests/**`. Cargo still discovers and runs those tests in the source workspace, where sibling crates and repository fixtures are available. The encoder's `sad_simd_oracle` example is also excluded because it uses the unpublished workspace harness. Its existing decoder dev-dependency now carries a registry version as well as the workspace path, allowing encoder unit tests in an extracted registry archive to compile.

## Regression and workspace checks

- Reproduced both failures from freshly packaged, extracted archives in registered scratch `flu38-baseline-3122ff7a`.
- A Cargo package probe with the same exclude rule omitted the integration-test source and reported that it ignored the excluded test target.
- `cargo test -p rvp9-decoder --test panic_safety --no-run`: passed and produced the workspace test executable.
- `cargo test -p rvp9-encoder --test quality_gate --no-run`: passed and produced the workspace test executable, including after the final manifest change.
- `cargo test -p rvp9-encoder --lib --no-run`: passed with the final versioned path dependency.
- `cargo fmt --all --check` and `git diff --check`: passed.
- The first extracted encoder archive attempt with only the integration-test exclusion still failed: its `src/` unit tests use `rvp9_decoder`. The versioned path dependency fixes that; excluding `sad_simd_oracle` also removes the packaged example's unpublished harness dependency.

## Clean archive validation

- `deltic timeout 600 cargo package --locked --offline -p rvp9-decoder --jobs 4`: passed; Cargo packaged 17 files and ignored the three excluded integration-test targets.
- `deltic timeout 600 cargo package --locked --offline -p rvp9-encoder --jobs 4`: passed; Cargo packaged 63 files and ignored the excluded integration tests and `sad_simd_oracle` example.
- Inspected both extracted manifests and file trees: neither archive contains a `tests/` directory or test target declaration; encoder also contains no `sad_simd_oracle` source. Its normalized manifest retains the version-only `rvp9-decoder` dev-dependency.
- From the extracted decoder archive, `cargo test --locked --manifest-path Cargo.toml --jobs 4`: passed, 224 unit tests and one compile-fail doctest passed; three doctests remained ignored.
- From the extracted encoder archive, the same command passed, 824 unit tests passed, one was ignored, and no doctests were defined.

## Limits

This changes only registry archive contents. It does not change workspace test coverage or claim that Cargo package verification runs integration tests.
