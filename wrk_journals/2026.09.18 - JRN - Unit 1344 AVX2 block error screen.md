# Unit 1344 — AVX2 block-error screen

Date: 2026-09-18  
Branch: `task/20260917-TSK-HUM-x86-final-emission-residual-sse2`

## Scope

This run screened an exact x86-64 AVX2 implementation of the scalar
`vp9_block_error` kernel for the common 4x4, 8x8, and 16x16 coefficient
lengths.  The scalar implementation remained the reference fallback on
other targets and lengths.  The candidate was compared with the retained
Unit 1342 SSE2 candidate binary before any PGO qualification.

## Correctness and architecture coverage

- Local AArch64 release `rdo::block_error` tests passed all five tests.
- Local x86-64 cross-target release `rdo::block_error` tests passed all five
  tests, including the AVX2-gated differential cases.
- Local x86-64 cross-target `rvp9-core` tests passed both AVX2 differential
  tests.
- Native Crucible x86 release AVX2 differential tests passed after a deliberate
  red mutation of the odd-lane square; the mutation failed both tests, and
  restoring the source made both pass.

All three timed clips produced byte-identical candidate and control output
hashes.  The raw run, summary, and manifest are retained in
`wrk_docs/evidence/2026-09-18-unit1344-block-error/`.

## Fresh Crucible screen

The relaxed-load harness used CPU-used 6, CBR 1260 kbps, 720p30, one thread,
zero tile columns, 60 frames, keyframe interval 60, one warmup, 15 alternating
pairs, and two reverse rotations.  The anchor was the exact Unit 1342 SSE2
candidate binary (`b479957f-control`); the test was the AVX2 block-error
candidate.

| Clip | Separate | Paired | Test ms/frame | Anchor ms/frame |
| --- | ---: | ---: | ---: | ---: |
| Ducks take off | 1.022650x | 1.027052x | 27.624 | 27.013 |
| In to tree | 1.007470x | 1.005076x | 24.992 | 24.807 |
| Old town cross | 1.038154x | 1.007971x | 22.741 | 21.906 |
| Corpus | 1.022681x | **1.013320x** | — | — |

The candidate was slower on every clip, with a 1.33% paired corpus regression.
The result does not justify a canonical production-PGO or pinned-libvpx
qualification run, even though it remains below the harness's 1.05x safety
ceiling.

## Decision

Reject Unit 1344 as a performance candidate and retain its evidence only as a
negative result.  The local worktree source and the remote Crucible scratch
tree were restored to their pre-screen state; no code from this candidate was
committed or integrated.
