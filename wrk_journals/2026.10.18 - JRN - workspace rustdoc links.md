# Workspace rustdoc link cleanup

RVP9-BUG-FLU-00055 reproduced with `cargo doc --workspace --no-deps --locked --offline`, which completed successfully while emitting 143 rustdoc warning diagnostics across the workspace. The diagnostics came from unresolved links, links to private implementation items, ambiguous function/module names, and literal syntax interpreted as links or HTML.

Updated documentation across the affected crates and binaries: retained links only for documented public items, used inline code for private implementation details and literal values, and qualified valid cross-module links. No API or runtime behavior changed.

The same workspace rustdoc command completed with zero warning diagnostics after the edits. `cargo fmt --all --check`, `git diff --check`, and a diff audit that confirmed the 290 changed Rust source lines are documentation comments passed.
